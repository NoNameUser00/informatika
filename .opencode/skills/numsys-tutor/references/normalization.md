# Нормализация numeric_base и частичный балл

## Нормализация (применять до сравнения)

1. trim, убрать все пробелы и подчёркивания: `1 010` → `1010`.
2. Кириллицу А–Е (и ё) в латиницу A–E: `аF` == `AF`, регистр не важен.
3. Срезать префиксы `0b`/`0o`/`0x` и — только явные — суффиксы `_(2|8|10|16)`, `(2|8|10|16)`.
   Голые цифры на конце НЕ трогать: `111010` нельзя резать до `1110`.
4. Ведущие нули игнорировать: `00101` == `101`.
5. Сравнивать числовое значение в base 10, не строки.

## Частичный балл

- `single_choice`, `numeric_base`: all_or_nothing (опечатка в numeric_base = 0).
- `matching`: `score = round(matched_pairs / total_pairs × points)`.
- `multiple_choice` (если появится): `score = max(0, (ok − extra) / total_correct) × points`.
