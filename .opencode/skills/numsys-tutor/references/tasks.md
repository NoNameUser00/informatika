# Формат заданий и типовые ошибки

Каждое задание: `id, class, topic, type, prompt, points, difficulty, cognitive_level, fgos, student_view, auto_check`.
`student_view` — что видит ученик (base, placeholder, options, left/right). `teacher_only` — только сервер/БД.

## Приёмы по подтемам

- 10→2/8/16: деление на основание, остатки снизу вверх (13 → 1101₂: остатки 1-0-1-1).
- 2/8/16→10: развёрнутая форма, степени основания (101101₂ = 32+8+4+1 = 45).
- 16↔2: тетрады (3A₁₆ = 0011 1010 → 111010₂, ведущие нули отбросить). 2↔8: триады (1101011₂ = 1|101|011 = 153₈).
- Арифметика: считать через десятичную для проверки (1011₂ + 110₂ = 11 + 6 = 17 = 10001₂).
- Количество единиц: сначала корректный перевод, потом подсчёт (2A₁₆ = 101010₂ → 3 единицы).

## Типовые ошибки учеников

- Путают число нулей с числом единиц в двоичной записи.
- Читают десятичную запись как двоичную (15₁₀ ≠ 111₂).
- Путают основание системы с позиционностью (римская — непозиционная, остальные наши — позиционные).
- Теряют ведущие нули тетрад/триад при склейке или, наоборот, оставляют их в ответе.
- В matching путают пары 8↔1000₂ и 10↔1010₂.
