# Ученическая офлайн-версия (Windows / Rosa OS Mostex 12)

Работает без интернета на школьном компьютере.

## Запуск

- **Windows 10/11:** двойной клик по `start-windows.bat` (нужен Python — обычно уже стоит; нет — попроси учителя).
- **Rosa OS Mostex 12:** в терминале из этой папки `sh start-rosa.sh` (или двойной клик, если настроено).
- Сайт откроется сам: `http://localhost:8000/`. Закроешь окно сервера — сайт встанет.

## Как сдать работу

1. Открой свою контрольную/проверочную/тренажёр, заполни ФИО и класс.
2. Ответь на все вопросы, нажми «Отправить».
3. Скачается файл вида `8-Ч_Иванов_Иван_control-ss_v3.json` — **это твоя работа**.
4. Передай файл учителю: по почте, на флешке или по локальной сети.

Важно: верных ответов и баллов здесь нет — их посчитает учитель.
Один файл — одна работа. Не переименовывай файл: в имени закодированы класс, фамилия и вариант.
