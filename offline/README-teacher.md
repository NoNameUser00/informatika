# Учительская офлайн-версия (Windows / Rosa OS Mostex 12)

Здесь лежат ключи всех работ — **не раздавать ученикам**.

## Запуск

- **Windows 10/11:** двойной клик по `start-windows.bat`.
- **Rosa OS Mostex 12:** `sh start-rosa.sh` из этой папки.
- Сайт: `http://localhost:8000/`.

## Проверка работ

1. Открой страницу «Проверка файлов» (раздел учителя).
2. Загрузи файлы ответов учеников (можно несколько сразу).
3. Каждый файл проверяется: формат, известная работа, **хэш версии**.
   Файл от другой версии работы отклоняется с причиной — такие не проверять.
4. Итоги: таблица (верно из N, баллы, отметка), разбор по каждому ученику,
   аналитика по темам, экспорт CSV (`offline-vedomost.csv`).

Шкала отметок та же, что онлайн: «5» — от 90%, «4» — от 75%, «3» — от 50%, иначе «2».

## Как обновить версию

Работы и ключи зашиты в сборку. Новая версия — только пересборкой из репозитория:
`npm run build:offline-teacher` (см. `docs/offline.md`).
