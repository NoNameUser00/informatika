# Считаем пути накопилением

**Направленный ациклический граф (DAG)** — ориентированный граф без циклов: вершины можно перечислить так, что каждое ребро идёт от более ранней к более поздней.

Пример DAG: A → B, A → C, B → D, C → D.

Порядок вершин: A, B, C, D. Каждое ребро направлено «влево направо» — циклов нет.

## Правило

**Число путей в вершину = сумма чисел путей во все её предшественники.**

Считаем накоплением, в топологическом порядке.

| Вершина | Предшественники | Путей |
|---|---|---|
| A | нет | **1** (пустой путь) |
| B | A | 1 + 1 = **2** |
| C | A | 1 + 1 = **2** |
| D | B, C | 2 + 2 = **4** |

Ответ: в D ведут 4 пути.

Перечислим их: A → B → D, A → C → D, A → B → C → D (если есть ребро B → C), A → C → B → D. Для графа A → B, A → C, B → D, C → D пути ровно два: A → B → D и A → C → D. Значит D = 2 + 2... нет, здесь B и C не связаны между собой, поэтому в D = 2.

Проверим на нашем графе: B = 1 (из A), C = 1 (из A), D = B + C = 1 + 1 = **2**. Верно.

## Стартовое значение

В вершину-источник всегда **1 путь** — пустой путь. Это не «ноль путей»: из A в A можно попасть, никуда не двигаясь.

Забыть эту единицу — самая частая ошибка: тогда все остальные значения получатся в 2 раза меньше.

## Более сложный пример

Граф: A → B, A → C, B → C, B → D, C → D.

| Вершина | Предшественники | Путей |
|---|---|---|
| A | — | 1 |
| B | A | 1 |
| C | A, B | 1 + 1 = 2 |
| D | B, C | 1 + 2 = 3 |

Проверка перебором: в D ведут A → B → D, A → B → C → D, A → C → D. Три пути. Сходится.

## Почему работает

Любой путь в вершину заканчивается ребром из одного из её предшественников. Значит, все пути разбиваются на непересекающиеся группы по последнему ребру — их столько же, сколько путей в предшественников. Складываем.

## Практическая работа

1. Дан граф: X → Y, X → Z, Y → W, Z → W, W → V, Y → V.
2. Построй топологический порядок.
3. Посчитай пути накоплением: X = 1, Y = 1, Z = 1, W = Y + Z = 2, V = W + Y = 2 + 1 = 3.
4. Проверь перебором всех путей из X в V: X → Y → V, X → Y → W → V, X → Z → W → V. Три пути.

## Ключевое (записать)

- DAG: ориентированный граф без циклов; вершины топологически упорядочены.
- Число путей в вершину = сумма чисел путей в её предшественников.
- В источнике всегда 1 путь (пустой путь).
- Проверяй перебором: результат должен совпасть.

## Частые ошибки

- Ставить 0 в вершину-источник вместо 1: все значения в 2 раза меньше.
- Считать не в топологическом порядке: предшественник ещё не посчитан.
- Путать пути и длины путей: разные вопросы.
- Не проверить перебором: ошибку в суммировании не заметить.
