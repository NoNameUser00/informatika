# Логика внутри таблицы

**Логические функции** проверяют условия и возвращают значение — как ветвление из 8 класса.

## Функция ЕСЛИ

```
=ЕСЛИ(условие; значение_если_да; значение_если_нет)
```

Пример: цена со скидкой.

```
=ЕСЛИ(C2>1000; C2*0,9; C2)
```

Если цена больше 1000 — умножаем на 0,9 (скидка 10%), иначе оставляем как есть.

## Вложенные условия

Когда условий больше двух, `ЕСЛИ` вкладывают в `ЕСЛИ`:

```
=ЕСЛИ(C2>2000; C2*0,8; ЕСЛИ(C2>1000; C2*0,9; C2))
```

Логика: если больше 2000 — скидка 20%, иначе если больше 1000 — скидка 10%, иначе без скидки.

Порядок важен: сначала проверяют **самое крупное** условие, иначе «больше 1000» перехватит и «больше 2000», и скидка будет 10% вместо 20%.

## Логические операторы в формуле

| Оператор | Значение | Пример |
|---|---|---|
| `=` | равно | `B2=5` |
| `<>` | не равно | `B2<>5` |
| `<` `>` | меньше, больше | `B2>5` |
| `<=` `>=` | не больше, не меньше | `B2>=5` |
| `И(...)` | логическое И | `И(B2>0;C2>0)` |
| `ИЛИ(...)` | логическое ИЛИ | `ИЛИ(B2=1;B2=2)` |
| `НЕ(...)` | отрицание | `НЕ(B2>10)` |

## Считаем по вводимым пользователем формулам

Задание КТП: расчёты по формулам, которые вводит пользователь.

Схема: в ячейках стоят не константы, а формулы; пользователь меняет исходные данные — результаты пересчитываются.

1. Сделай лист «Параметры»: стоимость, количество, скидка.
2. На листе «Расчёт» ставь формулы со ссылками на параметры (`=Параметры.B2`).
3. Измени стоимость — и все расчёты обновятся.

Это **модель** в простом виде: заданы параметры, а результат считается по формулам.

## Практическая работа

1. В таблице «Продажи» добавь столбец «Скидка» по правилу: при сумме больше 2000 — 20%, больше 1000 — 10%, иначе 0.
2. Добавь столбец «Итого» = Сумма − Скидка.
3. Добавь столбец «Категория»: `=ЕСЛИ(D2>2000;"Крупный";"Мелкий")`.
4. Проверь границы: при сумме ровно 2000 должна быть скидка 10%, не 20%.

## Ключевое (записать)

- `ЕСЛИ(условие; да; нет)` — разделитель точка с запятой.
- Условия в формуле: `=`, `<>`, `<`, `>`, `<=`, `>=`, `И`, `ИЛИ`, `НЕ`.
- Вложенный `ЕСЛИ`: сначала проверяй самое строгое условие.
- Формулы со ссылками на параметры — основа моделирования в таблице.

## Частые ошибки

- Проверять условия в неправильном порядке: «больше 1000» раньше «больше 2000» ломает скидки.
- Писать `=` вместо `==` внутри формулы — в таблице это правильно (`=C2>10` работает, лишний `=` нет).
- Использовать запятую вместо точки с запятой.
- Забыть про границы: «больше» и «не меньше» дают разный результат на границе.
