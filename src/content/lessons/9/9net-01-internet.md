# Глобальная сеть и адреса

**Интернет** — глобальная сеть, соединяющая компьютеры по всему миру. Это не одна сеть, а сеть сетей: интернет-провайдеры соединяют между собой свои локальные сети.

## IP-адрес узла

**IP-адрес** — числовой адрес узла в сети. В четвёртой версии протокола (IPv4) это **четыре десятичных числа от 0 до 255**, записанные через точки:

```
22.4.13.73
```

Каждое число занимает 8 бит, итого 4 · 8 = **32 бита**.

Всего возможных адресов: 256⁴ ≈ 4,3 миллиарда. Адресов всех устройств мира это число заметно превышает, поэтому применяют IPv6: 128 бит (16 шестнадцатеричных чисел) — этого хватает с огромным запасом.

**Правило проверки:** каждое из четырёх чисел должно быть от 0 до 255 включительно.

- `113.256.0.138` — не адрес (256 > 255).
- `132.97.1212.14` — не адрес (1212 > 255).
- `0.0.0.0` — допустимый адрес, но в задачах такие не подходят.

## Двоичная форма адреса

Каждое число переводится в 8 бит:

```
210.171.30.128
→ 11010010.10101011.00011110.10000000
```

Это не новый адрес, а та же запись в двоичной системе — по одному принципу, что и в 8 классе.

## Как из фрагментов собрать адрес

Задача: даны обрывки, нужно склеить из них корректный адрес.

Обрывки: `3.133`, `22`, `.73`, `4.13`.

Склейка должна дать **ровно четыре числа, каждое 0–255**. Проверяем варианты: подходит только порядок Б → Г → А → В, дающий `224.133.133.73`. Остальные склейки дают либо пять чисел, либо число больше 255.

Правильный ход: перебрать варианты и проверять по правилу «четыре числа по 0–255».

## DNS: имена вместо чисел

Человеку удобнее имена, чем числа. **DNS** — система, которая переводит доменное имя в IP-адрес: `ya.ru` → 22.4.13.73.

Почти так же работает телефонная книга: имя — номер. DNS можно считать «телефонной книгой интернета».

Домены верхнего уровня: `.ru`, `.su` (Россия), `.com` (коммерческие), `.edu` (образование).

## Сетевое хранение данных

**Сетевое (облачное) хранилище** — файлы лежат не на твоём диске, а на сервере в интернете.

Плюсы: доступ с любого устройства, не потеряется вместе с флешкой, общий доступ для группы.

Минусы: нужен интернет, скорость зависит от канала, данные видны владельцу сервиса.

## Ключевое (записать)

- IPv4: четыре числа 0–255, всего 32 бита, ≈4,3 млрд адресов.
- IPv6: 128 бит — с большим запасом.
- Число больше 255 в адресе = ошибка.
- DNS переводит доменное имя в IP-адрес.
- Облачное хранилище: файлы на сервере, доступны отовсюду.

## Частые ошибки

- Принять число 256 за допустимое в адресе.
- Считать, что в IPv4 больше 255 адресов всего: их 4,3 миллиарда.
- Путать IP-адрес и MAC-адрес: IP меняется при переходе в сеть, MAC обычно нет.
- Считать облачное хранилище надёжнее локального: зависит от сервиса.
