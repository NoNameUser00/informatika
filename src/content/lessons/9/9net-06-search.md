# Поиск как логическая задача

**Средства и методика поиска информации**: операторы, кавычки, фильтры по дате и типу файла, поиск по картинке.

## Операторы — логика из 8 класса

| Оператор | Смысл | Пример |
|---|---|---|
| `AND` (И) | оба слова есть | `тормозной путь AND формула` |
| `OR` (ИЛИ) | хотя бы одно | `LibreOffice OR OpenOffice` |
| `-` (НЕ) | убрать мусор | `робот -игрушка` |
| `"..."` | точная фраза | `"исполнитель Автомат"` |
| `site:` | внутри сайта | `site:edu.ru теория вероятностей` |
| `filetype:` | тип файла | `программирование filetype:pdf` |

Проверим логику. Запрос `робот -игрушка` вернёт страницы со словом «робот», кроме страниц про игрушки: это вычитание множеств.

Запрос `"условие Фано" кодирование` — точная фраза целиком, а не два слова в любом порядке.

## Поиск по изображению

**Поиск по изображению** — сервисы, находящие похожие картинки или страницы с тем же снимком.

Как использовать:

1. Загрузить изображение в поисковик или сервис картинок.
2. Получить похожие результаты и страницы-источники.
3. Проверить найденное: это может быть другая картинка с тем же сюжетом.

Правило: результат поиска по картинке — **не источник**. Источник — страница, где ты проверил факт.

## Оценка найденного

Правило трёх вопросов:

1. **Кто автор?** Материал без автора — подозрителен.
2. **Когда опубликовано?** Старая статья может быть неверна.
3. **Подтверждает ли источник друг друга?** Пять сайтов с одинаковой ошибкой не делают её правдой.

Серьёзные источники: учебники, материалы вузов и библиотек, сайты организаций, википедия как точка старта (не как итоговый источник).

## Практическая работа

Задание КТП: поиск информации в сети по запросам с использованием логических операций.

1. Найди 3 источника по теме «тормозной путь автомобиля» — используй `"..."` и `site:`.
2. Найди 3 источника по теме «виды компьютерной графики» — используй `OR`.
3. Найди материалы, исключив мусорный запрос — используй `-`.
4. Найди сведения о **больших данных и умном городе**.
5. Для каждого источника запиши: автор, дата, адрес.
6. Выбери 2 лучших и обоснуй выбор.

## Ключевое (записать)

- Операторы `AND`, `OR`, `-`, `"..."`, `site:`, `filetype:` работают как логика.
- `-` вычитает: `робот -игрушка`.
- Кавычки требуют точную фразу.
- Поиск по картинке даёт похожие, а не источник.

## Частые ошибки

- Искать по одному слову: выдача из миллионов результатов.
- Верить первому результату без проверки автора и даты.
- Считать пять сайтов с одинаковым текстом подтверждением.
- Использовать `OR` там, где нужно `AND` (и наоборот).

2. Зачем нужны кавычки?
3. Назови три вопроса для оценки надёжности источника.
