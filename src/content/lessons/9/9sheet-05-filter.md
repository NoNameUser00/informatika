# Фильтрация

**Сортировка** (прошлый урок) переставляет строки целиком. **Фильтрация** — другой инструмент: она **прячет** строки, не подходящие под условие, но не удаляет и не меняет порядок остальных.

Это разные вещи: сортировка меняет расположение, фильтрация — только видимость.

## Как фильтровать

1. Выдели шапку и данные (или просто поставь курсор в таблицу).
2. Данные → Автофильтр (или кнопка на панели).
3. В шапке появятся стрелочки-маркеры.
4. Кликни по стрелке — откроется список значений столбца.
5. Отметь нужные значения — строки отфильтруются.

Автофильтр можно снять: Данные → Автофильтр (повторный клик). Важно: **фильтр не удаляет данные** — сними его, и все строки вернутся.

## Фильтр по условию

В списке значений есть пункт «Условие» или «Числовой фильтр», где задаётся диапазон:

- больше 1000,
- между 500 и 1000,
- содержит текст «Продажа».

## Условное форматирование

Отдельный инструмент: ячейка меняет цвет **по условию**, а не по значению.

Данные → Условное форматирование → «Если значение больше…» → задай цвет.

Пример: все суммы больше 2000 подсветить жёлтым. Так в таблице сразу видно выбросы.

## Практическая работа

Задание КТП: фильтрация данных в электронных таблицах.

1. Возьми таблицу «Продажи».
2. Включи автофильтр.
3. Отфильтруй по столбцу «Товар» — выбери два товара из списка.
4. Посчитай сумму `=СУММ(...)` по видимым строкам — обрати внимание: суммируются **только видимые**.
5. Сними фильтр и проверь: все строки вернулись, сумма изменилась.
6. Добавь условное форматирование: суммы больше 2000 выделяются цветом.
7. Отсортируй по столбцу «Сумма» по убыванию — убедись, что фильтр снят, иначе сортировка тронет скрытые строки.

## Ключевое (записать)

- Сортировка меняет порядок строк; фильтрация прячет строки, данные остаются.
- Автофильтр включается по кнопке, стрелки появляются в шапке.
- Функции считают **только видимые** строки при фильтре.
- Условное форматирование красит ячейки по условию.

## Частые ошибки

- Считать, что фильтр удалил строки: снятие фильтра всё возвращает.
- Забыть снять фильтр перед сохранением — получаешь файл, открытый «не на тех строках».
- Сортировать при активном фильтре: результат непредсказуем.
- Считать сумму при фильтре и удивляться расхождению с общей суммой.

## Проверь себя

1. Чем фильтрация отличается от сортировки?
2. Что считает `СУММ`, когда включён фильтр?
3. Что делает условное форматирование?
