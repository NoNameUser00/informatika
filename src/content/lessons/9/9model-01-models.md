# Модель — существенное вместо всего

**Модель** — новый объект, отражающий существенные (для цели!) признаки оригинала. **Моделирование** — метод познания через создание и исследование моделей.

## Виды и цель

- **Натурные**: уменьшенные/увеличенные копии (макет самолёта).
- **Информационные**: описания на языке (словесные, математические, табличные, графические).
- **Формализация** — замена объекта его формальным описанием.
- Цель решает, что существенно: для аэродинамики — форма, для расписания — время. Одному объекту — много моделей; одна модель — многим объектам.

## Адекватность: сверка с экспериментом

**Адекватная** модель даёт результаты, близкие к опытам с оригиналом. Не сошлось — модель врёт, чиним её, а не мир.

## Эталон: тормозной путь (только Python!)

Задача: по скорости найти путь торможения. Формула модели: `s = v²/10` (v — в м/с).

```
v = 72 * 1000 / 60 / 60   # км/ч → м/с: 20
s = v * v / 10            # 400 / 10
print(s)                  # 40
```

Ответ: 40 метров. Этапы: постановка → формула → программа → **тест** (совпало с опытом?) → выводы при разных данных.

## Ключевое (записать)

- Модель — существенное для цели. Формализация — замена описанием.
- Адекватность = совпадение с экспериментом.
- Путь: задача → формула → код → тест → выводы.

## Частые ошибки

- Тащить в модель всё подряд (модель должна быть ПРОЩЕ оригинала!).
- Верить модели без сверки с опытом.
- Путать км/ч и м/с в формулах (дели на 3.6!).

## Проверь себя

1. Приведи две разные модели одного объекта. А одну модель двух объектов?
2. Найди тормозной путь при 90 км/ч. (62.5 → проверь: 25²/10)
