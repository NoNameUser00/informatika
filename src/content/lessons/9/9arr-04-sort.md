# Упорядочиваем элементы

**Сортировка** — перестановка элементов так, чтобы они шли по возрастанию или по убыванию.

## Сортировка выбором

Идея та же, что в поиске максимума: **ищем чемпиона в остатке и ставим на своё место**.

По возрастанию:

1. Среди всех элементов найди минимальный.
2. Поставь его на первое место.
3. Среди остальных найди минимальный, поставь на второе.
4. Повторяй, пока элементы не кончатся.

Пример `[5, 2, 8]`:

| Шаг | Массив | Что делаем | Результат |
|---|---|---|---|
| 1 | [5, 2, 8] | минимум 2 → на место 1 | [2, 5, 8] |
| 2 | [2, 5, 8] | минимум из остатка 5 → на место 2 | [2, 5, 8] |
| 3 | [2, 5, 8] | минимум из остатка 8 → на место 3 | [2, 5, 8] |

## В Python

```
a = [5, 2, 8]
for i in range(len(a)):
    imin = i
    for j in range(i + 1, len(a)):
        if a[j] < a[imin]:
            imin = j
    a[i], a[imin] = a[imin], a[i]
print(a)   # [2, 5, 8]
```

Два цикла: внешний выбирает место, внутренний ищет минимум в остатке. Обмен — одной строкой через две переменные.

## Другие способы

- **Пузырьковая** — сравниваем соседние и меняем местами, «всплывает» максимум. Проще в коде, но медленнее.
- **Вставками** — каждый элемент вставляется в уже отсортированную часть. Эффективна на почти отсортированных данных.
- **Слиянием** — быстрая, но нужна дополнительная память.

В школе разбирают выбор и пузырьковую; остальное — обзорно.

## Сколько сравнений

Сортировка выбором делает ровно `n(n−1)/2` сравнений:

- 10 элементов → 45 сравнений,
- 100 элементов → 4950,
- 1000 → 499 500.

Рост квадратичный: в 10 раз больше данных — примерно в 100 раз больше работы.

## Связь с задачами

После сортировки сразу решаются задачи, которые раньше требовали просмотра:

- второй по величине элемент — `a[-2]`,
- сколько элементов больше 10 — бинарный поиск (не просмотр),
- медиана — элемент в середине.

## Практическая работа

1. Отсортируй `[5, 2, 8]` по возрастанию → `[2, 5, 8]`.
2. Отсортируй по убыванию → `[8, 5, 2]` (сравнение `>` вместо `<`).
3. Найди второй по величине элемент.
4. Посчитай, сколько сравнений сделает сортировка выбором для 8 элементов: 8·7/2 = 28.

## Ключевое (записать)

- Сортировка выбором: ищем минимум в остатке, ставим на место, повторяем.
- Два цикла: место (внешний) и поиск минимума (внутренний).
- По убыванию меняется только знак сравнения.
- Сложность `n(n−1)/2` — рост квадратичный.

## Частые ошибки

- Искать минимум по всему массиву, а не по остатку: уже поставленные элементы «прыгают» назад.
- Обменивать значения вместо элементов и забывать про временную переменную (в Python обмен одной строкой).
- Считать, что сортировка меняет сами числа — меняются только места.
