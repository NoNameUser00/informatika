# Граф решает задачу

Задачи, где есть «объекты» и «связи между ними», почти всегда решаются графом.

| Задача | Граф |
|---|---|
| Дороги между городами | вершины — города, рёбра — дороги |
| Кто кому родственник | вершины — люди, рёбра — родство |
| Зависимости работ | вершины — дела, рёбра — «после чего» |
| Потоки данных | вершины — узлы, рёбра — потоки |

## Кратчайший путь

Когда рёбра имеют веса (расстояния), ищем **кратчайший путь** — сумму весов минимальную.

Пример: A → B (4), A → C (2), C → B (1), B → D (5), C → D (8).

Перебираем пути из A в D:

| Путь | Расчёт | Сумма |
|---|---|---|
| A → B → D | 4 + 5 | 9 |
| A → C → D | 2 + 8 | 10 |
| A → C → B → D | 2 + 1 + 5 | **8** |

Кратчайший путь — A → C → B → D, 8. Обрати внимание: самый короткий по числу рёбер (A → B → D) не обязательно самый лёгкий по сумме весов.

## Метод перебора

1. Запиши все возможные пути (дерево перебора).
2. Посчитай сумму весов каждого.
3. Выбери наименьшую.

При малом числе вершин перебор надёжен и понятен. При большом числе путей растёт взрывообразно — тогда нужен алгоритм Дейкстры, но в 9 классе достаточно перебора.

## Задачи без весов

Иногда весов нет, а вопрос другой: «есть ли путь из A в C?», «сколько вершин в связной компоненте?».

- **Достижимость**: обход в ширину или в глубину от A, отмечаем посещённые.
- **Число путей**: считаем накоплением (следующий урок).

## Практическая работа

1. Построй взвешенный граф с 5 вершинами (карта города: 5 перекрёстков, 6 дорог).
2. Запиши весовую матрицу.
3. Найди кратчайший путь из A в E перебором — запиши все пути и суммы.
4. Ответь: есть ли путь из B в E, если такой дороги нет?
5. Построй неориентированный вариант того же графа и сравни матрицы.

## Ключевое (записать)

- Граф подходит, когда есть объекты и связи между ними.
- Кратчайший путь = минимальная сумма весов, а не минимальное число рёбер.
- Метод перебора: выписать все пути → посчитать суммы → выбрать минимум.
- Без весов решают достижимость и число путей.

## Частые ошибки

- Считать кратчайшим путь с наименьшим числом рёбер, а не весов.
- Забыть взвешенную матрицу (потеряны расстояния).
- Перебрать не все пути: упущенный путь может быть короче.
- Считать сумму, складывая количества рёбер вместо весов.

## Проверь себя

1. Почему граф подходит для задачи о дорогах?
2. Чем отличается кратчайший путь от пути с наименьшим числом переходов?
3. Опиши три шага метода перебора.
