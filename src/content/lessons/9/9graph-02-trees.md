# Дерево как структура

**Дерево** — граф без циклов: из любой вершины существует ровно один путь в другую. Пример — генеалогическое дерево, дерево файлов на диске, дерево решений задачи.

У дерева есть вершина без входящих рёбер — **корень**. От неё расходятся ветви, внизу — **листья**.

## Дерево решений

Самый полезный для школы вид: дерево перебора вариантов.

Задача: «имеются монеты 5, 2, 1 рубля. Сколько разными способами можно набрать сумму 7?»

Дерево решений:

```
          корень (0)
          ├─ взять 5 → осталось 2 → лист ✓
          ├─ взять 2 → осталось 5 → ...
          └─ взять 1 → осталось 6 → ...
```

Каждая ветка — один выбор, каждый лист — законченный вариант. Посчитав листья, получаем число способов.

**Дерево помогает не забыть варианты.** В лоб: сколько бы ни старайся, варианты легко пропустить или посчитать дважды.

## Типичная ошибка: считать «на глаз»

Одно и то же дерево, посчитанное вручную и по правилам, даёт разные числа. Правило: **лист = законченный вариант, ветка от корня до листа = один вариант**. Считал только ветки до первого решения — потерял остальные.

## Списки

**Список** — простейшая структура данных: элементы идут по порядку, у каждого есть номер (индекс). Массив из 8 класса — как раз список.

Отличие от дерева: в списке элементы не связаны между собой, в дереве — связаны иерархически.

Списки применяются, когда порядок важен и связи нет: очередь, список учеников, ряд чисел.

## Практическая работа

1. Построй дерево для задачи: «сколькими способами можно расставить числа 1, 2, 3 на трёх местах?».
2. Посчитай листья: первый элемент — 3 варианта, второй — 2, третий — 1, итого 3 · 2 · 1 = 6.
3. Проверь, что в дереве ровно 6 листьев.
4. Построй дерево для: «имеются монеты 1, 3, 5, как набрать сумму 7?» Посчитай варианты.

## Ключевое (записать)

- Дерево — граф без циклов; у него есть корень и листья.
- Дерево решений помогает перебрать варианты и ничего не забыть.
- Ветка от корня до листа — один вариант; лист — законченный вариант.
- Список — элементы с индексами, связей между ними нет.

## Частые ошибки

- Считать промежуточные вершины вместо листьев.
- Пропускать ветки: например, забыть вариант, где первый элемент самый большой.
- Считать одно и то же дерево дважды, разными методами.
- Путать лист и вершину: лист — там, где вариант завершён.

## Проверь себя

2. Что считать в дереве решений — листья или вершины?
3. Сколькими способами можно переставить три числа?
