# Страница из блоков

**Веб-страница** — документ в интернете, написанный языком **HTML** и показанный браузером.

## Из чего состоит страница

Страница — набор блоков, оформленных тегами:

| Тег | Что делает |
|---|---|
| `<p>` | абзац текста |
| `<h1>` … `<h6>` | заголовки |
| `<img src="...">` | изображение |
| `<a href="...">` | ссылка |
| `<table>` | таблица |
| `<ul>`, `<ol>` | списки |
| `<div>` | универсальный блок |

Картинки хранятся **отдельными файлами**, а страница на них ссылается. Отсюда важный вывод: перенесли HTML без картинок — страница «посыпалась».

## Конструктор вместо набора тегов

Вручную теги пишут редко. **Конструктор (шаблон)** — визуальный редактор: выбираешь макет, вставляешь текст и графику, а конструктор сам расставляет теги.

Как это устроено: ты видишь результат (как в текстовом процессоре), а под капотом правится HTML. Отсюда главное правило — **не править код в конструкторе**: после этого конструктор может перезаписать твои изменения.

## Практическая работа

Задание КТП: создание комплексных информационных объектов в виде веб-страниц, включающих графические объекты, с использованием конструкторов (шаблонов).

1. Выбери конструктор сайтов или редактор (есть готовые шаблоны).
2. Возьми шаблон: стартовая страница сайта или страница статьи.
3. Добавь текстовые блоки: заголовок, абзацы, список.
4. Добавь графические объекты: изображения, схему.
5. Добавь таблицу с данными.
6. Добавь ссылки: на внутренние страницы и на внешний источник.
7. Проверь: страница открывается, картинки видны, ссылки работают.
8. Сохрани и опубликуй, если конструктор это позволяет.

## Что проверить перед сдачей

1. Все ли картинки на месте (не осталось «битых» значков).
2. Работают ли ссылки.
3. Читается ли текст на телефоне: длинные строки и огромные картинки мешают.
4. Нет ли ошибок в заголовке и орфографии.

## Ключевое (записать)

- HTML — язык разметки; теги описывают блоки страницы.
- Изображения хранятся отдельными файлами.
- Конструктор: макет → содержимое → теги расставляются сами.
- В конструкторе не правят код вручную.

## Частые ошибки

- Скопировать HTML без папки с картинками: страница без изображений.
- Править код конструктора: изменения перезаписываются.
- Перегружать страницу: текст должен читаться на телефоне.
- Забыть про подписи к рисункам и источники.

## Проверь себя

1. За что отвечает тег `<img>`?
2. Почему страница «ломается», если перенести только HTML?
3. Почему в конструкторе не правят код вручную?
