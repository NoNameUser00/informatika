# Поиск чемпиона

**Минимум** и **максимум** находятся линейным просмотром, но сравнивают не с образцом, а с «текущим чемпионом».

## Максимум: алгоритм «стопки карточек»

1. Возьми первую карточку, запиши число на доске как «самый большой из просмотренных».
2. Бери следующую: если она больше записанного — сотри и запиши новое. Иначе оставь.
3. Повторяй, пока карточки не кончатся.

На доске — максимум.

В Python запоминают не значение, а **индекс** — доступ по индексу надёжнее:

```
a = [3, 7, 5]
imax = 0
for i in range(1, len(a)):
    if a[i] > a[imax]:
        imax = i
print(a[imax])   # 7
```

Почему `imax = 0`, а не 0: первый элемент становится начальным чемпионом, дальше сравниваем с ним.

## Минимум — тот же приём

```
imin = 0
for i in range(1, len(a)):
    if a[i] < a[imin]:
        imin = i
print(a[imin])   # 3
```

Разница только в знаке сравнения.

## Главная ловушка: массив из отрицательных чисел

Если написать `imax = 0` и сравнивать со значением `a[imax]` — всё верно. Но если начать с числа ноль (`m = 0`) и искать максимум, то массив `[-5, -2, -9]` даст ответ **0**, которого в массиве нет.

Правило: чемпион — это **первый элемент массива**, а не ноль. Ноль подходит только для счётчика количества.

## Инвариант цикла

Утверждение «сейчас `imax` указывает на максимум из просмотренных» истинно **перед** циклом (просмотрен один элемент) и **после** каждого прохода. Раз оно верно в конце — программа выдала правильный ответ.

Так доказывают корректность циклов: достаточно проверить утверждение на каждом шаге.

## Практическая работа

1. Дан массив `[12, -5, 23, -1, 8]`.
2. Максимум: 23 (индекс 2).
3. Минимум: −5 (индекс 1).
4. Проверь: правильно ли отработает программа с `m = 0` на массиве `[-5, -2, -9]`? (Нет — выдаст 0.)
5. Исправь так, чтобы работало для любых чисел.

## Ключевое (записать)

- Максимум: `imax = 0`, сравниваем `a[i] > a[imax]`.
- Минимум: `imin = 0`, сравниваем `a[i] < a[imin]`.
- Чемпион — первый элемент, а не ноль (иначе сломается на отрицательных).
- Запоминаем индекс, значение читаем в конце: `a[imax]`.

## Частые ошибки

- Инициализировать чемпиона нулём: максимум из отрицательных не найдётся.
- Путать индекс и значение: `imax` — номер, `a[imax]` — число.
- Сравнивать `a[i] > a[imax]` с первого элемента, а не со второго (сравнение с самим собой бессмысленно, но безвредно).
