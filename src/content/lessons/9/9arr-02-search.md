# Три задачи поиска (из учебника)

1. Найти наибольший/наименьший элемент.
2. Найти элемент, равный заданному.
3. Найти количество (сумму) подходящих под условие.

Всем нужен **последовательный просмотр**: идём по элементам и сравниваем каждый с образцом.

## Максимум: стопка карточек

Представь массив стопкой карточек с числами:
1. Возьми верхнюю, запиши число на доске как «самый большой из просмотренных», карточку — в сторону.
2. Бери следующую: если число больше записанного — сотри и запиши новое, иначе оставь. Карточку — в сторону.
3. Повторяй, пока карточки не кончатся. На доске — максимум.

В Python запоминают не значение, а **индекс** (`imax`): доступ по индексу дешевле и точнее.

```
a = [3, 7, 5]
imax = 0
for i in range(1, len(a)):
    if a[i] > a[imax]:
        imax = i
print(a[imax])   # 7
```

## Инвариант цикла (для сильных)

Утверждение «на доске — максимум из просмотренных» истинно ПЕРЕД циклом и ПОСЛЕ каждого прохода. Раз оно верно в конце — ответ правильный. Так доказывают циклы.

## Сортировка — идея

Упорядочить по возрастанию/убыванию. Простейшая — выбором: каждый раз ищем минимум в остатке и ставим на своё место (тот же приём «чемпиона», что в максимуме!).

## Ключевое (записать)

- Поиск = просмотр + сравнение с образцом.
- Максимум: «чемпион» (значение или imax).
- Инвариант: что верно после каждого прохода.

## Частые ошибки

- Начинать чемпиона с 0 вместо первого элемента (массив из отрицательных сломается!).
- Сравнивать с неправильным образцом (ищем > , а пишем >= — для максимума сойдёт, для подсчёта — нет).
- Путать индекс и значение (imax — НОМЕР, a[imax] — число).

## Проверь себя

1. Найди максимум [3, 7, 5] карточками. А минимум?
2. Что лежит в imax в конце для [3, 7, 5]?
3. Сколько сравнений сделает поиск максимума в списке из 100?
