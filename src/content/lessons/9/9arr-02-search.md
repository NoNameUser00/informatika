# Поиск значения

**Линейный поиск** — просмотр массива от начала к концу и сравнение каждого элемента с образцом. Это самый простой и самый универсальный поиск.

## Поиск первого вхождения

Задача: есть ли в массиве число 5 и на каком оно месте?

```
a = [3, 7, 5, 5, 9]
n = -1              # -1 означает «не найдено»
for i in range(len(a)):
    if a[i] == 5:
        n = i
        break        # нашли первое — дальше смотреть незачем
print(n)            # 2
```

Значение `-1` как признак «не найдено» — стандартный приём: индекс не может быть отрицательным.

## Поиск всех вхождений

Если нужен не первый, а все элементы — `break` убирают и добавляют счётчик:

```
k = 0
for i in range(len(a)):
    if a[i] == 5:
        k = k + 1
print(k)            # 2
```

## Зачем нужен break

Экономит время: если значение нашлось на первом элементе из тысячи, цикл остановится сразу. Для поиска всех вхождений `break` наоборот вреден.

## Когда линейный поиск плох

Просмотр всей стопки каждый раз — простой способ, но медленный. Если массив отсортирован, нужное можно найти делением пополам (бинарный поиск): за 1000 элементов это 10 шагов вместо 1000.

| Способ | Шагов на 1000 | Когда применять |
|---|---|---|
| Линейный | до 1000 | массив не отсортирован |
| Бинарный | до 10 | массив отсортирован |

## Практическая работа

1. Дан массив `[4, 11, 7, 11, 2, 11]`, ищем 11.
2. Первое вхождение — индекс 1.
3. Всего вхождений — 3.
4. Ищем 5 — не найдено, программа выдаёт −1.
5. Напиши программу для всех трёх случаев.

## Ключевое (записать)

- Линейный поиск: просмотр от начала и сравнение с образцом.
- Признак «не найдено» — обычно −1 (индекс не бывает отрицательным).
- `break` останавливает цикл при первом нахождении.
- Бинарный поиск (10 шагов на 1000) работает только на отсортированном массиве.

## Частые ошибки

- Использовать 0 как признак «не найдено»: индекс 0 бывает (первый элемент).
- Ставить `break` там, где нужны все вхождения.
- Сравнивать `>=` вместо `==`, если ищем конкретное значение.
- Уверенно применять бинарный поиск к неотсортированному массиву: результат случайный.

## Проверь себя

1. Почему признаком «не найдено» выбирают −1, а не 0?
2. На каком индексе первое вхождение 11 в `[4, 11, 7, 11, 2, 11]`?
3. Сколько шагов нужно бинарному поиску на 1000 элементах?
