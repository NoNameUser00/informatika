# Граф: точки и связи

**Граф** — набор **вершин** (точек, объектов) и **рёбер** (связей между ними). Граф описывает то, что на плоскости рисовать неудобно: дороги, сети, родственные связи, зависимости.

Разновидности:

- **Ориентированный (орграф)** — рёбра со стрелками, направление важно.
- **Неориентированный** — стрелок нет, связь двусторонняя.
- **Взвешенный** — у каждого ребра число-вес: расстояние, цена, время.

Неориентированный граф — частный случай орграфа: если ребро заменить на два встречных, получится орграф.

## Матрица смежности

**Матрица смежности** — таблица «кто с кем связан». Строка — «откуда», столбец — «куда». Значение 1 — ребро есть, 0 — нет.

Пример цепочки 1 → 2 → 3:

```
      1  2  3
  1 [ 0  1  0 ]
  2 [ 0  0  1 ]
  3 [ 0  0  0 ]
```

Читаем: из 1 можно попасть в 2; из 2 — в 3; из 3 нельзя никуда.

Диагональ нулевая: вершина не соединена сама с собой. Если есть петля — на диагонали стоит 1.

## Весовая матрица

Когда у рёбер есть числа, вместо 1 пишут вес. Отсутствие ребра обозначают **∞** (бесконечность) — так его нельзя случайно принять за путь.

Пример дорог: A → B весом 4, A → C весом 2, C → B весом 1, B → D весом 5, C → D вестом 8:

```
      A    B    C    D
  A [ 0    4    2    ∞ ]
  B [ ∞    0    ∞    5 ]
  C [ ∞    1    0    8 ]
  D [ ∞    ∞    ∞    0 ]
```

Важно: направление в весовой матрице несимметрично. В строке A, столбец B стоит 4 (A → B), а в строке B, столбце A — ∞ (обратно идти нельзя). Это отличает орграф от неориентированного.

## Матрица или рисунок

Рисунок нагляднее для небольшого графа. Матрица удобнее, когда граф большой, надо часто отвечать «есть ли ребро A → C?» и нужна проверка на ошибку.

| Ситуация | Что удобнее |
|---|---|
| 5–8 вершин, показать связность | рисунок |
| 20+ вершин, частые запросы «есть ли ребро?» | матрица |
| Записать граф в программе | матрица |

## Ключевое (записать)

- Граф: вершины + рёбра. Орграф — со стрелками, взвешенный — с числами.
- Матрица смежности: строка «откуда», столбец «куда»; 1 — ребро, 0 — нет.
- Весовая матрица: вместо 1 вес ребра, вместо отсутствия ∞.
- В неориентированном графе матрица симметрична.

## Частые ошибки

- Читать матрицу наоборот: строка и столбец меняются местами, и ответ инвертируется.
- Ставить в весовой матрице 0 вместо ∞: путь по несуществующему ребру «стоит ноль» и выглядит самым выгодным.
- Путать неориентированный граф и орграф: в первом матрица симметрична.
- Забыть про петли на диагонали.

3. Почему отсутствие ребра в весовой матрице обозначают ∞, а не 0?
