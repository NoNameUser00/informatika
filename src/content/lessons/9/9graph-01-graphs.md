# Граф: точки и связи

**Граф** — набор **вершин** (точек) и **рёбер** (связей). Ориентированный граф (орграф): у рёбер есть направление (стрелки). **Взвешенный**: у рёбер числа-веса (расстояния, цены).

## Матрицы: граф в таблице

- **Матрица смежности**: таблица «кто с кем связан» — 1 есть ребро, 0 нет. Строка = «откуда», столбец = «куда».
- **Весовая матрица**: вместо 1 — вес ребра, отсутствие — 0 или ∞.

Пример (цепочка 1→2→3):

```
    1  2  3
1 [ 0  1  0 ]
2 [ 0  0  1 ]
3 [ 0  0  0 ]
```

## Деревья и перебор

**Дерево** — граф без циклов (как родословная). Перебор вариантов удобно рисовать деревом: каждая ветка — выбор, лист — итог.

## Подсчёт путей в направленном графе

Правило: число путей в вершину = сумма путей во все её предшественники. Идём по порядку, накапливаем:

```
A → B, A → C, B → D, C → D
путей: A=1 (старт), B=1, C=1, D = B+C = 2
Ответ: в D ведут 2 пути.
```

## Ключевое (записать)

- Вершины + рёбра (веса). Орграф — со стрелками.
- Матрица смежности: строка «от», столбец «до».
- Пути в DAG: суммируй предшественников по порядку.

## Частые ошибки

- Читать матрицу наоборот (строка/столбец!).
- Считать пути «на глаз» вместо накопления.
- Забывать стартовую вершину (= 1 путь — пустой).

## Проверь себя

1. Составь матрицу смежности цепочки 1→2→3.
2. Сколько путей в D, если в B — 2, в C — 3, и оба ведут в D?
3. Чем дерево отличается от графа?
