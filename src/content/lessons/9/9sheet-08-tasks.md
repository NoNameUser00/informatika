# Обобщение по таблицам

Урок повторения: собираем всё, что разобрали за блок, и решаем задачи целиком.

## Что нужно знать

**Структура:** книга → листы → ячейки (строки, столбцы). Шапка — первая строка с названиями, без объединений.

**Данные в ячейке:** число, текст, дата, формула. Тип определяется автоматически, но задаётся вручную через форматирование.

**Формулы:**

```
= A1 + B1              сложение
= СУММ(B2:B20)         сумма диапазона
= МИН(B2:B20)          минимум
= МАКС(B2:B20)         максимум
= СРЗНАЧ(B2:B20)       среднее
= СЧЁТЕСЛИ(B2:B100;"текст")     количество по условию
= СУММЕСЛИ(D2:D100;B2:B100;"текст")  сумма по условию
= ЕСЛИ(A2>10;"да";"нет")          ветвление
```

Разделитель аргументов — точка с запятой.

**Ссылки:** относительная (`A1`) едет при копировании, абсолютная (`$A$1`) стоит на месте, смешанная (`$A1` или `A$1`) — половина едет.

**Анализ:** сортировка переставляет строки, фильтр прячет их, условное форматирование красит.

**Визуализация:** столбчатая — сравнение, круговая — доли, график — изменение по времени.

**Моделирование:** входные → формулы → таблица; модель показывает закон.

## Разбор задачи 1

Условие: 12 учеников, баллы. Найти: средний балл, лучший, худший, количество с баллом не ниже 4.

```
СРЗНАЧ = СРЗНАЧ(B2:B13)
лучший = МАКС(B2:B13)
худший = МИН(B2:B13)
не ниже 4 = СЧЁТЕСЛИ(B2:B13;">=4")
```

Одна строка формулы вместо ручного подсчёта.

## Разбор задачи 2

Условие: магазин, продажи по товарам. Найти долю каждого товара и построить круговую диаграмму.

1. Суммируй продажи каждого товара: `СУММЕСЛИ` по названию.
2. Общий итог: `СУММ` по столбцу сумм.
3. Доля: `=сумма_товара/итог*100`, процентный формат.
4. Построй круговую диаграмму: доли одного целого — круговая корректна.

## Разбор задачи 3

Условие: температура по дням недели. Построить график, найти самый тёплый день.

График показывает изменение по времени. Максимум — `МАКС` по столбцу, день определяется по этой строке.

## Типичные ошибки на зачёте

1. **Объединённая шапка** ломает сортировку и фильтр.
2. **Запятая вместо точки с запятой** — функция не распознаётся.
3. **Текст в числовом столбце** — `СРЗНАЧ` и диаграммы считают неверно.
4. **Сортировка одного столбца** — строки разъезжаются.
5. **Круговая диаграмма по несвязанным величинам** — визуальная ложь.
6. **Отсутствие заголовка** у диаграммы.

## Ключевое (записать)

- Формулы, функции, ссылки, анализ, диаграммы, моделирование — блок пройден.
- Разделитель аргументов — точка с запятой.
- Перед сортировкой и фильтрацией проверь тип данных в столбцах.
- Диаграмму выбирают по характеру данных.

## Частые ошибки

- Считать данные, которые не являются числами (итого, заголовки внутри диапазона).
- Путать три диапазона в `СУММЕСЛИ`.
- Забыть про заголовки диаграммы и осей.

## Проверь себя

1. Назови шесть функций блока и их назначение.
2. Сколько диапазонов у `СУММЕСЛИ` и что они означают?
3. Какую диаграмму выбрать для долей, а какую для сравнения?
