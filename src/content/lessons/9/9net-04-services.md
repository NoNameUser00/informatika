# Чем люди занимаются в сети

**Интернет-сервис** — сайт или приложение, решающее задачу через браузер: не нужно устанавливать программу, нужен только доступ в сеть.

## Виды деятельности

| Деятельность | Сервисы |
|---|---|
| Поиск информации | поисковики, электронные библиотеки, справочники |
| Обучение | открытые курсы, видеолекции, тренажёры |
| Общение | мессенджеры, почта, видеозвонки |
| Творчество | онлайн-редакторы текста, таблиц, презентаций, рисования |
| Покупки | интернет-магазины, маркетплейсы, оплата услуг |
| Работа | облачные офисы, CRM, сервисы совместной работы |
| Развлечения | видеохостинги, игры, стриминг |

## Облачные хранилища

**Облачное хранилище** — файловое хранилище в интернете.

Примеры: Яндекс.Диск, Google Диск, облако в Mail.ru, файлообменники учебных организаций.

Что даёт:

- доступ с любого устройства (дома, в школе, с телефона),
- общий доступ для группы: дал ссылку — товарищ увидел файл,
- не потеряется вместе с флешкой,
- история версий: если испортил файл, можно вернуть предыдущий.

О чём помнить:

- данные хранит компания-владелец сервиса,
- бесплатный тариф часто ограничен по размеру,
- для важных данных нужна локальная копия,
- не загружай личные данные и документы в открытые сервисы.

## Средства совместной разработки документов

**Онлайн-офис** — веб-сервис для работы с документами без установки программы: текст, таблицы, презентации.

Как устроена совместная работа:

1. Создаёшь документ в облаке.
2. Открываешь доступ группе: только просмотр, редактирование или комментирование.
3. Все работают одновременно: видят изменения в реальном времени.
4. История версий помнит, кто и что внёс.

В основе многих онлайн-офисов — технологии LibreOffice (Collabora Online), поэтому приёмы те же: стили, таблицы, формулы.

Права доступа важны: «редактирование» для всех — значит каждый может испортить документ. Для контрольной работы ставят «только просмотр».

## Практическая работа

1. Создай документ в облачном хранилище.
2. Открой доступ одному однокласснику на редактирование, другому — только на просмотр.
3. Отредактируйте документ одновременно: проверь, что изменения видны сразу.
4. Найди историю версий и верни предыдущую версию файла.
5. Скачай файл локально: убедись, что копия работает без интернета.

## Ключевое (записать)

- Интернет-сервис решает задачу через браузер, без установки.
- Облачное хранилище: доступ отовсюду, общий доступ, история версий.
- Для важных данных нужна локальная копия.
- Права доступа: просмотр / комментирование / редактирование.

## Частые ошибки

- Считать облако надёжнее локального диска: сервис могут закрыть.
- Дать доступ на редактирование всем: документ испортят.
- Не скачать файл локально: без интернета работа невозможна.
- Загрузить документы с личными данными в открытый сервис.

## Проверь себя

1. Что такое интернет-сервис?
2. Какие три уровня доступа бывают к документу?
3. Почему нужна локальная копия облачного файла?
