# Готовые формулы

**Встроенные функции** — заранее написанные формулы с именем: `СУММ`, `МИН`, `МАКС`, `СРЗНАЧ`.

## Основные функции

| Функция | Что делает | Пример |
|---|---|---|
| `СУММ(диапазон)` | сумма всех чисел | `=СУММ(B2:B20)` |
| `МИН(диапазон)` | наименьшее | `=МИН(B2:B20)` |
| `МАКС(диапазон)` | наибольшее | `=МАКС(B2:B20)` |
| `СРЗНАЧ(диапазон)` | среднее арифметическое | `=СРЗНАЧ(B2:B20)` |
| `СЧЁТ(диапазон)` | количество чисел | `=СЧЁТ(B2:B20)` |
| `ЕСЛИ(условие;да;нет)` | ветвление | `=ЕСЛИ(B2>10;"много";"мало")` |

Разделитель аргументов — **точка с запятой** (в русской локали LibreOffice). В английской версии это запятая.

## Диапазон

`B2:B20` — прямоугольный участок: от ячейки B2 до B20.

Сокращения:
- `B2:B20` — все ячейки прямоугольника.
- `B2` — одна ячейка.
- `B:B` — весь столбец B.
- `B2:B20` можно задавать перетаскиванием — LibreOffice подставит адрес сам.

## Среднее арифметическое

```
СРЗНАЧ = СУММ / количество
```

Пример: числа 4, 7, 9. Сумма 20, количество 3, среднее 20 / 3 = 6,67.

Важно: `СРЗНАЧ` считает только числа, текст и пустые ячейки игнорирует. Если в диапазоне смешаны числа и текст, результат может не совпасть с ожиданием.

## Вложенные функции

Внутри одной формулы можно вызывать другие:

```
=МАКС(B2:B20) - МИН(B2:B20)
```

Это **размах** — наибольшее минус наименьшее. Показывает разброс данных.

## Практическая работа

Задание КТП: обработка больших массивов данных.

1. Возьми таблицу «Продажи» из прошлого урока.
2. Добавь столбец «Выручка» = Количество × Цена.
3. В ячейках под таблицей вычисли:
   - `=СУММ(...)` — общая выручка,
   - `=МАКС(...)` — максимальная выручка,
   - `=МИН(...)` — минимальная,
   - `=СРЗНАЧ(...)` — средняя,
   - `=МАКС(...)-МИН(...)` — размах.
4. Добавь 20 строк данных и проверь: суммы пересчитались сами?

Главный вывод: при добавлении строк формулы не нужно править — они пересчитываются автоматически. Это отличает таблицу от калькулятора.

## Ключевое (записать)

- `СУММ`, `МИН`, `МАКС`, `СРЗНАЧ`, `СЧЁТ` — встроенные функции.
- Разделитель аргументов — точка с запятой.
- `СРЗНАЧ` игнорирует текст и пустые ячейки.
- При добавлении строк формулы пересчитываются сами.

## Частые ошибки

- Ставить запятую вместо точки с запятой: функция не распознаётся.
- Брать диапазон с шапкой: текст в диапазоне ломает `СРЗНАЧ`.
- Копировать `СУММ` формулы без проверки диапазона: сумма посчитает не то.
- Делить на количество ячеек вместо количества чисел: при пустых ячейках среднее неверное.

## Проверь себя

1. Что делает `СРЗНАЧ` с пустыми ячейками внутри диапазона?
2. Как найти размах набора чисел одной формулой?
3. Что произойдёт с суммой, если добавить в таблицу новую строку?
