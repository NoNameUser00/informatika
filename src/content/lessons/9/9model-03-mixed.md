# Модели, соединяющие языки

**Смешанная (комплексная) модель** соединяет несколько видов описаний сразу: таблицу, график, формулу, схему, карту.

Реальные объекты редко описываются чем-то одним. Погода — это таблица измерений, график хода температуры, карта фронтов и формула прогноза.

## Что входит в смешанную модель

| Часть | Что даёт |
|---|---|
| Таблица | точные значения |
| График | наглядная тенденция |
| Формула | возможность пересчёта |
| Схема или карта | связи и пространственное расположение |
| Текстовое описание | качественные признаки |

Ни одна часть не заменяет остальные. Таблица даст числа, но не покажет, что кривая идёт вверх. График покажет trend, но не даст точного значения.

## Готовые компьютерные модели

Модели из разных предметных областей устроены одинаково: есть входные данные, есть правила, есть результат.

Примеры:

- **Физика** — маятник, полёт тела, столкновения.
- **Биология** — популяция: рождаемость и смертность, численность по годам.
- **Экономика** — спрос и предложение, рост вклада.
- **География** — климат, приливы.

Работать с ними одинаково:

1. Ввести или взять данные.
2. Задать начальные условия.
3. Запустить, получить результат.
4. Изменить данные, сравнить результаты — так проверяют влияние фактора.

## Модель популяции

Простейший пример: численность меняется по правилу `N = N + рождение − смертность`.

```
N = 100
рождение = 20
смертность = 12
через год: 100 + 20 − 12 = 108
```

Что покажет модель: если разность положительная, популяция растёт; если отрицательная — сокращается. Меняем рождаемость — видим, где популяция начнёт расти быстрее.

Это тот же приём, что и с тормозным путём: одиночные числа ничего не значат, а **ряд** значений показывает закон.

## Практическая работа

Задание КТП: работа с готовыми компьютерными моделями из различных предметных областей.

1. Открой готовую модель (симулятор) по выбору учителя.
2. Определи, какие величины на неё влияют (входные параметры).
3. Запусти с начальными условиями, запиши результат.
4. Измени один параметр, запусти снова, сравни.
5. Сформулируй вывод: какой фактор сильнее влияет на результат.

## Ключевое (записать)

- Смешанная модель соединяет таблицу, график, формулу, схему.
- Каждая часть даёт своё: таблица — числа, график — тенденцию.
- С готовыми моделями работают одинаково: вход → запуск → результат → изменение входа.
- Меняя один параметр, проверяют его влияние на результат.

## Частые ошибки

- Считать, что таблица заменяет график: она не показывает тенденцию.
- Менять несколько параметров сразу: непонятно, что повлияло.
- Сделать один запуск и объявить вывод: нужен ряд значений.
- Путать управляющий параметр с результатом.

## Проверь себя

1. Какие виды описаний входят в смешанную модель?
2. Почему одного запуска модели недостаточно для вывода?
3. Как проверить влияние одного фактора на результат?
