# Данные нужно увидеть

Таблица из 50 строк читается плохо. Диаграмма показывает **главное** за секунду.

## Виды диаграмм

| Вид | Для чего | Правило |
|---|---|---|
| **Столбчатая** (гистограмма) | сравнение величин | площади стран, продажи по месяцам |
| **Круговая** | доли целого | структура: пашня / луг / лес |
| **Линейчатая (график)** | изменение по времени | температура по дням, продажи по неделям |
| **С накоплением** (ярусная) | вклад частей в сумму | структура расходов |

**Главное правило выбора:** круговая диаграмма — только для долей одного целого. Если величины не связаны и не дают 100 %, круговая будет ложью.

Пример ошибки: «площади России, Китая, США» — это несвязанные величины, круговая покажет бессмысленные доли. Здесь нужна столбчатая.

## Как построить

1. Выдели данные: столбцы-категории и столбцы-значения (вместе с заголовками).
2. Вставка → Диаграмма.
3. Выбери тип.
4. Пройди мастера: тип, данные, подписи элементов.
5. Заголовок и подпись обязательны.

Диаграмма связана с таблицей: поменял число — диаграмма перестроилась сама. Это удобно: не надо перерисовывать.

## Подписи и читаемость

1. **Заголовок диаграммы** — что показывает.
2. **Подписи данных** — числа у столбцов, если их мало.
3. **Легенда** — если серий несколько.
4. **Цвета** — контрастные, не одинаковые для разных серий.
5. Не смешивай 15 цветов: глаз не разберёт.

Диаграмма без заголовка — потерянная диаграмма.

## Практическая работа

Задание КТП: построение диаграмм и графиков в электронных таблицах.

1. Возьми таблицу «Продажи».
2. Построй **круговую** диаграмму долей по товарам (сумма продаж каждого товара).
3. Построй **столбчатую** диаграмму: продажи по месяцам.
4. Построй **график**: как менялась выручка по дням.
5. Добавь заголовки и подписи ко всем трём.
6. Поменяй число в таблице — проверь, что диаграммы обновились.

## Ключевое (записать)

- Столбчатая — сравнение; круговая — доли целого; график — изменение по времени.
- Круговая только для долей, дающих 100 %; несвязанные величины — столбчатая.
- Диаграмма связана с таблицей и обновляется сама.
- Заголовок и подписи обязательны.

## Частые ошибки

- Строить круговую по несвязанным величинам.
- Оставлять диаграмму без заголовка: непонятно, что это.
- Использовать много похожих цветов.
- Забыть про подписи осей — без них диаграмма не читается.

## Проверь себя

1. Какая диаграмма покажет долю пашни от всех угодий? А сравнение площадей трёх стран?
2. Что произойдёт с диаграммой, если изменить число в таблице?
3. Почему заголовок диаграммы обязателен?
