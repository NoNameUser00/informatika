# Суммируем и считаем

Задачи этого типа решаются **одним проходом** по массиву: смотрим каждый элемент и накапливаем.

## Сумма

```
s = 0
for x in a:
    s = s + x
```

Правило: заводим накопитель `s = 0` **до** цикла, внутри прибавляем элемент. Иначе результат потеряется.

Для `[3, 7, 5]`: 0 + 3 = 3, 3 + 7 = 10, 10 + 5 = 15.

## Количество

Считаем элементы, удовлетворяющие условию:

```
k = 0
for x in a:
    if x > 5:
        k = k + 1
```

Для `[3, 7, 5]`: 3 не подходит, 7 подходит, 5 не подходит → k = 1.

Если нужно посчитать всё подряд, условие не нужно — достаточно `len(a)`.

## Среднее арифметическое

```
s = 0
for x in a:
    s = s + x
sr = s / len(a)
```

Для `[3, 7, 5]`: сумма 15, количество 3, среднее 15 / 3 = 5.

Среднее = сумма / количество. Не дели на `s` (это сумма, а не количество).

## Ловушка: пустой массив

Если массив пуст, `len(a) = 0`, и деление на ноль даст ошибку.

```
if len(a) > 0:
    sr = s / len(a)
else:
    sr = 0
```

## Один проход — три результата

Сумму, количество и максимум можно найти за один проход, если нужны все три:

```
s = 0
k = 0
for x in a:
    s = s + x
    if x > 0:
        k = k + 1
```

Один проход по 1000 элементов дешевле трёх.

## Практическая работа

1. Дан массив `[12, 7, 25, 3, 18, 9]`.
2. Найди сумму: 12 + 7 + 25 + 3 + 18 + 9 = 74.
3. Найди количество чисел больше 10: 12, 25, 18 → 3.
4. Найди среднее: 74 / 6 = 12,33.
5. Напиши программу и проверь результат.

## Ключевое (записать)

- Накопитель (`s = 0`, `k = 0`) заводим **до** цикла.
- Сумма: прибавляем каждый элемент. Количество: считаем по условию.
- Среднее = сумма / количество.
- Пустой массив: деление на ноль — проверяй `len(a) > 0`.

## Частые ошибки

- Обнулять накопитель **внутри** цикла: результат будет последним элементом, а не суммой.
- Делить сумму на сумму вместо количества.
- Забыть проверить пустой массив.
- Считать количество, не задав `k = 0` до цикла.

## Проверь себя

1. Где заводится накопитель суммы — до цикла или внутри?
2. Как найти количество элементов больше 10?
3. Чему равно среднее для `[12, 7, 25, 3, 18, 9]`?
