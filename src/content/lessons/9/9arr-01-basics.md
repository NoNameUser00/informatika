# Массив — это список (Python: list)

**Массив** — пронумерованный набор однотипных значений. В Python — обычный список: `a = [3, 7, 5]`. Номер элемента — **индекс**, счёт с НУЛЯ: `a[0]` — первый!

## Ввод, вывод, доступ

```
a = [3, 7, 5]     # объявление сразу со значениями
print(a[0])       # 3 — первый элемент
print(len(a))     # 3 — длина списка
```

## Суммы, количества, средние — одним проходом

```
s = 0
for x in a:       # перебираем элементы
    s = s + x     # накапливаем сумму
print(s)          # 15
```

Среднее: сумма / количество (`s / len(a)`). Количество «хороших» — счётчик с условием внутри.

## Ключевое (записать)

- Массив (список): индекс с 0, длина — len().
- Сумма: накопитель + перебор. Среднее = сумма / длина.
- Счётчик с условием — для «сколько подходит».

## Частые ошибки

- Индекс с 1 вместо 0 (a[3] при длине 3 — ошибка!).
- Забывать обнулить накопитель перед циклом.
- Делить среднее на длину ПУСТОГО списка.
