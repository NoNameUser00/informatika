# Вспомогательные алгоритмы

Знакомые конструкции — **следование**, **ветвление**, **повторение**. Сегодня учимся строить алгоритм из них и выносить повторяющиеся куски в отдельную процедуру.

## Вспомогательный алгоритм

**Вспомогательный алгоритм (процедура)** — именованный кусок кода, который можно вызвать по имени из любого места основного алгоритма.

Зачем: если один и тот же кусок повторяется трижды, достаточно написать его один раз. Программа становится короче, а исправлять ошибку — в одном месте, а не в трёх.

В Python это функция:

```
def площадь(a, b):
    return a * b

print(площадь(3, 4))   # 12
```

## Правила проектирования

1. **Один вход — один выход.** Функция получает данные (параметры) и возвращает результат.
2. **Имя — глагол или вопрос.** `площадь`, `сумма_элементов`, `среднее` — понятно, что делает.
3. **Функция не должна ничего выводить сама.** Печать — дело вызывающего кода, иначе функцию нельзя переиспользовать.

## Пример: управление исполнителем

Задача: робот проходит коридор и закрашивает клетки. Повторяющиеся куски — «шаг вперёд с закрашиванием» — выносим в процедуру.

```
алг ЗакраситьКоридор
нач
  | вперед_и_закрась
  | вперед_и_закрась
  | вперед_и_закрась
  | вперед_и_закрась
кон

процедура вперед_и_закрась
нач
  | вперед
  | закрась
кон
```

Программа читается как план: «сделай это четыре раза». Само действие описано один раз.

В Python то же самое:

```
def вперед_и_закрась():
    вперед()
    закрась()

for i in range(4):
    вперед_и_закрась()
```

## Комбинирование конструкций

В одном алгоритме встречаются все три:

```
# Цикл по всем клеткам + ветвление «красить или нет»
for i in range(10):
    if клетка_свободна(i):
        закрасить(i)
```

Так описывается, например, обход поля с условиями или подсчёт элементов, удовлетворяющих условию.

## Практическая работа

Задание КТП: программы с вспомогательными алгоритмами для управления исполнителями (Робот, Черепаха, Чертёжник).

1. Нарисуй квадрат 3 × 3 движением вперёд и поворотом направо на 90°.
2. Вынеси «поворот на 90°» в процедуру.
3. Проверь: вызвал процедуру четыре раза — получил квадрат.

## Ключевое (записать)

- Вспомогательный алгоритм — именованный кусок кода, вызываемый по имени.
- У функции: параметры (вход) и результат (выход).
- Функция не печатает сама — печать в вызывающем коде.
- Повтор кода → одна функция, а не три копии.

## Частые ошибки

- Сделать три одинаковых куска вместо одной функции: правильно работает, но чинить надо в трёх местах.
- Забыть `return`: функция посчитала, но ничего не вернула.
- Смешать кириллицу и латиницу в имени (`площадь` и `площадь` — разные имена!).
