# Функции с условием

Прежде чем сортировать, научимся считать по условию — это то, ради чего данные и собирают.

**Функции с условием** берут не весь диапазон, а только подходящие ячейки:

| Функция | Что делает | Пример |
|---|---|---|
| `СЧЁТЕСЛИ(диапазон; условие)` | количество подходящих | `=СЧЁТЕСЛИ(B2:B100;"Майский")` |
| `СУММЕСЛИ(диапазон_сумм; диапазон; условие)` | сумма подходящих | `=СУММЕСЛИ(D2:D100;B2:B100;"Майский")` |
| `СРЗНАЧЕСЛИ(диапазон; условие)` | среднее подходящих | `=СРЗНАЧЕСЛИ(D2:D100;"Майский")` |

Обрати внимание на структуру `СУММЕСЛИ`: **три** диапазона — что суммировать, где смотреть, что считать условием. Перепутать порядок — самая частая ошибка.

Пример из учебника: 1000 учеников, районы, баллы. Вопрос «сколько учеников из Майского района?» — одна формула `СЧЁТЕСЛИ`, а не перебор 1000 строк вручную.

Условие можно уточнить: `">=4"` (балл не меньше 4), `"<>Майский"` (не из Майского).

## Сортировка

**Сортировка** упорядочивает строки по значениям столбца: по возрастанию, по убыванию или по алфавиту.

Как сделать:

1. Поставь курсор в любую ячейку таблицы.
2. Данные → Сортировка.
3. Выбери столбец и направление.
4. Обязательно проверь галочку «Автоматически распознать ячейки с заголовками» — иначе первая строка уедет в данные.

Зачем: после сортировки видно лидера, последнего, выбросы. Ученики по баллам, становится видно, кто первый, кто последний, где провал в середине.

## Главная ловушка сортировки

Сортировать **только один столбец** нельзя — строки разъедутся, и данные станут бессмысленными.

Неправильно: выделил столбец «Баллы» → отсортировал → теперь балл одного ученика, а фамилия другого.

Правильно: сортируй **диапазон** (всю таблицу) либо с включённой галочкой распознавания заголовков. LibreOffice тогда переставит строки целиком.

## Практическая работа

Задание КТП: сортировка данных в выделенном диапазоне.

1. Возьми таблицу «Продажи».
2. Добавь функциями с условием: сколько строк по каждому товару, сумма по каждому товару.
3. Отсортируй всю таблицу по столбцу «Сумма» по убыванию.
4. Проверь: фамилии и даты остались на своих местах (то есть строки целые)?
5. Отсортируй по дате по возрастанию.

## Ключевое (записать)

- `СЧЁТЕСЛИ`, `СУММЕСЛИ`, `СРЗНАЧЕСЛИ` — агрегаты с условием.
- У `СУММЕСЛИ` три диапазона: что суммировать, где смотреть, что считать условием.
- Сортировать надо диапазон, а не один столбец.
- При сортировке проверяй галочку распознавания заголовков.

## Частые ошибки

- Считать тысячи строк вручную вместо одной функции.
- Сортировать один столбец — строки разъезжаются, данные портятся.
- Путать порядок аргументов в `СУММЕСЛИ`.
- Забыть про заголовки: строка заголовков уезжает в данные.

## Проверь себя

1. Чем `СЧЁТЕСЛИ` отличается от `СУММЕСЛИ`?
2. Сколько диапазонов принимает `СУММЕСЛИ` и что они означают?
3. Что произойдёт, если отсортировать только столбец «Баллы»?
