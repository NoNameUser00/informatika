# Функции с условием

- **СЧЁТЕСЛИ (COUNTIF)**: сколько ячеек диапазона подходят под условие.
- **СУММЕСЛИ (SUMIF)**: сумма подходящих.
- **СРЗНАЧЕСЛИ (AVERAGEIF)**: среднее подходящих.
- Пример учебника: 1000 учеников, районы, баллы — «сколько из Майского?» считается одной функцией, а не вручную!

## Сортировка, фильтр, диаграммы

- **Сортировка**: упорядочить строки по столбцу (баллы по убыванию — и виден лидер).
- **Фильтр**: показать только подходящие строки (только свой район).
- **Диаграммы**: круговая — доли целого (структура угодий); столбчатая (гистограмма) — сравнение величин (площади стран); с накоплением (ярусная) — вклад частей в сумму.

## Численное моделирование

Формулы + протягивание = модель: меняешь входные — таблица пересчитывает всё. Тысячи строк считаются мгновенно — вручную так не выйдет.

## Ключевое (записать)

- СЧЁТЕСЛИ/СУММЕСЛИ/СРЗНАЧЕСЛИ — агрегаты с условием.
- Сортировка упорядочивает, фильтр прячет лишнее.
- Круговая — доли, столбчатая — сравнение, ярусная — вклады.

## Частые ошибки

- Считать тысячи строк вручную вместо одной функции.
- Строить круговую по несвязанным величинам (она — только про доли!).
- Сортировать один столбец без расширения диапазона (строки разъедутся!).

## Проверь себя

1. Чем СЧЁТЕСЛИ отличается от СУММЕСЛИ?
2. Какая диаграмма покажет долю пашни? А сравнение площадей стран?
3. Что сломается, если отсортировать только столбец баллов?
