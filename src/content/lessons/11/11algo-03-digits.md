# Целочисленная арифметика

## Две операции для цифр

- `n % 10` — **остаток от деления на 10** = последняя цифра числа.
- `n // 10` — **целая часть от деления на 10** = число без последней цифры.

Эти две операции позволяют разбирать число по цифрам и собирать обратно.

## Пример разбора числа

Число `n = 9575`. Последовательность `n % 10`, затем `n // 10`:

| Шаг | `n % 10` (цифра) | `n // 10` (остаток числа) |
|---|---|---|
| 1 | 5 | 957 |
| 2 | 7 | 95 |
| 3 | 5 | 9 |
| 4 | 9 | 0 |

Цифры числа: **5, 7, 5, 9**.

## Программа: сумма цифр числа

```
n = int(input())
s = 0
while n > 0:
    s = s + n % 10
    n = n // 10
print(s)
```

Для `n = 9575`: s = 5 → 12 → 17 → **26**.

## Цифры числа в другой системе счисления

**Число в системе счисления с основанием P** — это последовательность цифр, соединённых остатками от деления на P:

- `n % P` — последняя цифра в системе счисления с основанием P;
- `n // P` — число без последней цифры.

### Пример в двоичной системе (P = 2)

`n = 25`.

| Шаг | `n % 2` (цифра) | `n // 2` |
|---|---|---|
| 1 | 1 | 12 |
| 2 | 0 | 6 |
| 3 | 0 | 3 |
| 4 | 1 | 1 |
| 5 | 1 | 0 |

Цифры от младшей к старшей: 1, 0, 0, 1, 1. Читаем **с конца**: **11001₂**.

Проверка: 16 + 8 + 1 = 25 ✓

### Пример в восьмеричной системе (P = 8)

`n = 100`. `100 % 8 = 4`, `100 // 8 = 12`. Далее `12 % 8 = 4`, `12 // 8 = 1`, затем `1 % 8 = 1`.

Цифры от младшей: 4, 4, 1. Читаем с конца: **144₈**. Проверка: 64 + 32 + 4 = 100 ✓

## Программа: перевод числа в систему с основанием P

```
n = int(input())
P = 8
digits = ''
while n > 0:
    digits = str(n % P) + digits
    n = n // P
print(digits)
```

Обрати внимание на порядок: цифры накапливаются **в начало** строки, чтобы после чтения с конца получилось правильное число.

Для `n = 100`, `P = 8`: на каждом шаге добавляем цифру в начало → получаем «144».

## Число поразрядно в системе счисления с основанием P

Если дана запись числа в системе счисления с основанием P, её значение считают по формуле развёрнутой формы: для цифр `d_k … d_1 d_0` в системе счисления с основанием P:

```
N = d_k · P^k + … + d_1 · P^1 + d_0 · P^0
```

## Ключевое (записать)

- `n % 10` — последняя цифра; `n // 10` — без последней цифры.
- Для системы счисления с основанием P: `n % P` и `n // P`.
- Цифры при разборе идут от младшей к старшей; читать надо с конца.
- При переводе цифры накапливаем в начало строки.

## Частые ошибки

- Читать цифры с начала, а не с конца.
- Восстанавливать число в неправильном порядке: не получается.
- Использовать `%` вместо `//` для убирания цифры.
- Для основания больше 10 использовать `%` — появятся цифры больше 9 (нужны буквы A–F).
