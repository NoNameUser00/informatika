# Запросы к базе

## Запрос на выборку

**Запрос** — обращение к базе с требованием вернуть нужные данные. **Запрос на выборку** — самый частый: выбрать записи по условию и показать нужные столбцы.

В интерфейсе базы данных условие задаётся визуально: выбираем таблицу, столбцы, условие.

## Запросы в табличном процессоре

В LibreOffice Calc есть режим работы с источником данных. Проще использовать возможности, знакомые из таблиц:

- **фильтр по диапазону** — оставить строки, где поле удовлетворяет условию;
- **сводная таблица** — сгруппировать и посчитать;
- **формулы** — сослаться на столбцы и вычислить.

## SQL: язык запросов

**SQL** (Structured Query Language) — стандартный язык работы с реляционными базами данных.

Основная команда выборки:

```sql
SELECT столбцы
FROM таблица
WHERE условие;
```

Примеры:

```sql
SELECT фамилия, класс
FROM ученики
WHERE класс = '11А';

SELECT *
FROM блюда
WHERE калорийность < 300
ORDER BY калорийность DESC;
```

Ключевые слова:

| Ключевое слово | Что делает |
|---|---|
| `SELECT` | выбрать столбцы |
| `FROM` | указать таблицу |
| `WHERE` | условие отбора |
| `ORDER BY` | сортировка |
| `ASC` / `DESC` | по возрастанию / убыванию |
| `GROUP BY` | группировка |
| `COUNT`, `SUM`, `AVG` | подсчёт, сумма, среднее |
| `LIKE` | поиск по образцу |

## Запрос к нескольким таблицам

Данные лежат в разных таблицах — их надо соединить. В SQL это делает `JOIN`.

```sql
SELECT ученики.фамилия, блюда.название
FROM поставки
JOIN ученики ON поставки.номер = ученики.номер
JOIN блюда ON поставки.код = блюда.код;
```

Принцип: соединяем по **внешним ключам** — по тем полям, которые ссылаются друг на друга.

## Практическая работа

Задание КТП: работа с готовой базой данных — заполнение, поиск, сортировка и фильтрация записей, запросы на выборку.

1. Открой готовую базу (например, SQLite, LibreOffice Base или Google Sheets как источник).
2. Заполни базу данными: не менее 10 записей в каждой таблице.
3. **Поиск**: выведи учеников 11 класса.
4. **Сортировка**: расположи блюда по калорийности по убыванию.
5. **Фильтрация**: покажи только блюда, где калорийность меньше 300.
6. **Запрос на выборку**: выведи фамилию ученика и название блюда (соедини две таблицы).
7. **Подсчёт**: сколько записей у каждого ученика (группировка с подсчётом).

## Ключевое (записать)

- Запрос — обращение к базе; выборка — самая частая.
- `SELECT … FROM … WHERE …` — основа выборки.
- `ORDER BY` сортирует, `GROUP BY` группирует, `COUNT`/`SUM`/`AVG` считают.
- `JOIN` соединяет таблицы по внешним ключам.

## Частые ошибки

- Забыть условие `WHERE` — выводится вся база.
- Соединить таблицы не по тем полям: пустой результат или дубли.
- Использовать `SELECT *` в рабочем запросе: выводит лишние столбцы.
- Не указать тип данных: текст с числами смешивается и ломает сравнение.
