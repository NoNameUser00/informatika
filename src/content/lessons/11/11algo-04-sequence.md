# Числовые последовательности

**Числовая последовательность** — упорядоченная последовательность чисел: `a₁, a₂, …, aₙ`.

## Количество элементов

Количество элементов `n`. В программе — `len(a)` для списка.

## Сумма элементов

```
s = 0
for i in range(n):
    s = s + a[i]
print(s)
```

Для `[3, 7, 5, 2]`: 0 + 3 = 3, + 7 = 10, + 5 = 15, + 2 = **17**.

## Произведение элементов

```
p = 1
for i in range(n):
    p = p * a[i]
print(p)
```

Для `[3, 7, 5, 2]`: 1 · 3 = 3, · 7 = 21, · 5 = 105, · 2 = **210**.

**Начальное значение произведения — 1, а не 0!** Если начать с нуля, произведение любого набора будет нулём.

## Количество элементов с заданным свойством

```
k = 0
for i in range(n):
    if a[i] > 5:
        k = k + 1
```

Для `[3, 7, 5, 2]`: подходят 7 и 5 → **2**.

## Одновременно несколько величин

Чтобы не делать несколько проходов, накапливаем всё за один:

```
s = 0
p = 1
k = 0
for i in range(n):
    s = s + a[i]
    p = p * a[i]
    if a[i] % 2 == 0:
        k = k + 1
```

Один проход вместо трёх — и программа короче.

## Формулы и разряд

Часто эти величины вычисляются по формулам, например сумма арифметической прогрессии:

```
S = (a₁ + aₙ) · n / 2
```

Но прямой подсчёт циклом надёжнее: работает для любой последовательности.

## Практическая работа

Задание КТП: разработка и реализация алгоритмов обработки числовой последовательности.

1. Возьми последовательность из 8–10 чисел.
2. Вычисли сумму элементов — найди результат вручную и сравни с программой.
3. Вычисли произведение.
4. Посчитай количество положительных, отрицательных и нулевых элементов.
5. Найди сумму и количество элементов, удовлетворяющих условию (например, чётных).
6. Сделай всё за один проход по массиву.
7. Проверь на последовательности, где есть ноль и отрицательные числа.

## Ключевое (записать)

- Сумма: накопитель `s = 0`, прибавляем каждый элемент.
- Произведение: накопитель `p = 1`, умножаем каждый элемент.
- Количество по условию: счётчик `k = 0`, увеличиваем при выполнении условия.
- Несколько величин считают за один проход.

## Частые ошибки

- Начинать произведение с 0: результат всегда 0.
- Обнулять накопитель внутри цикла: теряется результат.
- Забыть про нули и отрицательные числа при проверке.
- Делать несколько проходов вместо одного: программа длиннее и медленнее.

## Проверь себя

1. Почему произведение считают с начального значения 1?
2. Как за один проход найти сумму и количество?
3. Проверь на последовательности из трёх элементов каждый из видов.
