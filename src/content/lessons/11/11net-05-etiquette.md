# Поведение в сети и проверка информации

## Сетевой этикет

**Сетевой этикет** — правила поведения в киберпространстве. Основываются на обычном этикете: уважение к другому человеку.

Правила:

1. **Представляйся**, если пишешь незнакомому.
2. **Отвечай** на сообщения — не игнорируй.
3. **Не груби**: спор веди по существу, без оскорблений.
4. **Не спамь** повторяющимися рассылками.
5. **Не выкладывай личные данные**: адрес, телефон, фото документов, геометки.
6. **Уважай чужие авторские права**: картинка из сети не значит «можно использовать».
7. **Помни, что интернет не анонимен**: написанное можно найти спустя годы.

## Проблема подлинности информации

**Фейк** — ложная информация, выданная за настоящую. Распространение фейков — серьёзная проблема: они вызывают панику, влияют на решения, портят репутацию.

Признаки недостоверной информации:

- срочность и категоричность («ПРЯМО СЕЙЧАС», «ВСЕ ДОЛЖНЫ»);
- сенсационность, страх, агрессия;
- отсутствие источника или автора;
- «правдоподобные» цифры без ссылки;
- требование сразу распространить: «перешли друзьям».

## Как проверить источник

1. **Кто автор?** Материал без автора — подозрителен.
2. **Когда опубликовано?** Старое может быть неверным.
3. **Подтверждают ли источники друг друга?** Пять сайтов с одной ошибкой не делают её правдой.
4. **Есть ли ссылка на первоисточник?**

Серьёзные источники: научные статьи, сайты организаций, материалы вузов и библиотек.

## Язык поисковых запросов

Поисковик понимает операторы — это логика из 8 класса:

| Оператор | Смысл | Пример |
|---|---|---|
| `AND` | оба слова | `реляционная база данных AND проектирование` |
| `OR` | хотя бы одно | `LibreOffice OR OpenOffice` |
| `-` | убрать мусор | `Python -джава` |
| `"..."` | точная фраза | `"язык гипертекстовой разметки"` |
| `site:` | внутри сайта | `site:edu.ru SQL` |
| `filetype:` | тип файла | `методичка filetype:pdf` |

## Практическая работа

Задание КТП: язык поисковых запросов.

1. Найди три источника по теме своего урока, используя `"..."` и `site:`.
2. Найди три источника, исключив мусорный запрос, используя `-`.
3. Найди материалы определённого типа через `filetype:`.
4. Для каждого источника запиши: автор, дата, адрес, тип ресурса.
5. Разбери два примера фейков, найди признаки подделки.
6. Выбери два лучших источника и обоснуй выбор.

## Ключевое (записать)

- Сетевой этикет = обычный этикет плюс учёт того, что интернет не анонимен.
- Признаки фейка: срочность, сенсационность, отсутствие источника.
- Проверка источника: автор, дата, первоисточник, подтверждение другими.
- Операторы `AND`, `OR`, `-`, `"..."`, `site:`, `filetype:` работают как логика.

## Частые ошибки

- Искать по одному слову: выдача из миллионов результатов.
- Верить первому результату без проверки.
- Распространять непроверенную информацию.
- Перепутать `OR` и `AND` в запросе.

## Проверь себя

1. Назови три признака фейка.
2. Что делает оператор `-` в поисковом запросе?
3. По каким четырём критериям проверяют источник?
