# Показываем результаты

## Выбор диаграммы под задачу

| Что показываем | Диаграмма |
|---|---|
| Изменение показателя по времени | график (линейная) |
| Сравнение величин по категориям | столбчатая |
| Доли целого (сумма 100 %) | круговая |
| Вклад частей в сумму | с накоплением (ярусная) |
| Связь двух величин | диаграмма разброса (XY) |
| Распределение значений по интервалам | гистограмма |

**Главное правило выбора**: столбчатая — сравнение, круговая — доли, график — время, диаграмма разброса — связь двух величин.

Диаграмма разброса (XY) нужна для анализа корреляции: по оси X — одна величина, по оси Y — другая. Облако точек покажет связь.

## Оформление диаграммы

1. **Заголовок** — что показывает (без него диаграмма потеряна).
2. **Подписи осей** — с единицами измерения.
3. **Подписи данных** — числа у точек, если их немного.
4. **Легенда** — если серий несколько.
5. **Источник данных** — обязательно для аналитической работы.

## Как диаграмма искажает данные

График можно обмануть:

1. **Обрезанная ось.** Если начать шкалу не с нуля, разница 10 и 12 будет выглядеть огромной.
2. **Неудачный масштаб.** Слишком мелкий масштаб скрывает изменения, слишком крупный превращает шум в «трагедию».
3. **Линия без маркеров** прячет отдельные значения.
4. **Лишние трёхмерные объёмы** искажают площади.

Правило: для сравнения величин ось начинаем с нуля; для показа тренда — можно обрезать, но подписать это.

## График функции

График показывает, где функция растёт, где падает, где имеет максимум и минимум — то, что не видно по таблице.

Пример: график продаж по месяцам сразу покажет пик в декабре и провал в летние месяцы.

## Практическая работа

Задание КТП: наглядное представление результатов статистической обработки в виде диаграмм.

1. Возьми обработанный на прошлом уроке набор данных.
2. Построй **график** изменения показателя по времени — найди максимум и минимум.
3. Построй **столбчатую** диаграмму для сравнения по категориям.
4. Построй **круговую** диаграмму долей, если сумма равна 100 %.
5. Подпиши заголовок, оси, единицы, источник.
6. Построй диаграмму разброса для двух связанных величин.
7. Проверь: оси подписаны, заголовки есть, масштаб честный.

## Ключевое (записать)

- Столбчатая — сравнение, круговая — доли, график — время, разброса — связь.
- Заголовок, подписи осей с единицами и источник обязательны.
- Ось для сравнения начинается с нуля.
- Диаграмма может искажать данные — настройки в руках автора.

## Частые ошибки

- Строить круговую по несвязанным величинам, не дающим 100 %.
- Обрезать ось для сравнения: разница выглядит больше, чем есть.
- Забыть заголовок и единицы измерения.
- Не указать источник данных.
- Перегрузить диаграмму 15 цветами.

## Проверь себя

1. Какую диаграмму выбрать для долей, а какую для связи двух величин?
2. Почему ось сравнения начинают с нуля?
3. Что обязательно должно быть на любой диаграмме?
