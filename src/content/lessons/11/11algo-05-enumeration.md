# Решаем задачи перебором

## Что такое перебор

**Перебор** — метод решения задачи, при котором проверяются все возможные варианты решения.

Первый вопрос всегда один: **сколько всего вариантов?** Если их не слишком много — перебор работает.

## Вложенные циклы

Когда нужно проверить сочетания двух объектов, циклы вкладывают:

```
for i in range(n):
    for j in range(m):
        # проверить пару (i, j)
```

Тогда проверяется n · m сочетаний.

## Виды перебора

**Перебор значений переменной.** Например: при каких целых x уравнение `x² − 5x + 6 = 0` равно нулю? Перебираем x от −20 до 20 и проверяем.

Проверка: x = 2 → 4 − 10 + 6 = 0 → корень. x = 3 → 9 − 15 + 6 = 0 → корень. Ответ: **x = 2 и x = 3**.

**Перебор сочетаний.** Например: трехзначное число, у которого сумма первой и последней цифр равна средней.

```
for a in range(1, 10):
    for b in range(10):
        c = a + b
        if c <= 9:
            print(100*a + 10*b + c)
```

Ответ: числа вида `aba` — 101, 121, …, 989 (девять чисел).

**Перебор подмножеств.** Для множества из n элементов число подмножеств равно 2ⁿ. При n = 10 это 1024 — перебор выполним; при n = 20 уже миллион.

## Сложность перебора

Перебор всегда медленный, растёт очень быстро:

| n | Число проверок |
|---|---|
| 10 | 10 |
| 100 | 100 |
| 1000 | 1000 |
| 10 000 | 10 000 |

Для пар: n². Для троек: n³. При n = 1000 это миллиард — недопустимо.

Вывод: перебор подходит только для малых n. Иначе нужен алгоритм с меньшим ростом.

## Как сократить перебор

1. **Ограничить диапазон** заранее, а не перебирать «с запасом».
2. **Проверять условие по ходу**, а не в конце.
3. **Выходить при нахождении первого** решения, если нужно одно.

## Практическая работа

Задание КТП: разработка и реализация алгоритмов решения задач методом перебора.

1. Реши уравнение `x² − 5x + 6 = 0` перебором в диапазоне [−20, 20].
2. Найди все трёхзначные числа, у которых сумма первой и последней цифр равна средней.
3. Найди числа от 1 до 100, которые делятся и на 3, и на 5.
4. Оцени число проверок: для 100 чисел — сколько пар? Для 1000?
5. Построй перебор в программе и сравни с ручным подсчётом.

## Ключевое (записать)

- Перебор проверяет все возможные варианты решения.
- Для сочетаний двух объектов — вложенные циклы, n · m проверок.
- Перебор выполним только при малом n.
- Диапазон задаём заранее, а не «с запасом».

## Частые ошибки

- Перебирать слишком широкий диапазон: время растёт линейно.
- Считать, что перебор подходит для больших данных.
- Забыть проверить все пары: вложенные циклы должны быть оба.
- Не оценить число проверок заранее — программа «зависнет».
