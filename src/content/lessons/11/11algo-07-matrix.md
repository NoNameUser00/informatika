# Матрицы

**Двумерный массив (матрица)** — таблица чисел, у которой каждый элемент задаётся **двумя индексами**: номером строки и номером столбца.

```
a[0][0]  a[0][1]  a[0][2]
a[1][0]  a[1][1]  a[1][2]
a[2][0]  a[2][1]  a[2][2]
```

## Создание в Python

```
a = [[1, 2, 3],
     [4, 5, 6],
     [7, 8, 9]]
```

`a[0]` — первая строка (список), `a[0][1]` — элемент второй строки? Нет: `a[0][1]` — второй элемент **первой** строки, то есть 2.

## Размеры матрицы

```
n = len(a)          # число строк
m = len(a[0])       # число столбцов
```

## Заполнение и вывод

```
n = 3
m = 3
a = [[0] * m for _ in range(n)]

for i in range(n):
    for j in range(m):
        a[i][j] = i * m + j + 1

for i in range(n):
    for j in range(m):
        print(a[i][j], end='  ')
    print()
```

Важно: `[0] * m` внутри `for` создаёт **новый** список на каждой строке. Написать `a = [[0] * m] * n` — ошибка: строки станут ссылками на один список, и изменение одной затронет все.

## Главная диагональ

Элементы, у которых индексы равны: `a[0][0]`, `a[1][1]`, `a[2][2]`.

```
s = 0
for i in range(n):
    s = s + a[i][i]
```

## Вторичная диагональ

Элементы, у которых сумма индексов равна n − 1: `a[0][n-1]`, `a[1][n-2]`, …

```
s = 0
for i in range(n):
    s = s + a[i][n - 1 - i]
```

## Обход в столбцы

```
for j in range(m):
    for i in range(n):
        print(a[i][j], end=' ')
    print()
```

## Типовые задачи

| Задача | Идея |
|---|---|
| Сумма всех элементов | двойной цикл, всё прибавляем |
| Сумма элементов строки | цикл по строке |
| Максимум в строке | сравниваем элементы строки |
| Сумма главной диагонали | индексы равны |
| Количество положительных | двойной цикл со счётчиком |
| Максимум и его позиция | запоминаем значение и индексы |

## Ключевое (записать)

- Матрица: элемент задаётся двумя индексами `a[i][j]`.
- Число строк `len(a)`, число столбцов `len(a[0])`.
- Главная диагональ: `a[i][i]`; вторичная: `a[i][n−1−i]`.
- Строки создавать как `[0] * m for _ in range(n)`, а не `[0] * m] * n`.

## Частые ошибки

- Путать строку и столбец при обходе.
- Создавать строки как `[0] * m] * n`: все строки станут одной.
- Обращаться к `a[i][j]` при выходе за границы: IndexError.
- Для квадратной матрицы использовать `len(a)` для столбцов — работает, только если она действительно квадратная.
