# HTML

## Что такое HTML

**HTML** (HyperText Markup Language) — язык разметки, задающий структуру веб-страницы.

HTML **не язык программирования**: в нём нет циклов и вычислений. Он только размечает: «здесь заголовок», «здесь абзац», «здесь картинка».

Браузер читает разметку и показывает страницу.

## Базовая структура

```
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Моя страница</title>
</head>
<body>
  <h1>Заголовок</h1>
  <p>Абзац текста.</p>
</body>
</html>
```

Разделы:

- `<head>` — то, что не видно: кодировка, заголовок вкладки, подключение стилей;
- `<body>` — то, что видит пользователь.

## Основные теги

| Тег | Значение |
|---|---|
| `<h1>`…`<h6>` | заголовки разных уровней |
| `<p>` | абзац |
| `<b>`, `<i>`, `<u>` | жирный, курсив, подчёркнутый |
| `<a href="...">` | ссылка |
| `<img src="..." alt="...">` | изображение |
| `<ul>`, `<ol>`, `<li>` | маркированный и нумерованный списки |
| `<table>`, `<tr>`, `<td>` | таблица |
| `<div>` | блок-контейнер |
| `<br>` | перенос строки |

## Главные правила написания

1. **Закрывающие теги.** Почти у каждого тега есть пара: `<p>…</p>`. Незакрытый тег «съедает» следующий блок.
2. **Атрибуты** пишутся внутри открывающего тега: `<a href="url" title="описание">`.
3. **Значения атрибутов** — в кавычках.
4. **Теги не чувствительны к регистру**, но пишут строчными.
5. **Комментарии**: `<!-- пояснение -->`.

## Списки и таблицы

```
<ul>
  <li>Первый пункт</li>
  <li>Второй пункт</li>
</ul>
```

## Вложенность тегов

Теги могут вкладываться друг в друга, но порядок закрытия должен быть обратным: сначала закрывается внутренний, потом внешний.

```
<p><b>жирный</b> текст</p>
```

## Практическая работа

Задание КТП: разработка веб-страницы.

1. Создай файл `index.html` в текстовом редакторе.
2. Задай структуру документа: `DOCTYPE`, `html`, `head`, `body`.
3. Добавь заголовок, три абзаца текста, маркированный список.
4. Вставь изображение `<img>` и подпись к нему.
5. Добавь таблицу 3 × 3.
6. Добавь ссылку на другой сайт.
7. Сохрани и открой страницу в браузере.
8. Проверь: всё ли отображается, работает ли ссылка, видна ли картинка.

## Ключевое (записать)

- HTML — язык разметки, не программирования.
- `<head>` — невидимая часть, `<body>` — видимая.
- Закрывающие теги обязательны.
- Атрибуты пишутся в открывающем теге, значения — в кавычках.
- Вложенность: внутренний тег закрывается первым.

## Частые ошибки

- Забыть закрывающий тег: страница «поедет».
- Не указать `<meta charset="utf-8">`: русский текст покажется «кракозябрами».
- Забыть `alt` у изображения.
- Использовать `<br><br><br>` вместо абзацев для отступов.

## Проверь себя

1. Чем HTML отличается от языка программирования?
2. Зачем нужен тег `<head>`?
3. Что произойдёт, если забыть закрывающий тег?
