# Путь от задачи к работающей программе

## Этапы решения задачи

1. **Постановка задачи.** Что дано, что найти, какие ограничения.
2. **Формализация.** Записать условие в терминах предметной области: объекты, свойства, связи.
3. **Построение алгоритма.** Схема, псевдокод, блок-схема.
4. **Программирование.** Запись алгоритма на языке.
5. **Отладка.** Поиск и исправление ошибок.
6. **Тестирование.** Проверка на разных входных данных.

Шаг 1–2 пропускают чаще всего, и тогда программа решает не ту задачу.

## Основные конструкции языка

- **Типы данных**: целые (`int`), вещественные (`float`), строки (`str`, `bool`).
- **Ветвление**: `if … else`.
- **Циклы**: `while` (условие продолжения), `range` и `for` (заданное число повторений).
- **Списки**: `a = [1, 2, 3]` — для хранения набора данных.

## Методы отладки

| Метод | Что делает |
|---|---|
| **Трассировка** | записывать значения переменных по шагам |
| **Отладочный вывод** | печатать промежуточные значения в программу |
| **Точки останова** | останавливать программу на нужном шаге |
| **Тестирование границ** | проверять крайние допустимые значения |

### Трассировка

Таблица «шаг → значения переменных» показывает, где именно появилась ошибка.

## Граничные значения

Обязательно проверяй:

- **пустой** набор данных: 0 элементов;
- **один** элемент;
- **ноль** как значение;
- **максимум** допустимого диапазона;
- **отрицательные** числа, если они допустимы.

Пример ошибки: программа находит среднее элементов. На пустом массиве будет деление на ноль. На одном элементе код, который ищет максимум с помощью цикла `for i in range(1, len(a))`, пропустит его.

## Тестирование

**Тестирование** — проверка на наборах входных данных с заранее известным правильным ответом.

Два обязательных вида:

- позитивные тесты: верные данные, верный результат;
- **негативные тесты**: некорректные данные (пусто, ноль, слишком большое число, текст вместо числа) — программа должна сообщить об ошибке, а не выдать мусор.

## Ключевое (записать)

- Этапы: постановка → формализация → алгоритм → программа → отладка → тестирование.
- Отладка: трассировка, отладочный вывод, точки останова.
- Граничные значения: пусто, один, ноль, максимум, отрицательные.
- Тестирование: позитивные и негативные тесты.

## Частые ошибки

- Пропустить формализацию и писать программу сразу.
- Тестировать только «хорошие» значения, забыв границы.
- Делить на ноль при пустом массиве.
- Не обработать неверный ввод (текст вместо числа) — программа падает.
