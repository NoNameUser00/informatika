# Функции

## Подпрограмма

**Подпрограмма (функция)** — именованный блок кода, который можно вызвать по имени.

Зачем: повторяющийся кусок пишется один раз; ошибка исправляется в одном месте; программа становится короче и понятнее.

## Функция в Python

```
def имя(параметры):
    # тело
    return результат
```

Пример:

```
def площадь(a, b):
    return a * b

s = площадь(3, 4)
print(s)   # 12
```

**Параметры** — входные данные, **возвращаемое значение** — результат.

## Локальные и глобальные переменные

Переменная, созданная внутри функции, **локальна**: вне функции она не существует.

```
def f():
    x = 10

f()
print(x)   # NameError: имя 'x' не определено
```

Это хорошо: функция не «засоряет» программу. Но если нужно передать результат наружу — используем `return`.

## Побочные эффекты

**Побочный эффект** — изменение, которое функция делает «вокруг себя»: печать, изменение глобальных переменных, запись в файл.

Правило хорошего тона: функция **возвращает** результат, а не печатает его. Тогда её можно переиспользовать в любом месте.

```
# плохо
def сумма_вывести(a):
    print(sum(a))

# хорошо
def сумма(a):
    return sum(a)
```

## Рекурсия

**Рекурсия** — функция вызывает сама себя.

Классический пример — **факториал**:

```
def факториал(n):
    if n <= 1:
        return 1
    return n * факториал(n - 1)
```

**Базовый случай** (`n <= 1`) обязателен: без него рекурсия не остановится.

Проверка: `факториал(5)` = 5 · `факториал(4)` = 5 · 4 · 3 · 2 · 1 = **120**.

Ещё пример — сумма цифр:

```
def сумма_цифр(n):
    if n == 0:
        return 0
    return n % 10 + сумма_цифр(n // 10)
```

## Три способа решить задачу

Задача «сумма чисел от 1 до n» решается тремя способами:

1. **Цикл** — работает всегда, понятно.
2. **Формула** — `n(n+1)/2`, но не для произвольных наборов.
3. **Рекурсия** — `f(n) = n + f(n−1)`, красиво, но глубже стек.

Выбор зависит от задачи и читаемости.

## Ключевое (записать)

- Функция: параметры → тело → `return` результат.
- Переменные внутри функции локальны.
- Хорошая функция возвращает результат, а не печатает его.
- Рекурсия: функция вызывает себя; нужен базовый случай.
- Без базового случая рекурсия не остановится.

## Частые ошибки

- Забыть `return` — функция ничего не вернёт (вернёт `None`).
- Использовать глобальные переменные вместо параметров.
- Забыть базовый случай в рекурсии: бесконечное вызывание, переполнение стека.
- Печатать внутри функции, а не возвращать.
