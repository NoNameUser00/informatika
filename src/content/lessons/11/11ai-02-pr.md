# Работа с ИИ-сервисами

Задание КТП: работа с интернет-приложениями на основе искусственного интеллекта.

## Какие сервисы доступны

| Задача | Примеры сервисов |
|---|---|
| Перевод текста | Google Translate, Яндекс.Переводчик, DeepL |
| Распознавание речи | голосовой набор, субтитры, голосовые помощники |
| Распознавание изображений | поиск по картинке, переводчик камеры |
| Генерация текста | чат-ассистенты |
| Озвучка текста | синтез речи |

## Порядок работы

### 1. Сформулируй задачу

Чёткая постановка важнее длинного запроса:

- плохо: «сделай реферат про ИИ»;
- хорошо: «сделай план реферата из 5 разделов про искусственный интеллект в школе для 11 класса».

### 2. Выбери сервис под задачу

Для перевода — переводчик, для распознавания речи — сервис распознавания. Универсального сервиса «для всего» нет.

### 3. Проверь результат

**Обязательный шаг.** Сравни результат с исходным текстом:

1. **Факты** — все ли верны? Сравни с учебником.
2. **Термины** — правильно ли переведены? Проверь ключевые термины по словарю.
3. **Формулы и числа** — не искажены ли?
4. **Логика** — нет ли противоречий.

Что проверяют чаще всего: числа, имена, формулы, отрицания.

### 4. Зафиксируй ограничения

Отметь в работе, какие части требуют проверки. Если сервис перевёл термин неверно, отметь это: честность важнее гладкости.

## Правила использования ИИ в учёбе

1. **ИИ — помощник, не автор.** Работа, сданная полностью сгенерированная, не твоя.
2. **Пересказывай своими словами.** Тогда ИИ полезен.
3. **Проверяй факты.** ИИ может сослаться на несуществующий источник.
4. **Указывай использование.** Скажи учителю, если помогал ИИ.

## Практическая работа

1. Возьми текст из трёх абзацев на английском.
2. Переведи его двумя разными сервисами, сравни результаты.
3. Найди расхождения в терминах, числах, отрицаниях.
4. Проверь перевод ключевых терминов по отраслевому словарю.
5. Распознай речь: запиши абзац голосом, сравни текст с распознанным.
6. Составь отчёт: где сервис ошибся и почему.

## Типичные ошибки ИИ-сервисов

| Ошибка | Пример |
|---|---|
| Неверный перевод термина | «входная переменная» → «переменная входа» |
| Потеря отрицания | «не выполняется» → «выполняется» |
| Искажение числа | 1250 → 125 |
| Придуманный источник | ссылка на несуществующую статью |
| Смешение похожих терминов | алгоритм / алгоритмика |

## Ключевое (записать)

- ИИ-сервисы: перевод, распознавание речи, распознавание изображений, генерация текста.
- Результат ИИ **всегда проверяют**: факты, термины, числа, формулы.
- Частые ошибки: неверный термин, потеря отрицания, искажение числа, выдуманный источник.
- ИИ — помощник, а не автор работы.

## Частые ошибки

- Сдавать результат ИИ без проверки фактов.
- Верить ссылкам, которые выдаёт ИИ.
- Использовать ИИ для генерации текста целиком.
- Скрывать использование ИИ.

## Проверь себя

1. Какие четыре вида проверки результата ИИ нужны обязательно?
2. Приведи два примера типичных ошибок ИИ-сервисов.
3. Почему результат ИИ нельзя сдавать без проверки?
