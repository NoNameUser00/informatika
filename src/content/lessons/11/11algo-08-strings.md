# Работа со строками

**Строка** — последовательность символов: `s = 'информатика'`.

## Полезные операции

| Операция | Что делает | Пример |
|---|---|---|
| `len(s)` | длина | `len('абв')` = 3 |
| `s[i]` | символ по индексу (с 0) | `'абв'[1]` = `'б'` |
| `s[-1]` | последний символ | `'абв'[-1]` = `'в'` |
| `s[a:b]` | срез: с a по b−1 | `'абв'[0:2]` = `'аб'` |
| `s[::-1]` | разворот | `'абв'[::-1]` = `'вба'` |
| `s + t` | склейка | `'аб' + 'в'` = `'абв'` |
| `s * 3` | повтор | `'а' * 3` = `'ааа'` |
| `x in s` | вхождение | `'б' in 'абв'` = `True` |
| `ord(c)` | код символа | `ord('А')` = 65 |
| `chr(n)` | символ по коду | `chr(65)` = `'А'` |

## Перебор символов

```
for ch in s:
    print(ch)
```

## Подсчёт символов

```
s = 'барабан'
k = 0
for ch in s:
    if ch == 'а':
        k = k + 1
print(k)   # 3
```

## Перебор по индексам

```
for i in range(len(s)):
    print(i, s[i])
```

Нужен, когда внутри цикла меняем строку или работаем со срезами.

## Разворот

```
s = 'довод'
print(s == s[::-1])   # True — палиндром
```

## Сравнение строк

Строки сравниваются посимвольно по кодам. Регистр имеет значение: `'A' != 'а'`.

Для сравнения без учёта регистра используют `lower()` / `upper()`:

```
if s.lower() == 'да':
    print('согласен')
```

## Удаление пробелов

```
s = '  привет  '
print(s.strip())   # 'привет'
```

Методы `strip()`, `lstrip()`, `rstrip()` убирают пробелы слева, справа или с обеих сторон.

## Ключевое (записать)

- Строка — последовательность символов, индексы с 0, последний — `[-1]`.
- Срез `s[a:b]` — с a по b−1; разворот — `s[::-1]`.
- `len(s)`, `s + t`, `s * k`, `x in s`.
- Сравнение посимвольно по кодам, регистр важен.
- `strip()` убирает пробелы по краям.

## Частые ошибки

- Считать, что `s[-1]` — второй символ: это последний.
- Ожидать, что `s[1:3]` включает третий символ: не включает.
- Сравнивать строки без учёта регистра.
- Изменять строку в цикле, не понимая, что строки неизменяемы: нужен новый список.

## Проверь себя

1. Чем `s[-1]` отличается от `s[1]`?
2. Что вернёт `'абв'[1:3]`?
3. Как посчитать, сколько раз в строке встречается буква?
