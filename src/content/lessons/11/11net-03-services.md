# Сервисы, государство, экономика

## Сервисы Интернета

**Интернет-сервис** — сайт или приложение, решающее задачу через браузер.

| Задача | Сервисы |
|---|---|
| Поиск информации | поисковики, электронные библиотеки |
| Обучение | открытые курсы, видеолекции, репозитории |
| Общение | мессенджеры, почта, видеозвонки |
| Работа | онлайн-офис, CRM, облачные диски |
| Покупки | маркетплейсы, оплата услуг |
| Развлечения | видеохостинги, стриминг, игры |
| Госуслуги | государственные услуги |

## Геоинформационные системы и геолокация

**Геоинформационная система (ГИС)** — программа для сбора, хранения, обработки и отображения данных о местоположении объектов.

**Геолокационные сервисы** — определяют местоположение по сигналам башен связи, спутникам, Wi-Fi.

Применение: навигатор, карты, доставка, «ближайшая аптека», экологический мониторинг.

**Информационная культура** — умение эффективно и безопасно работать с информацией и цифровыми средствами: находить, оценивать, создавать и защищать информацию.

## Открытые образовательные ресурсы

**Открытые образовательные ресурсы (ООР)** — материалы, свободно доступные для обучения: учебники, курсы, видео, тренажёры.

Проверяй: есть ли автор, указан ли источник, подходит ли уровень сложности.

## Госуслуги

**Портал государственных услуг** — единая точка доступа к государственным услугам: запись к врачу, подача документов, оплата налогов, регистрация.

Принцип работы:

1. Регистрация и подтверждение учётной записи.
2. Вход по логину, паролю и **двухфакторной аутентификации** (подтверждение по телефону).
3. Выбор услуги и подача заявления онлайн.
4. Получение результата.

Зачем нужна двухфакторная аутентификация: украденный пароль сам по себе не даст доступа — нужен ещё код с телефона.

## Цифровая экономика

**Цифровая экономика** — часть экономики, основанная на цифровых технологиях и данных.

Как ИТ меняет экономику:

- **производительность** — автоматизация рутины;
- **новые отрасли** — то, чего раньше не было;
- **данные как актив** — решения принимаются по анализу данных.

Риски цифровой экономики: безработица в автоматизируемых профессиях, цифровое неравенство, зависимость от платформ.

## Практическая работа

Задание КТП: использование интернет-сервисов.

1. Найди три образовательных ресурса по своей специальности, оцени их качество.
2. Изучи возможности Госуслуг: какие услуги доступны.
3. Построй маршрут в картах (навигация).
4. Проверь, как работает двухфакторная аутентификация.
5. Оцени один сервис по критериям: достоверность, актуальность, автор, бесплатность.

## Ключевое (записать)

- ГИС — система для работы с данными о местоположении.
- Госуслуги — единая точка доступа к государственным услугам.
- Двухфакторная аутентификация: пароль плюс подтверждение.
- Информационная культура — умение эффективно и безопасно работать с информацией.
- Цифровая экономика меняет производительность, отрасли и роль данных.

## Частые ошибки

- Считать, что данные ГИС всегда точные: погрешность есть.
- Отключать двухфакторную аутентификацию «для удобства».
- Доверять любому найденному ресурсу без проверки автора.
- Считать, что цифровые сервисы бесплатны для пользователя: за ними стоит чья-то работа.

## Проверь себя

3. Назови три критерия оценки интернет-ресурса.
