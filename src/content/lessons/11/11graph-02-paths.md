# Две задачи на графах

## Задача 1: оптимальный (кратчайший) путь

В **взвешенном графе** «лучше» = дешевле: складываем веса вдоль пути и берём минимум.

### Разбор примера

Веса рёбер: `A–B = 4`, `A–C = 2`, `C–B = 1`, `B–D = 5`, `C–D = 8`.

Перебираем все пути из A в D и считаем суммы:

| Путь | Расчёт | Сумма |
|---|---|---|
| A → B → D | 4 + 5 | 9 |
| A → C → D | 2 + 8 | 10 |
| A → C → B → D | 2 + 1 + 5 | **8** |

Ответ: кратчайший путь **A → C → B → D**, длина **8**.

Обрати внимание: путь с наименьшим числом рёбер (A → B → D) не обязательно самый лёгкий.

### Приём

Выпиши все пути в столбик с суммами — минимум виден сразу. На больших графах перебор не годится: там работает алгоритм Дейкстры (жадный: идём к ближайшей ещё не посещённой вершине).

## Задача 2: число путей в направленном ациклическом графе

**Направленный ациклический граф (DAG)** — ориентированный граф без циклов.

### Правило

**Число путей в вершину = сумма чисел путей во всех её предшественники.**

Считаем накоплением, в топологическом порядке.

### Разбор примера

Рёбра: `A→B`, `A→C`, `B→C`, `B→D`, `C→D`.

| Вершина | Предшественники | Путей |
|---|---|---|
| A | нет | **1** (пустой путь) |
| B | A | 1 |
| C | A, B | 1 + 1 = **2** |
| D | B, C | 1 + 2 = **3** |

Ответ: в D ведут **3 пути**: A→B→D, A→B→C→D, A→C→D.

Проверка перебором совпала.

### Главная ловушка

В вершину-источник всегда **1 путь** — пустой путь. Забыть эту единицу — значит получить все значения в 2 раза меньше.

## Смешанная задача

Часто требуется и минимум стоимости, и число способов его достичь:

- **число путей** в вершину — суммированием по предшественникам;
- **минимальная стоимость** — сравнением: берём меньшую из стоимостей предшественников и прибавляем вес ребра.

```
стоимость(A) = 0
стоимость(B) = min(A) + 4 = 4
стоимость(C) = min(A, B) + 2 = min(0, 4) + 2 = 2
стоимость(D) = min(B, C) + 5 = min(4, 2) + 5 = 7
```

Ответ: минимальная стоимость до D — 7 (путь A→C→D).

## Практическая работа

1. Построй взвешенный граф с 6 вершинами (карта города).
2. Запиши весовую матрицу.
3. Найди кратчайший путь перебором — выпиши все пути и суммы.
4. Построй направленный ациклический граф с 6 вершинами.
5. Посчитай число путей в последнюю вершину накоплением.
6. Проверь оба ответа обратным счёстом: перебором всех путей.

## Ключевое (записать)

- Кратчайший путь: суммы весов всех путей, берём минимум.
- Число путей в DAG = сумма чисел путей в предшественников.
- В источнике всегда 1 путь (пустой путь).
- Минимальная стоимость = min по предшественникам + вес ребра.
- Ответы всегда проверяем обратным счётом.

## Частые ошибки

- Считать, что кратчайший путь — самый короткий по числу рёбер.
- Ставить 0 в вершину-источник при подсчёте путей.
- Считать не в топологическом порядке: предшественник ещё не посчитан.
- Не проверить результат перебором.

## Проверь себя

1. Для весов A–B 4, A–C 2, C–B 1, B–D 5, C–D 8 найди кратчайший путь из A в D.
2. Для рёбер A→B, A→C, B→D, C→D сколько путей в D?
3. Чему равно число путей в вершину-источник?
