## Проектная работа

Итоговое задание КТП: работа с интернет-приложениями на основе искусственного интеллекта.

## Требования к работе

1. **Проблема.** Сформулируйте, какую реальную задачу вы решаете.
2. **Инструмент.** Какие сервисы ИИ использовали и для чего.
3. **Ход работы.** Что делали по шагам.
4. **Проверка.** Как проверяли результат, какие ошибки нашли.
5. **Вывод.** Где ИИ помог, где не справился.

## Темы проектов

| Тема | Инструменты |
|---|---|
| Перевод технической статьи | переводчик |
| Голосовое резюме документа | распознавание речи |
| Распознавание объектов на фото | сервис распознавания |
| Проверка подозрительного видео | анализ признаков дипфейка |
| Сравнение качества перевода двух сервисов | переводчики |
| Распознавание рукописного текста | сервисы OCR |

## Порядок выполнения

1. **Выберите тему и инструменты.** Запишите, что именно собираетесь сделать.

2. **Подготовьте исходные данные.** Текст, аудио, изображение или видео. Данные должны быть законными и получены законно.

3. **Примените инструменты.** Делайте всё по шагам, фиксируйте промежуточные результаты.

4. **Проверьте результат.** Составьте таблицу:

| Что проверяем | Как | Результат |
|---|---|---|
| Факты | по учебнику / первоисточнику | верно / ошибка |
| Термины | по словарю | верно / ошибка |
| Числа и формулы | вручную | верно / ошибка |
| Логика | смысловая проверка | верно / ошибка |

5. **Оцените инструмент.** Где ошибался? Как часто? В каких случаях?

6. **Оформите вывод.** 5–7 предложений: что ИИ умеет, чего не умеет, где его можно и нельзя применять.

## Правила оформления

- Структура: титульный лист, цель, ход работы, проверка результата, вывод, выводы — 5–7 слайдов.
- Укажите источник исходных данных.
- Укажите, какие сервисы ИИ использовались.
- Приведите конкретные примеры ошибок — это главная ценность работы.
- **Укажите использование ИИ** — по правилам учебного заведения.

## Критерии оценки

| Критерий | Что оценивается |
|---|---|
| Постановка задачи | задача сформулирована явно |
| Корректность применения | инструмент выбран обоснованно |
| Проверка результата | проверка выполнена по пунктам, а не «на глаз» |
| Анализ ошибок | найдены конкретные ошибки |
| Выводы | выводы следуют из работы |
| Оформление | структура и единый стиль |

## Ключевое (записать)

- Проект: проблема, инструмент, ход работы, проверка, вывод.
- Проверка результата — обязательный этап, а не формальность.
- Главная ценность работы — найденные конкретные ошибки ИИ.
- Указывай использование ИИ и источник данных.

## Частые ошибки

- Сдать работу без проверки результата — это главная потеря баллов.
- Написать выводы, не следующие из работы.
- Не указать источник исходных данных и сервисы.
- Публиковать работы в интернет целиком, как свои.
- Оставить «невероятные» скриншоты без проверки.

## Проверь себя

1. Из каких обязательных частей состоит проектная работа?
2. По каким четырём пунктам проверяют результат ИИ?
3. Почему важно указывать использование ИИ в работе?
