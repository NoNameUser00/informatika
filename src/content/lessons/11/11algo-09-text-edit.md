# Замена, удаление, вставка, поиск

Задание КТП: разработать и реализовать алгоритмы редактирования текста.

## Поиск подстроки

### Наивный поиск

```
s = 'информатика'
sub = 'мат'
n = len(s)
m = len(sub)
found = -1
for i in range(n - m + 1):
    if s[i:i+m] == sub:
        found = i
        break
print(found)   # 5
```

Работает, но сравнивает подстроки целиком. Для больших строк — медленно.

### Поиск всех вхождений

```
s = 'барабан'
sub = 'а'
positions = []
for i in range(len(s)):
    if s[i] == sub:
        positions.append(i)
print(positions)   # [1, 3, 5]
```

## Замена

В Python строка неизменяема, поэтому `replace` создаёт **новую** строку:

```
s = 'banana'
s = s.replace('a', 'o')
print(s)   # 'bonono'
```

Без присваивания результат потеряется: `s.replace(...)` ничего не меняет.

### Замена всех вхождений вручную

```
s = 'a-b-c'
res = ''
for ch in s:
    if ch == '-':
        res = res + '+'
    else:
        res = res + ch
print(res)   # 'a+b+c'
```

## Удаление

```
s = 'a-b-c'
s = s.replace('-', '')
print(s)   # 'abc'
```

Ручной вариант — то же самое, но без добавления символа в ветке.

## Вставка

Строку собирают по символам, добавляя нужное в нужном месте:

Вставка буквы `ы` после четвёртой буквы слова `книга`:

```
s = 'книга'
res = s[:4] + 'ы' + s[4:]
print(res)   # 'книгы'
```

Главное правило срезов: `s[:k]` — первые k символов, `s[k:]` — начиная с k-го.

## Ключевое (записать)

- Поиск: перебираем позиции и сравниваем подстроки.
- Замена и удаление через `replace` создают **новую** строку — результат надо присвоить.
- Ручная замена: собираем новую строку посимвольно.
- Вставка через срезы: `s[:k] + новое + s[k:]`.

## Частые ошибки

- Забыть присвоить результат `replace`.
- Перепутать границы срезов при вставке.
- Искать подстроку, не ограничив диапазон: выход за границу.
- Считать, что строки изменяются на месте (в Python это не так).

## Проверь себя

1. Найди все вхождения буквы `а` в слове «барабан».
2. Замени все дефисы в строке `a-b-c` на плюсы.
3. Вставь букву `ы` в слово `книга` после четвёртой буквы.

Ответ на 3: `s[:4] + 'ы' + s[4:]` даст `'книгы'`.
