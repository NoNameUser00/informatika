# Цикл for

Цикл с заданным числом повторений — для него в Python есть оператор `for`:

```
for i in range(1, 4):
    print(i, i * i)
```

`range(1, 4)` даёт 1, 2, 3. Правая граница **не входит** — это главная ловушка.

Вывод:

```
1 1
2 4
3 9
```

## Нюансы range

```
range(5)        # 0 1 2 3 4
range(1, 5)     # 1 2 3 4
range(1, 10, 2) # 1 3 5 7 9
```

Первый аргумент — начало, второй — конец (не включается), третий — шаг.

## Задача 1. Сумма чисел от 1 до n

```
n = int(input())
s = 0
for i in range(1, n + 1):
    s = s + i
print(s)
```

Проверка: n = 4 → 1 + 2 + 3 + 4 = 10. Обрати внимание на `n + 1` — без единицы потеряем само n.

## Задача 2. Факториал

```
n = int(input())
f = 1
for i in range(1, n + 1):
    f = f * i
print(f)
```

n = 4 → 24. Если n = 0, цикл не выполнится и ответ будет 1 — это верно (0! = 1).

## Задача 3. Таблица умножения

```
k = int(input())
for i in range(1, 11):
    print(i, '×', k, '=', i * k)
```

## Задача 4. Чётные числа до n

```
n = int(input())
for i in range(2, n + 1, 2):
    print(i)
```

Шаг 2 в range делает перебор сразу по чётным. При n = 7 выведет 2, 4, 6.

## Почему for, а не while

Число повторений известно заранее — `for` короче и в нём нельзя забыть увеличить счётчик. В `while` придётся самому инициализировать и обновлять переменную.

## Ключевое (записать)

- `for i in range(a, b):` — от a до b − 1.
- `range(1, n + 1)`, если нужно включить n.
- Шаг: `range(1, 10, 2)`.
- Число повторений известно — бери `for`.

## Частые ошибки

- `range(1, n)` вместо `range(1, n + 1)` — потеряем последнее значение.
- Считать, что `range(5)` начинается с 1: начинается с 0.
- Забыть двоеточие после `range(...)` и отступ в теле.
- Называть счётчик `i` и забыть, что он остаётся в памяти после цикла.
