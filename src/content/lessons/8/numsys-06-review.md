# Решение задач: шесть ловушек

## 1. Ведущие нули

`001101` = `1101`. Нули слева значение не меняют, но внутри числа важны: `101` != `11`.

## 2. Префиксы и суффиксы

`0b1101`, `1101₂`, `1101(2)` — одно число. Ввод: можно с ними или без.

## 3. Триады vs тетрады

- Восьмеричная <-> двоичная: группы по **3**.
- Шестнадцатеричная <-> двоичная: группы по **4**.
- Группируем всегда **справа**, слева дописываем нули.

## 4. A-F: цифры 10-15

A=10, B=11, C=12, D=13, E=14, F=15. Проверка: `2A₁₆ = 0010 1010 = 101010₂`, единиц — 3 (inf-8-numsys-010).

## 5. Соответствия: сверяй каждое

10=`1010₂`, 8=`1000₂`, 16=`10000₂` (inf-8-numsys-009). Частичный балл: 2/3 = 2 балла из 3.

## 6. Арифметика: проверка через 10СС

Сложил в двоичной — проверь в десятичной.

## Смешанный тренажер (10 заданий bank.yaml)

- базовые (1б): 001, 003, 004, 005, 011, 012, 013
- повышенные (2б): 006, 007, 008 (+002 как мост к hex)
- высокие (3б): 009, 010
- макс. 17б без новых 011-013; с ними 20б (шкала в docs/spec-numbersystems.md)

## Работа над ошибками (после проверочной/КР)

- Ошибка в триадах -> вернуться к numsys-03-octal.
- Ошибка в тетрадах/A-F -> numsys-04-hex.
- Ошибка в сложении -> numsys-05-arith.
- Ошибка в развернутой/Римской -> numsys-01-intro.
