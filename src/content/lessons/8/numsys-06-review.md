# Решение задач: шесть ловушек

## 1. Ведущие нули

`001101` = `1101`. Нули слева значение не меняют, но внутри числа важны: `101` != `11`. Незначащие нули можно отбрасывать (как в учебнике: 010101100₂ → 10101100₂).

## 2. Префиксы и суффиксы

`0b1101`, `1101₂`, `1101(2)` — одно число. Ввод: можно с ними или без. Суффикс всегда читай: 10111₂, 1F₁₆, 27₈, 30₈ — разные числа!

## 3. Триады vs тетрады

- Восьмеричная <-> двоичная: группы по **3** (8 = 2³).
- Шестнадцатеричная <-> двоичная: группы по **4** (16 = 2⁴).
- Группируем всегда **справа**, слева дописываем нули.
- 8↔16 напрямую не меняем — только через двоичную.

## 4. A-F: цифры 10-15

A=10, B=11, C=12, D=13, E=14, F=15. Проверка: `2A₁₆ = 0010 1010 = 101010₂`, единиц — 3 (inf-8-numsys-010).

## 5. Минимальное основание

Смотри старшую цифру/букву записи, основание = она + 1 (для букв: A→11, F→16). Примеры: числу 123 подойдёт 4; 506 — 7; записи с F — минимум 16.

## 6. Сравнение чисел в разных системах

Не сравнивай «в лоб» — переведи всё в десятичную. Пример: 10111₂=23, 1F₁₆=31, 27₈=23, 30₈=24 → наибольшее 1F₁₆. А FF₁₆=255, 777₈=511, 11111111₂=255, 1000₁₀=1000 → наибольшее 1000₁₀ (подвох: десятичное!).

## 7. Арифметика: проверка через 10СС

Сложил в двоичной — проверь в десятичной. Смешанные выражения считай по частям: (1111101₂ + AF₁₆) : 36₈ = (125 + 175) : 30 = 300 : 30 = 10.

## Смешанный тренажер

- базовые: развёрнутая форма, основание, Римская;
- переводы 10↔2↔8↔16, триады/тетрады;
- подсчёт единиц/нулей, минимальное основание, сравнения;
- арифметика с проверкой через 10СС.
