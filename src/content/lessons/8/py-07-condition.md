# else и сложные условия

Полная форма условного оператора:

```
if <условие>:
    <действие 1>
else:
    <действие 2>
```

Выполняется **ровно одна** ветка. Ключевое слово `else` пишется на том же уровне отступа, что и `if`.

## Сложные условия

В условии работает вся логика 8 класса: сравнения и связки.

- `and` — И (конъюнкция): истинно, только если истинны оба.
- `or` — ИЛИ (дизъюнкция): истинно, если истинно хотя бы одно.
- `not` — НЕ (отрицание): переворачивает значение.

```
x = int(input())
if x >= 0 and x <= 10:
    print('внутри')
else:
    print('снаружи')
```

## Разбор случаев

- x = 5 → оба сравнения истинны → «внутри».
- x = 20 → первое истинно, второе ложно → «снаружи».
- x = −3 → первое ложно → «снаружи».

## elif: когда вариантов больше двух

Если условий несколько, цепочку `elif` пишут подряд:

```
if x > 100:
    print('больше 100')
elif x > 50:
    print('от 51 до 100')
elif x > 10:
    print('от 11 до 50')
else:
    print('не больше 10')
```

Проверки идут сверху вниз, выполняется **первое** подходящее условие, остальные пропускаются.

## Вложенные условия

Внутри ветки может стоять другое ветвление — тогда следи за отступами, они выравниваются по уровню:

```
if a > 0:
    if a > 10:
        print('больше 10')
    else:
        print('от 1 до 10')
else:
    print('не положительное')
```

## Ключевое (записать)

- `if` / `else` выполняет ровно одну ветку.
- `elif` — цепочка проверок, срабатывает первая подходящая.
- Связки: `and` (оба), `or` (хотя бы одно), `not` (отрицание).
- Отступы определяют вложенность.

## Частые ошибки

- Забыть `else`, хотя при ложном условии нужно действие.
- Написать несколько `elif` после уже сработавшего `if` — они не проверятся.
- Использовать `=` вместо `==` в сравнении.
- Смешать табы и пробелы.
