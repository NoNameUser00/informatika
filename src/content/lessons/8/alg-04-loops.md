# Конструкция «повторение» (цикл)

Цикл выполняет тело, пока верно условие (или заданное число раз). В ШАЯ:

```
нц пока <условие>
  <тело>
кц
```

Проверка условия — ПЕРЕД каждой итерацией: если сразу ложно, тело не выполнится ни разу.

## Три вида (по КТП)

1. **Цикл с условием продолжения** (`пока`): крутимся, пока условие истинно. Коридор Робота: `нц пока справа свободно`.
2. **Цикл с условием окончания** (`до`): крутимся, пока условие ложно (выход — когда станет истинно).
3. **Цикл с заданным числом повторений** (`Повтори k`): Черепаха рисует квадрат: `Повтори 4 [Вперёд 20 Направо 90]`.

## Эталонный пример: деление вычитанием

Частное и остаток без операции деления: вычитаем делитель, пока можно; число вычитаний — частное, остаток — последняя разность.

```
Начало → ввод x, y → r := x, q := 0 →
пока r >= y: { r := r − y; q := q + 1 } → вывод r, q → Конец
```

Проверка на числах: x=13, y=5. r=13: 13−5=8 (q=1), 8−5=3 (q=2), 3<5 — стоп. Ответ: q=2, r=3. Проверка: 2·5+3 = 13 ✓.

## Опасность: бесконечный цикл

Если условие никогда не становится ложным (забыл изменить счётчик!) — цикл крутится вечно. Лекарство: убедись, что тело приближает выход (r уменьшается, счётчик растёт).

## Ключевое (записать)

- `нц пока <условие> … кц`. Условие проверяется ДО тела.
- Три вида: пока / до / Повтори k.
- Деление = вычитания до упора: счётчик → частное, остаток → r.
- Тело обязано приближать выход, иначе — бесконечный цикл.

## Частые ошибки

- Путать «пока» и «до» (противоположные условия!).
- Забывать менять переменную условия внутри тела.
- Выполнять тело хотя бы раз при ложном условии (нет — проверка сначала!).

## Проверь себя (практика)

1. Сколько раз выполнится `Повтори 4 [...]`? А если условие сразу ложно?
2. Найди q и r для x=20, y=6 вычитаниями. Проверь формулой q·y+r.
3. Что нарисует `Повтори 12 [Направо 45 Вперёд 20 Направо 45]`? (поворот за итерацию 90°, итераций 12 → 1080° = 3 полных оборота: квадрат, пройденный трижды)
