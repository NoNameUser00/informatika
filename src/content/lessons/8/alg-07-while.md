# Повторение

**Алгоритмическая конструкция «повторение»** заставляет одни и те же действия выполняться несколько раз. В КТП различают три вида цикла — различаются они тем, **когда** цикл заканчивается.

## Цикл с условием продолжения (while)

Цикл работает, **пока условие истинно**. Условие проверяется перед каждой итерацией.

```
нц пока <условие>
  <тело цикла>
кц
```

Если условие ложно сразу — тело не выполнится ни разу. Если условие никогда не станет ложным — цикл зациклится (бесконечный цикл).

## Пример: подсчёт цифр числа

Задача: сколько цифр в числе n?

```
нц пока n > 0
  n := n // 10
  k := k + 1
кц
```

Проверка на n = 12345:

| шаг | условие n > 0 | n | k |
|---|---|---|---|
| старт | — | 12345 | 0 |
| 1 | истина | 1234 | 1 |
| 2 | истина | 123 | 2 |
| 3 | истина | 12 | 3 |
| 4 | истина | 1 | 4 |
| 5 | истина | 0 | 5 |
| 6 | ложно | — | выход |

Ответ 5. Обрати внимание: цикл выполнился 5 раз, а проверок условия было 6 — последняя проверка «сломала» цикл.

## Сумма цифр — тот же цикл

```
нц пока n > 0
  s := s + n mod 10
  n := n // 10
кц
```

Для n = 9575: 5 + 7 + 5 + 9 = 26.

## Как не зациклиться

Главная опасность цикла с условием продолжения — условие, которое не меняется. Проверь: переменная из условия обязана меняться внутри тела и двигаться к тому, чтобы условие стало ложным.

## Ключевое (записать)

- Цикл с условием продолжения работает, пока условие истинно.
- Условие проверяется **перед** каждой итерацией.
- Если условие ложно сразу — тело не выполняется ни разу.
- В теле должно меняться то, что стоит в условии.

## Частые ошибки

- Поставить цикл «до первого» вместо «пока»: проверка уходит на конец.
- Забыть изменить переменную условия внутри тела — бесконечный цикл.
- Считать, что при n = 0 тело выполнится один раз: нет, условие ложно сразу.
- Считать `//` и `%`: это целая часть и остаток от деления на 10.

## Проверь себя

1. Сколько раз выполнится тело цикла «пока n > 0» при n = 1?
2. Сколько цифр в числе 12345?
3. Чему равна сумма цифр числа 9575?
