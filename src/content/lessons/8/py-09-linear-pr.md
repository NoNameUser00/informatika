# Линейные алгоритмы: арифметика

Задание по КТП: программирование линейных алгоритмов, вычисляющих арифметические и логические выражения.

**Линейный алгоритм** — команды по порядку, без ветвлений и циклов. Весь набор операций: сложение, вычитание, умножение, деление, остаток, целая часть, степень, плюс логические операции.

## Задание 1. Площадь и периметр

```
a = int(input())
b = int(input())
s = a * b
p = 2 * (a + b)
print(s)
print(p)
```

## Задание 2. Остаток и целая часть

```
n = int(input())
print(n % 10)    # последняя цифра
print(n // 10)   # число без последней цифры
```

Для n = 12345: остаток 5, целая часть 1234.

## Задание 3. Разряд числа

Последние две цифры: `n % 100`. Для n = 2024 будет 24 — именно так определяют, какие цифры «торчат».

## Задание 4. Логическое выражение

```
x = 7
if x > 5 and x < 10:
    print('да')
else:
    print('нет')
```

Здесь уже есть ветвление, но само условие — линейное вычисление.

## Задание 5. Деление вычитанием (без операции деления)

Частное и остаток получают вычитанием, считая шаги:

```
x = 13
y = 5
r = x
q = 0
while r >= y:
    r = r - y
    q = q + 1
print(q, r)   # 2 3
```

Проверка: q · y + r = 2 · 5 + 3 = 13 ✓.

## Типичные ошибки

- Думать, что `n / 10` отбрасывает цифру — нет, это дробь; нужно `//`.
- Перепутать порядок: сначала создать переменные, потом их использовать.
- Забыть скобки: `2 * (a + b)` не равно `2 * a + b`.
- Не проверить результат на простом примере (например, на 0 или 1).

## Ключевое (записать)

- Линейный алгоритм: команды сверху вниз, без ветвлений и циклов.
- Порядок вычисления: скобки → `*`, `/`, `//`, `%` → `+`, `-`.
- `//` — целая часть, `%` — остаток, `**` — степень.
- После вычисления проверь на маленьком примере.

## Частые ошибки

- Путать `n / 10` и `n // 10`.
- Забыть скобки в выражении.
- Не проверить результат.

## Проверь себя

1. Чему равны `13 // 5`, `13 % 5`, `2 ** 10`?
2. Что выведет `print(2024 % 100)`?
3. Проверь формулой: q · y + r = x для x = 13, y = 5.
