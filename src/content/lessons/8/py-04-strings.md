# Строки как последовательность символов

**Строка** (`str`) — последовательность символов в кавычках: `'Python'`, `"привет"`. Строка хранит порядок символов, поэтому у каждого есть номер — **индекс**. Счёт идёт **с нуля**: первый символ под номером 0.

```
s = 'Python'
print(len(s))   # 6
print(s[0])     # P — первый
print(s[5])     # n — последний
print(s[-1])    # n — тоже последний (счёт с конца)
```

**Длина** — функция `len()`. У `'информатика'` длина 11. Последний индекс всегда `len − 1`: для `'Python'` это 5. Обратишься к `s[6]` — получишь `IndexError`: такого номера нет.

## Срезы

**Срез** `s[a:b]` берёт символы с `a` по `b − 1`. Правая граница не входит — ровно как в `range`.

```
s = 'Python'
print(s[1:4])   # yth
print(s[:3])    # Pyt — от начала
print(s[3:])    # hon — до конца
```

## Операции над строками

- `+` — склейка: `'Py' + 'thon'` → `'Python'`.
- `*` — повтор: `'ab' * 3` → `'ababab'`.
- `in` — поиск подстроки: `'yth' in 'Python'` → `True`.

Код символа: `ord('A')` → `65`, обратно `chr(66)` → `'B'`. Это мост к урокам о кодировании.

## Перебор символов

Цикл `for ch in s:` идёт по символам по одному — так считают буквы:

```
s = 'барабан'
k = 0
for ch in s:
    if ch == 'а':
        k = k + 1
print(k)   # 3
```

## Приём: разбор строки на цифры

```
s = '12345'
n = 0
for ch in s:
    n = n * 10 + int(ch)
print(n)   # 12345
```

Каждый шаг приписывает цифру справа: сначала 1, потом 12, потом 123 и так далее. Обратный приём — `n // 10` отбрасывает последнюю цифру (это разбирали в циклах).

## Ключевое (записать)

- Индексы с нуля; последний — `s[-1]` или `s[len(s) − 1]`; за границей — `IndexError`.
- Срез `s[a:b]` — с `a` по `b − 1`.
- `+` клеит, `*` повторяет, `in` ищет подстроку.
- `ord` — код символа, `chr` — символ по коду.
- `for ch in s` — перебор символов; `n = n * 10 + цифра` — разбор строки в число.

## Частые ошибки

- Начинать счёт с 1: `s[1]` — это второй символ, не первый.
- Ждать, что `s[1:4]` включит символ 4 — нет, только до `b − 1`.
- Считать, что `len` — это последний индекс: индекс последнего — `len − 1`.
- Путать `=` и `==` в условиях.

## Проверь себя

2. Что даст `s[1:4]`? А `'on' in s`?
3. Сколько раз буква `а` встречается в слове «барабан»?
