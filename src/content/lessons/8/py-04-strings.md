# Строки в Python

**Строка** (`str`) — последовательность символов в кавычках: `'Python'`, `"привет"`. Строка хранит порядок символов, поэтому у каждого есть номер — **индекс**. Счёт идёт с нуля: первый символ под номером 0!

```
s = 'Python'
print(len(s))   # 6
print(s[0])     # P — первый
print(s[5])     # n — последний
print(s[-1])    # n — тоже последний (счёт с конца!)
```

**Длина** — функция `len()`: у `'информатика'` длина 11. Последний индекс всегда `len − 1` (для `'Python'` это 5). Обратишься к `s[6]` — получишь ошибку `IndexError`: такого номера нет.

## Срезы и операции

**Срез** `s[a:b]` берёт символы с `a` по `b−1` (правая граница не входит — как в `range`!):

```
s = 'Python'
print(s[1:4])   # yth
print(s[:3])    # Pyt — от начала
print(s[3:])    # hon — до конца
```

Строки умеют `+` (склейка: `'Py' + 'thon'` → `'Python'`) и `*` (повтор: `'ab' * 3` → `'ababab'`). Проверка `in` ищет подстроку: `'yth' in 'Python'` → `True`. Каждый символ имеет числовой код: `ord('A')` → `65`, обратно — `chr(66)` → `'B'`. А цикл `for ch in s:` перебирает символы по одному — так считают буквы (в `'барабан'` буква `а` встречается 3 раза).

## Анализ алгоритмов: результат и обратные задачи

**Анализ** — понять работу алгоритма без полного прогона на компьютере. Прямая задача: дан вход — найди выход. Трассируй по шагам:

```
a = 5
if a > 3:
    a = a * 2
else:
    a = a + 1
print(a)   # 10 (5 > 3 — верхняя ветка)
```

С циклами так же: `s = 0; for i in range(1, 5): s += i` даёт `1 + 2 + 3 + 4 = 10`. Выпиши значения по виткам — и ответ виден без запуска.

**Обратная задача**: дан выход — найди вход. Программа: чётное `x` делит пополам (`x // 2`), нечётное — считает `x * 2 + 1`. Вывод `10`. Какое было `x`? Первая мысль — чётная ветка: `x // 2 = 10`, откуда `x = 20`. Проверка: 20 чётное — ветка верная! А нечётная? `x * 2 + 1 = 10` даёт `x = 4,5` — не целое, отпадает. Ответ единственный: 20. Приём: разбери обе ветки уравнением, лишние корни отсеются сами.

## Ключевое (записать)

- Индексы с 0; последний — `s[-1]` или `s[len(s)−1]`; за границей — `IndexError`.
- Срез `s[a:b]` — с `a` по `b−1`; `+` клеит, `*` повторяет, `in` ищет.
- `ord` — код символа, `chr` — символ по коду; `for ch in s` — перебор.
- Анализ: таблица значений по шагам (прямая задача) и уравнение наоборот (обратная).

## Частые ошибки

- Начинать счёт с 1 (`s[1]` — это второй символ, не первый!).
- Ждать, что `s[1:4]` включит символ 4 (нет — только до `b−1`).
- Путать `=` и `==` в условиях при трассировке.
- В обратной задаче забывать проверить найденный вход прямым прогоном.
- Думать, что `len` считает с 1 для индекса последнего (индекс последнего — `len − 1`).

## Проверь себя

1. Чему равны `len('информатика')`, `s[0]` и `s[-1]` при `s = 'Python'`? (11, P, n)
2. Что даст `s[1:4]`? А `'on' in s`? (yth, True)
3. Программа выше вывела 10. Почему вход 20, а не 9? (9 нечётное: 9 * 2 + 1 = 19 ≠ 10.)
