# Как записывают алгоритмы

## Школьный алгоритмический язык (ШАЯ)

Строгие слова для нестрогих людей:

```
нц            — начало цикла
кц            — конец цикла
пока <условие> — цикл с условием продолжения
:=            — присваивание (x := x + 1 читается «x присвоить x+1»)
```

Пример (Робот красит коридор, пока справа свободно):

```
нц пока справа свободно
  вправо
  закрась
кц
```

## Блок-схемы: четыре фигуры

- **Овал** — начало / конец.
- **Параллелограмм** — ввод / вывод данных.
- **Прямоугольник** — действие (присваивание, вычисление).
- **Ромб** — условие (вопрос с ответами Да / Нет, два выхода).

## Следование: просто по порядку

Самая простая конструкция — команды идут одна за другой. Все ранние примеры (Вычислитель 21212, коридор Робота) — линейные внутри себя.

## Объекты алгоритмов: переменные и выражения

**Переменная** — именованная ячейка со значением. **Присваивание** `x := x + y` означает: вычисли правую часть СТАРЫМИ значениями, положи результат в x. Пример: было x=2, y=5 → правая часть 2+5=7 → стало x=7 (а y не изменился).

**Выражение** — запись вычисления по правилам: `*` и `/` раньше `+` и `-`, скобки — первыми.

## Ручное исполнение: трассировочная таблица

Готовый алгоритм прогоняют **вручную**: заводят таблицу «шаг → значения всех переменных» и выполняют команды по одной, как компьютер:

```
старт:        x = 2, y = 5
x := x + y →  x = 7, y = 5
y := x − y →  x = 7, y = 2
```

Каждая строка — честный пересчёт правой части старыми значениями. Так ловят ошибки до запуска: не сошлось с ожиданием — виновата строка, а не компьютер.

## Ключевое (записать)

- нц/кц — скобки цикла; `пока` — условие; `:=` — присваивание.
- Блок-схема: овал (старт/стоп), параллелограмм (ввод/вывод), прямоугольник (действие), ромб (условие).
- Присваивание: сначала правая часть, потом — в переменную.

## Частые ошибки

- Путать фигуры: ромб — только условие, параллелограмм — только ввод/вывод.
- Читать `:=` как равенство (это команда «положи», а не утверждение!).
- Забывать `кц` — цикл без конца.

## Проверь себя

2. Что лежит в x после `x := x + 1`, если было x = 5?
3. Какая фигура у условия?
4. Было x=2, y=5. После `x := x+y; y := x−y` чему равен y? (2)
