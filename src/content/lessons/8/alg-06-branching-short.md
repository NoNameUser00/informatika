# Когда «иначе» не нужно

**Неполная форма** ветвления — только «если» и «то», без «иначе»:

```
если <условие>
  то <действие>
```

Если условие истинно — действие выполняется. Если ложно — программа просто идёт дальше, ничего не выполняя.

Разница с полной формой одна, но важная: в неполной форме есть только один выход, который всегда ведёт дальше по алгоритму. Действие — «если получится», а не «в любом случае одно из двух».

## Пример: пополнение баланса

Задача: пополнить баланс только если на счёте меньше 30 рублей.

```
если balance < 30
  то balance := balance + 50
```

- balance = 12 → условие истинно → пополняем, стало 62.
- balance = 100 → условие ложно → ничего не делаем, осталось 100.

Если бы здесь была полная форма, пришлось бы писать «иначе ничего не делать» — лишнее действие в схеме.

## Ещё пример: проверка ввода

```
если x < 0
  то вывести('отрицательное')
```

Положительное и нулевое значение ветку не задевают.

## Как выбрать форму

Задай себе вопрос: «что должно произойти, если условие ложно?»

- Ничего → неполная форма.
- Что-то конкретное → полная форма.

## Ключевое (записать)

- Неполная форма: `если условие то действие`, без «иначе».
- При ложном условии — идём дальше, ничего не делая.
- Вопрос выбора: что делать при ложном условии — ничего или что-то конкретное?

## Частые ошибки

- Дописать «иначе» с пустым действием — это полная форма, а не неполная.
- Наоборот: забыть «иначе» там, где оно нужно, и потерять часть задачи.
- Считать, что при ложном условии цикл повторится: неполная форма — это не цикл.

## Проверь себя

1. Чем неполная форма отличается от полной?
2. Запиши неполную форму: «если число делится на 3 — вывести частное».
3. Когда лучше полная форма?
