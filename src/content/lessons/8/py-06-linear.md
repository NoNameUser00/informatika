# Выражения и вычисления

**Арифметическое выражение** — запись вычисления по правилам: сначала скобки, потом `*` и `/`, потом `+` и `-`.

```
s = (a + b) * 2 - 4
```

Остаток от деления — `%`, целая часть — `//`, возведение в степень — `**`.

```
17 // 5 = 3      17 % 5 = 2      2 ** 10 = 1024
```

## Сначала правая часть

Присваивание выполняется справа налево: сначала считаем выражение, потом кладём результат в переменную.

```
x = 2
y = 5
x = x + y      # правая часть: 2 + 5 = 7, теперь x = 7
```

Важно: справа используются **старые** значения. Поэтому `x = x + 1` увеличивает x на единицу, а не делает пустоту.

Одной строкой можно обменять значения:

```
a, b = b, a
```

## Линейный алгоритм

**Линейный алгоритм** — команды идут одна за другой, без ветвлений и циклов. Программа выполняется сверху вниз.

Пример «площадь и периметр прямоугольника»:

```
a = int(input())
b = int(input())
s = a * b
p = 2 * (a + b)
print(s)
print(p)
```

Порядок важен: переменную надо создать раньше, чем её использовать в выражении.

## Смысл и отладка

Перед запуском пройди программу руками и запиши значения переменных — так ловишь ошибку в выражении. Если результат не тот, ищи строку, где значение впервые стало не таким.

## Ключевое (записать)

- Порядок: скобки → `*` и `/` → `+` и `-`.
- `%` — остаток, `//` — целая часть, `**` — степень.
- Присваивание: сначала правая часть (со старыми значениями), потом переменная.
- Линейный алгоритм — команды по порядку, сверху вниз.

## Частые ошибки

- Использовать `=` как знак сравнения в условии (там нужно `==`).
- Делить на ноль.
- Создавать переменную после того, как использовали.
- Считать `17 / 5 = 3` — нет, это 3.4; целая часть — `17 // 5`.

## Проверь себя

1. Чему равно `17 // 5` и `17 % 5`?
2. Было x = 2, y = 5. Выполнили `x = x + y`. Чему равен x?
3. Вычисли `(2 + 3) * 2 ** 2`.
