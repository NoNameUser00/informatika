# Задачи со строками

Строки умеют то, чего не умеют числа: сравнивать, искать, заменять. Разберём четыре приёма, которые нужны постоянно.

## Приём 1. Сравнение

Строки сравниваются посимвольно слева направо, по кодам символов. `'Python' < 'Питон'`, потому что кириллица идёт после латиницы.

```
print('а' < 'б')     # True
print('abc' < 'abd') # True
```

Важно: `'10' < '9'` — **True**, потому что сравниваются символы: `'1'` меньше `'9'`. Числа так не сравниваются!

## Приём 2. Замена

```
s = 'banana'
print(s.replace('a', 'o'))   # bonono
```

Метод возвращает **новую** строку — исходная не меняется. Чтобы изменить, нужно присвоить результат обратно:

```
s = s.replace('a', 'o')
```

## Приём 3. Поиск и вхождение

```
s = 'информатика'
print('мат' in s)          # True
print(s.find('мат'))       # 5 — индекс начала
print(s.count('а'))        # 2 — сколько раз встретилось
print(s.index('а'))        # 8 — первый индекс, иначе ошибка
```

`find` возвращает −1, если не нашлось. `index` бросает ошибку — аккуратнее.

## Приём 4. Разворот и регистр

```
s = 'Python'
print(s[::-1])      # nohtyP
print(s.upper())     # PYTHON
print(s.capitalize())  # Python
```

Срез `s[::-1]` — это «считай с конца с шагом −1», то есть разворот строки.

## Задача: палиндром

Строка — палиндром, если читается одинаково в обе стороны. Проверяем разворотом:

```
s = 'довод'
print(s == s[::-1])   # True
```

Для `'Python'` сравнение даст False: `nohtyP` не равно `Python`.

## Ключевое (записать)

- Строки сравниваются посимвольно по кодам: `'10' < '9'` истинно.
- `replace` возвращает новую строку — присваивай обратно.
- `find` → −1 если нет, `index` → ошибка; `count` считает вхождения.
- `s[::-1]` — разворот. Сравнение `s == s[::-1]` проверяет палиндром.

## Частые ошибки

- Забыть присвоить результат `replace`: `s.replace(...)` без `s =` ничего не меняет.
- Сравнивать строки как числа: `'10' < '9'` истинно.
- Использовать `index` там, где подстроги может не быть: программа упадёт.
- Путать разворот `s[::-1]` со срезом `s[:-1]` (это все символы, кроме последнего).

## Проверь себя

1. Что выведет `'10' < '9'` и почему?
2. После `s = 'aaa'; s = s.replace('a', 'b')` чему равно s?
3. Является ли «довод» палиндромом? А «Python»?
