# Три операции

- **И (конъюнкция, ∧, &)**: истинна, только если истинны ОБА. `1 ∧ 1 = 1`, иначе 0.
- **ИЛИ (дизъюнкция, ∨)**: ложна, только если ложны ОБА. `0 ∨ 0 = 0`, иначе 1.
- **НЕ (отрицание, ¬)**: переворачивает. `¬1 = 0`, `¬0 = 1`.

## Приоритет (как в арифметике: сначала умножение)

1. НЕ, 2. И, 3. ИЛИ. Скобки — как обычно, в первую очередь.

Пример: `A ∨ A ∧ B` читается как `A ∨ (A ∧ B)`, а не `(A ∨ A) ∧ B`.

## Как считать выражение при известных значениях

Подставь 0/1 и иди по приоритету. Пример: A=1, B=0: `A ∧ ¬B = 1 ∧ ¬0 = 1 ∧ 1 = 1` (истина).

## Частые ошибки

- Считать ИЛИ «исключающим» (либо-либо): в логике `1 ∨ 1 = 1`.
- Игнорировать приоритет: сначала НЕ, потом И, потом ИЛИ.

## Проверь себя

1. Вычисли: `1 ∧ 0`, `1 ∨ 0`, `¬0`.
2. При A=0, B=1: `A ∨ ¬B`?
