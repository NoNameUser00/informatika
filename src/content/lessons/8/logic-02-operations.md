# Как посчитать составное высказывание

Из простых высказываний связками НЕ, И, ИЛИ строят составные. Заменим высказывания переменными 0/1 — связки станут **операциями**:

- **НЕ (инверсия, ¬)**: переворачивает. Таблица: ¬0 = 1, ¬1 = 0.
- **И (конъюнкция, ∧, &, логическое умножение)**: истина, только если истинны ОБА. 1∧1 = 1, остальные — 0.
- **ИЛИ (дизъюнкция, ∨, +, логическое сложение)**: ложь, только если ложны ОБА. 0∨0 = 0, остальные — 1. Внимание: 1∨1 = 1 (ИЛИ здесь НЕисключающее!).

Таблица обозначений учебника: НЕ — инверсия (¬), И — конъюнкция (∧, &, ·), ИЛИ — дизъюнкция (∨, +, |).

## Приоритет (как в арифметике)

1. НЕ (как унарный минус), 2. И (как умножение), 3. ИЛИ (как сложение). Скобки — в первую очередь.

Пример: `A ∨ A ∧ B` читается как `A ∨ (A ∧ B)`. А в выражении `A ∨ ¬B ∧ C` первой выполняется НЕ.

## Порядок вычисления при известных значениях

1. Запиши значения всех букв: `A = 1, B = 0`.
2. Посчитай скобки (если есть).
3. Иди по приоритету: НЕ, затем И, затем ИЛИ.

Примеры из учебника:

1. `(0 ∨ 1) ∧ 1 = 1 ∧ 1 = 1`
2. `¬(0 ∨ 1 ∧ 1) = ¬(0 ∨ 1) = ¬1 = 0`
3. `(1 ∨ 1) ∧ (0 ∨ 1) = 1 ∧ 1 = 1`
4. `1 ∨ 1 ∧ 0 ∨ 1 = 1 ∨ 0 ∨ 1 = 1`
5. `¬(0 ∨ 1) ∧ ¬1 = ¬1 ∧ 0 = 0 ∧ 0 = 0`

Пример с буквами: A = 1, B = 0, значит `A ∧ ¬B = 1 ∧ ¬0 = 1 ∧ 1 = 1` — истина.

## Ключевое (записать)

- НЕ: ¬0=1, ¬1=0. И: только 1∧1=1. ИЛИ: только 0∨0=0.
- Порядок: скобки → НЕ → И → ИЛИ.
- 1∨1 = 1 (ИЛИ неисключающее!).

## Частые ошибки

- Считать ИЛИ «исключающим» (либо-либо): в логике `1 ∨ 1 = 1`.
- Игнорировать приоритет: сначала НЕ, потом И, потом ИЛИ.
- Путать знаки ∧ и ∨ (галочка И смотрит вверх, ИЛИ — вниз, как чаша).
- Считать по буквам вместо их значений: сначала подставил 0/1 — потом считал.

## Проверь себя

1. Вычисли: `1 ∧ 0`, `1 ∨ 0`, `¬0`.
2. Вычисли `A ∧ ¬B` при A = 1, B = 1.
3. Какая операция выполняется первой в `A ∨ ¬B ∧ C`?
