# Другой момент остановки

Цикл с условием окончания работает **до тех пор, пока условие ложно**. То есть условие означает «продолжать», а заканчивается цикл, когда оно становится истинным.

Запись:

```
нц
  <тело цикла>
  пока <условие продолжения>
кц
```

В ШАЯ это `нц ... пока ... кц`. Обрати внимание на порядок: тело стоит **до** проверки, поэтому выполняется хотя бы один раз — в отличие от цикла «пока».

## Сравнение двух циклов

| | Условие продолжения | Условие окончания |
|---|---|---|
| Смысл условия | работаем, пока истинно | работаем, пока ложно |
| Где проверка | до тела | после тела |
| Минимум выполнений | 0 | 1 |
| Смысл условия при выходе | ложно | истинно |

## Пример: обязательный ввод

Задача: спрашивать число, пока пользователь не введёт положительное.

```
нц
  ввод n
пока n <= 0
кц
```

Проверка:

- Ввели −5 → цикл продолжается, спрашиваем ещё раз.
- Ввели 0 → продолжается (нуль не положительный).
- Ввели 7 → условие «7 <= 0» ложно → выходим.

Тело выполнилось минимум один раз — ведь спросить надо было до всякой проверки.

## Когда что удобнее

- «Пока в очереди есть люди» — условие продолжения.
- «Пока не выучили таблицу» — условие окончания.

В Python у цикла с условием окончания нет отдельного синтаксиса, но его легко построить через `while True` с `break` внутри. В КТП его полезно уметь записывать в ШАЯ и в виде блок-схемы.

## Ключевое (записать)

- Цикл с условием окончания работает, пока условие **ложно**.
- Тело выполняется **до** проверки, минимум один раз.
- Выход, когда условие становится истинным.
- Запись: `нц <тело> пока <условие> кц`.

## Частые ошибки

- Считать, что тело может не выполниться ни разу — нет, условие проверяется после.
- Перепутать смысл условия и зациклить программу (условие, которое никогда не становится истинным).
- В Python искать отдельный оператор: там используют `while True` и `break`.

## Проверь себя

1. Чем отличается цикл с условием окончания от цикла с условием продолжения?
2. Сколько раз выполнится тело в примере с вводом, если сразу ввели 7?
3. Запиши цикл «спрашивать, пока ответ не равен 5» в ШАЯ.
