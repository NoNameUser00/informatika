# Позиционные и непозиционные системы счисления

**Система счисления** — знаковая система, задающая правила записи чисел. Знаки — **цифры**, их набор — **алфавит**, количество цифр в алфавите — **основание**. Цифры обозначают **узловые** числа, остальные (**алгоритмические**) получаются из узловых операциями.

## Три вида (своими словами)

1. **Унарная (единичная)**: один знак повторяется (зарубки, счётные палочки). Число = количество знаков. Сегодня — возраст на пальцах, индикаторы уровня звука.
2. **Непозиционная**: значение знака НЕ зависит от места. **Египетская**: узлы 1, 10, 100, 1000… — спецзнаки (иероглифы), 3252 = три лотоса + две пальмы + пять дуг + два шеста в любом порядке. **Римская**: узлы I=1, V=5, X=10, L=50, C=100, D=500, M=1000. Меньший слева вычитается (IV=4, IX=9, XC=90), справа — прибавляется (XI=11, VI=6). Правило: не более трёх одинаковых подряд (IIII — брак, пиши IV). **Славянская**: буквы с титлом (аз=1 … цы=900), тысячи — те же буквы со спецзначками.
3. **Позиционная**: значение цифры зависит от разряда. Десятичная: 355 = 3·100 + 5·10 + 5·1 — левая пятёрка в 10 раз «тяжелее». Плюс позиционных: лёгкая арифметика и мало символов.

## Развёрнутая и свёрнутая формы (позиционные)

Любое число в системе с основанием q:

```
a(n-1)...a1 a0 = a(n-1)*q^(n-1) + ... + a1*q + a0
```

Запись по этой формуле — **развёрнутая форма**, обычная запись — **свёрнутая**. Пример: 4351 = 4·10³ + 3·10² + 5·10¹ + 1·10⁰. Двоичный пример: `1011₂ = 1*2^3 + 0*2^2 + 1*2 + 1 = 8+0+2+1 = 11₁₀` (задача inf-8-numsys-011).

## Римская: как читать и писать

- Таблица разрядов: единицы I II III IV V VI VII VIII IX; десятки X XX XXX XL L LX LXX LXXX XC; сотни C CC CCC CD D DC DCC DCCC CM; тысячи M MM MMM.
- Сборка по разрядам слева направо: 99 = 90 + 9 = XC + IX = XCIX.
- Пример: XIV = X (10) + IV (4) = 14 (задача inf-8-numsys-013).
- Где живёт сегодня: века, тома, главы, циферблаты.

## Ключевое (записать)

- Непозиционная: значение цифры не зависит от места. Позиционная: зависит от разряда.
- Развёрнутая форма: цифра × вес разряда, всё сложить.
- Римская: меньший слева — вычесть, справа — прибавить; не более трёх одинаковых подряд.

## Частые ошибки

- Путать основание с количеством разрядов.
- Читать IX как 11 (надо 9: меньший слева вычитается).
- Думать, что римская позиционная (нет — значение V всегда 5).
- Минимальное основание: смотри старшую цифру записи и бери на 1 больше (числу 123 подойдёт основание 4).
