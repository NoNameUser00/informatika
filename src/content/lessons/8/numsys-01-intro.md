# Позиционные и непозиционные системы счисления

**Система счисления** — способ записи чисел с помощью знаков (цифр). Набор всех цифр — **алфавит**, количество цифр — **основание**.

## Три вида (своими словами)

1. **Унарная**: одно и то же обозначение повторяется (зарубки). Число = количество знаков.
2. **Непозиционная**: значение знака не зависит от места. Пример — **римская**: I=1, V=5, X=10, L=50, C=100, D=500, M=1000. Меньший слева от большего вычитается (IV=4, IX=9), справа — прибавляется (XI=11, VI=6).
3. **Позиционная**: значение цифры зависит от разряда (позиции). Пример — десятичная: 333 = 3 сотни + 3 десятка + 3 единицы.

## Развернутая форма (позиционные)

Число в системе с основанием q:

```
a(n-1)...a1 a0 = a(n-1)*q^(n-1) + ... + a1*q + a0
```

Пример: `1011₂ = 1*2^3 + 0*2^2 + 1*2 + 1 = 8+0+2+1 = 11₁₀` (задача inf-8-numsys-011).

## Римская: как читать

- Таблица разрядов: единицы I..IX, десятки X..XC, сотни C..CM, тысячи M..MMM.
- Пример: XIV = X (10) + IV (4) = 14 (задача inf-8-numsys-013).

## Частые ошибки

- Путать основание с количеством разрядов.
- Читать IX как 11 (надо 9: меньший слева вычитается).
- Думать, что римская позиционная (нет — значение V всегда 5).
