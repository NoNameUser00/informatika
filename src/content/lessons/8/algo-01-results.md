# Что может получиться на выходе

**Анализ алгоритмов** — разобраться в работе алгоритма, не выполняя его целиком. Первый тип такой задачи: дан набор входных данных, найти все возможные результаты.

## Метод: трассировка по шагам

Берём конкретное значение, записываем его, выполняем команды по одной и в каждой строке отмечаем, что изменилось.

```
a = 5
if a > 3:
    a = a * 2
else:
    a = a + 1
print(a)
```

Для a = 5: условие 5 > 3 истинно → верхняя ветка → a = 10. Ответ 10.

Другие входы:

| a | условие a > 3 | ветка | результат |
|---|---|---|---|
| 5 | истина | a = a * 2 | 10 |
| 0 | ложь | a = a + 1 | 1 |
| −4 | ложь | a = a + 1 | −3 |
| 3 | ложь | a = a + 1 | 4 |

Возможные результаты: 10, 1, −3, 4.

## С циклами

Цикл разбирают по виткам — по одной строке на итерацию.

```
s = 0
for i in range(1, 5):
    s = s + i
print(s)
```

| виток | i | s |
|---|---|---|
| старт | — | 0 |
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |
| 4 | 4 | 10 |

Ответ 10 = 1 + 2 + 3 + 4.

## Число разных результатов

Если спрашивают, сколько различных результатов возможно, не обязательно перебирать все входы — достаточно понять, сколько разных путей ведёт алгоритм к выходу.

Пример: одно условие с двумя ветками даёт не больше двух разных результатов. Два независимых условия — до четырёх.

## Ключевое (записать)

- Анализ без запуска: трассировка — таблица «шаг → значения».
- Для каждой ветки — своя строка таблицы.
- С циклом — строка на каждый виток.
- Число возможных результатов связано с числом путей в алгоритме.

## Частые ошибки

- Проверить только одну ветку и объявить один результат.
- Считать, что цикл выполнится на один раз больше или меньше: строки должно быть ровно столько, сколько витков.
- Путать `=` и `==` при записи условия в таблице трассировки.
- Забыть, что результат зависит от входных данных: без них возможных результатов может быть много.

## Проверь себя

1. Сколько различных результатов даст ветвление с одним условием?
2. Что выведет программа с циклом `for i in range(1, 5): s = s + i`, если s = 0?
3. Перечисли возможные результаты примера из первого раздела.
