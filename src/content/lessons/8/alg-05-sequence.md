# Следование

**Следование** — самая простая алгоритмическая конструкция: команды выполняются одна за другой, строго в том порядке, в котором записаны. Ничего не выбирается, ничего не повторяется.

Признак: в записи нет ни условия, ни цикла — только последовательность действий.

## Пример: Вычислитель 21212

Алгоритм в ШАЯ читает число, пока нечётное — делит на 2, пока чётное и больше 1 — отнимает 5, иначе прибавляет 3.

```
нц пока x > 1
  если x нечётно
    то x := x / 2
  всё
  если x чётно
    то x := x − 5
  все
кц
```

Проследим для x = 1: условие `1 > 1` ложно → выходим сразу, ответ 1.
Для x = 7: нечётно → 3,5; нечётно → 1,5; нечётно → 0,5 → цикл закончился, ответ 0.

## Обратная задача

Часто нужно не «что получится», а «какое число даст такой результат». Тогда идём с конца: какое значение на входе могло дать этот выход — восстанавливаем возможные входные значения и проверяем каждый.

Именно это позже станет отдельной темой: определение возможных входных данных.

## Практическая работа

**Задание**: разработать для формального исполнителя алгоритм, приводящий к результату при конкретных исходных данных.

Порядок разработки:

1. Выписать, что дано и что получить.
2. Определить исполнителя и его команды.
3. Записать алгоритм в выбранной форме (словесная, блок-схема, программа).
4. Выполнить на конкретных данных и проверить результат.
5. Преобразовать алгоритм из одной формы записи в другую — это тоже часть работы.

## Ключевое (записать)

- Следование — команды по порядку, без ветвлений и циклов.
- Алгоритм выполняется сверху вниз.
- Обратная задача: идём от результата к возможным входам.

## Частые ошибки

- Переставить команды местами: в следовании порядок определяет всё.
- Искать условие там, где его нет (следование не выбирает).
- В обратной задаче забыть про несколько возможных входных значений.

## Проверь себя

1. Чем следование отличается от ветвления?
2. Вычислитель 21212: чем закончится работа при x = 1?
3. Что делать, если нужно найти не результат, а входные данные?
