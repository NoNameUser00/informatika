# От логики к железу

**Логический элемент** — устройство, которое обрабатывает двоичные сигналы и выдаёт значение одной из логических операций. Три кирпичика, из которых собраны сумматоры, память и процессор:

- **НЕ (инвертор)**: один вход, выход наоборот. Вход 0 → выход 1, и наоборот. На схеме — прямоугольник с кружком на выходе.
- **И (конъюнктор, &)**: единица на выходе, только когда на ВСЕХ входах единицы.
- **ИЛИ (дизъюнктор, 1)**: ноль на выходе, только когда на всех входах нули (иначе единица).

Компьютер не «понимает» слова — он прогоняет нули и единицы через такие элементы. Программа «если … то …» в итоге превращается в их комбинации.

## Как проектируют схемы (путь инженера)

1. Описывают нужное поведение таблицей истинности (какой выход при каких входах).
2. По таблице записывают логическое выражение.
3. Упрощают выражение (тождествами!) — меньше элементов, дешевле схема.
4. Строят цифровую схему из И/ИЛИ/НЕ.

## Полезный закон: поглощение

`A ∨ (A ∧ B) = A`. Проверка: при A=1 левая часть всегда 1 (1 ∨ … = 1); при A=0 получаем 0 ∨ (0 ∧ B) = 0 ∨ 0 = 0. Слева и справа одно и то же при любом A — значит, тождество верно, и кусок схемы можно выкинуть.

## Ключевое (записать)

- Инвертор: выход = наоборот. Конъюнктор: 1, только если все входы 1. Дизъюнктор: 0, только если все входы 0.
- Путь инженера: таблица → выражение → упрощение → схема.
- Поглощение: A ∨ (A ∧ B) = A.

## Частые ошибки

- Думать, что компьютер «понимает» слова: он складывает нули и единицы через элементы И/ИЛИ/НЕ.
- Путать, где кружок инверсии: у НЕ — на выходе элемента.

## Проверь себя

1. Что на выходе элемента И при входах 1 и 0? А элемента ИЛИ при 0 и 0?
2. Чему равносильно `A ∨ (A ∧ B)`? Докажи подстановкой A=0 и A=1.
