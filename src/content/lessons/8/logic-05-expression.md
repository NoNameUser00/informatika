# Форма высказывания

Условие задачи почти всегда можно записать **логическим выражением** — формулой из букв и операций, у которой есть значение 1 (истина) или 0 (ложь).

Приёмы записи:

- **«И»** — когда нужно, чтобы оба условия выполнялись: `x > 0 ∧ y > 0` или `x > 0 и y > 0`.
- **«ИЛИ»** — когда достаточно хотя бы одного: `x = 1 ∨ x = 5` или `x = 1 или x = 5`.
- **«НЕ»** — когда условие отрицается: `¬(x > 10)`.
- **«Тогда и только тогда»** — это равносильно ИЛИ двух импликаций.

## Переход от условия к выражению

1. Выпиши условия отдельными строками.
2. Определи связку между ними: «и», «или», «не».
3. Замени слова операциями, слова-константы — на 1/0.
4. Расставь скобки по правилу приоритета.

Пример: «Число x положительное и делится на 5» → `x > 0 ∧ (x mod 5 = 0)`.

Пример с «или»: «x равно 1 или x равно 5» → `x = 1 ∨ x = 5` (а не `x = 1 ∧ x = 5` — это невозможно).

## Полезные тождества формы записи

- `A ∨ 0 = A` — нулевой операнд ничего не меняет.
- `A ∧ 0 = 0` — ноль обнуляет умножение.
- `A ∨ 1 = 1` — единица перетягивает сложение.
- `A ∧ 1 = A` — единичный операнд ничего не меняет.

Их используют, чтобы привести запись к удобному виду перед подстановкой значений.

## Нельзя смешивать уровни

Операция НЕ меняет только следующую за ней конструкцию: `¬A ∧ B` — это `(¬A) ∧ B`, а не `¬(A ∧ B)`. Чтобы отрицать всё выражение, нужны скобки.

## Ключевое (записать)

- Условие → выражение: выписать условия, найти связку, заменить слова операциями, расставить скобки.
- «и» → `∧`, «или» → `∨`, «не» → `¬`.
- `A ∨ 0 = A`, `A ∧ 1 = A`, `A ∧ 0 = 0`, `A ∨ 1 = 1`.

## Частые ошибки

- Ставить `∧` там, где в условии «или» (получается заведомо ложное выражение).
- Забыть скобки у НЕ и потом считать не то выражение.
- Путать `x = 1 ∨ x = 5` и `x = 1 ∧ x = 5`: первое истинно для двух значений, второе — никогда.

## Проверь себя

1. Запиши выражением: «a больше 2 и a чётное».
2. Запиши выражением: «b равно 0 или b равно 10».
3. Чему равно `(¬A) ∧ B` при A = 0, B = 1?
