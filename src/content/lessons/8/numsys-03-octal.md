# Восьмеричная система (основание 8, цифры 0-7)

Позиционная система с основанием 8. Алфавит: 0, 1, 2, 3, 4, 5, 6, 7 (цифр 8 и 9 здесь нет!).

## Перевод 8 -> 10: по весам восьмёрки

Развёрнутая форма с основанием 8. Подпиши номера разрядов и считай:

```
разряды: 3 2 1 0
цифры:   1 0 6 3
1063₈ = 1·8³ + 0·8² + 6·8¹ + 3·8⁰ = 512 + 0 + 48 + 3 = 563
```

Пример: `27₈ = 2*8 + 7 = 23` (inf-8-numsys-004).

## Перевод 10 -> 8: делением на 8

Как в двоичной, только делитель 8. Пример 103:

```
103 : 8 = 12 (ост. 7)
 12 : 8 = 1  (ост. 4)
  1 : 8 = 0  (ост. 1)   → читаем вверх: 147₈
```

## Связь с двоичной: триады

8 = 2³, поэтому каждая восьмеричная цифра = ровно 3 двоичных бита (**триада**):

```
0=000, 1=001, 2=010, 3=011, 4=100, 5=101, 6=110, 7=111
```

## Перевод 2 -> 8: группируем по 3 справа

Разбей цепочку справа налево на тройки (слева допиши нули), каждую тройку замени цифрой:

```
1101101100₂ → 001 101 101 100 → 1 5 5 4 → 1554₈
```

Пример: `1101011₂`: разбиваем справа `1|101|011` → 1, 5, 3 → `153₈` (проверка: 153₈ = 64+40+3 = 107 = 1101011₂).

## Перевод 8 -> 2: каждую цифру в триаду

Замени каждую цифру тройкой битов, ведущие нули отбрось:

```
147₈ = 001 100 111 → 1100111₂
```

Проверка через десятичную: 1·64+1·32+0·16+0·8+1·4+1·2+1 = 103. Сошлось с примером выше.

## Ключевое (записать)

- 8→10: развёрнутая форма с весами 8⁰, 8¹, 8², …
- 10→8: делить на 8, остатки снизу вверх.
- 8↔2: цифра ↔ триада (таблица выше); группируем всегда СПРАВА, слева дописываем нули.

## Частые ошибки

- Группировать слева, а не справа.
- Забывать дописать нули до 3 бит.
- Использовать цифры 8/9 в восьмеричной (их нет).
- Путать триады (по 3) с тетрадами (по 4).

## Проверь себя

1. `27₈` в десятичную; 103₁₀ в восьмеричную.
2. `1101011₂` в восьмеричную через триады; `147₈` в двоичную.
