# Восьмеричная система (основание 8, цифры 0-7)

## Перевод 8 -> 10: по весам восьмерки

Пример: `27₈ = 2*8 + 7 = 23` (inf-8-numsys-004).

## Связь с двоичной: триады

8 = 2^3, поэтому каждая восьмеричная цифра = ровно 3 двоичных бита:

```
0=000, 1=001, 2=010, 3=011, 4=100, 5=101, 6=110, 7=111
```

## Перевод 2 -> 8: группируем по 3 справа

Пример: `1101011₂`: разбиваем справа `1|101|011` = 1 5 3 = `153₈` (inf-8-numsys-008). Если слева не хватает битов — допиши нули.

## Перевод 8 -> 2: каждую цифру в триаду

Пример: `153₈` -> `001 101 011` -> убери ведущие нули -> `1101011₂`.

## Частые ошибки

- Группировать слева, а не справа.
- Забывать дописать нули до 3 бит.
- Использовать цифры 8/9 в восьмеричной (их нет).

## Проверь себя

1. `27₈` в десятичную.
2. `1101011₂` в восьмеричную через триады.
