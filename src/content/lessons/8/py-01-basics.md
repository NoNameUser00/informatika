# Первая программа

**Язык программирования** — формальный язык для записи алгоритмов компьютеру. Записи называются **программами**. Python (читается «пайтон») — один из самых популярных; работаем с Python 3.

Чтобы запустить программу, нужна **система программирования**: редактор, транслятор, отладчик. У нас она — прямо в браузере (страница «Код»).

## Присваивание: как работает память

`a = 10` — в ячейку с именем a положи 10. `s = a + b` — сложи значения ячеек a и b, результат положи в s.

```
a = 10
b = 5
s = a + b    # теперь s = 15
```

Правила: в правой части — только уже созданные переменные; можно множественное: `a, b = 19, 25`; можно цепочкой: `a = b = 5` (сначала b = 5, потом a = 5).

## Ввод и вывод

`print(...)` — вывод. `input()` — ввод строки с клавиатуры (программа ждёт Enter). Для чисел сразу преобразуем:

```
a = int(input())      # целое
x = float(input())    # вещественное
```

`int()` и `float()` без ошибок работают, только если в строке одни цифры.

## Отладка

Исправил ошибку → запустил снова → получил что надо. Этот цикл называется **отладкой**. Ошибка — нормально, это часть работы.

## Ключевое (записать)

- Программа = запись алгоритма. Python 3.
- `=` — положить (справа считается первым). `a, b = 19, 25`.
- `print`, `input`, `int()`, `float()`.
- Отладка: исправь → запусти → проверь.

## Частые ошибки

- Читать `=` как равенство (это команда!).
- Использовать переменную раньше создания.
- Забывать скобки у `input`/`print`.
- `int('12ab')` — ошибка: только цифры!
