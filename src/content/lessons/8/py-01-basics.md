# Что такое язык программирования

**Язык программирования** — формальный язык для записи алгоритмов так, чтобы их понял компьютер. Запись называется **программой**, а результат её работы — результат алгоритма.

Python (читается «пайтон») — один из самых популярных языков. Работаем с **Python 3**: команды набираются на английском, отступы в программе значимы.

## Система программирования

Чтобы написать и запустить программу, нужна **система программирования**. В ней три части:

- **Редактор** — окно для набора текста программы.
- **Транслятор** — переводит текст программы в машинный код, понятный процессору. Бывает компилятор (сразу машинный код) и интерпретатор (по одной инструкции).
- **Отладчик** — помогает найти ошибку: где программа остановилась и что пошло не так.

У нас система программирования работает прямо в браузере — на странице «Код» (тренажёр кода 8 класса).

## Первая программа

Программа, которая выводит приветствие:

```
print('Привет, мир!')
```

Запустили — увидели результат. Значит, алгоритм записан верно и компьютер его выполнил.

## Отладка

**Отладка** — цикл: написал программу → запустил → нашёл ошибку → исправил → запустил снова.

Ошибка — не беда, а часть работы. Сообщение об ошибке читай внимательно: в нём указан номер строки, где что-то пошло не так. Чаще всего это опечатка в имени переменной, забытые скобки или неправильный отступ.

## Ключевое (записать)

- Язык программирования — формальный язык записи алгоритмов. Программа — запись алгоритма.
- Система программирования = редактор + транслятор + отладчик.
- Python 3. Отступы в тексте программы значимы.
- Отладка: запустил → нашёл ошибку → исправил → запустил снова.

## Частые ошибки

- Путать транслятор и отладчик (отладчик ищет ошибки, а не выполняет перевод).
- Считать, что отступы в Python — украшение: на самом деле они определяют вложенность.
- Сдавать программу с первой попытки и удивляться ошибке: отладка — обязательный шаг.
