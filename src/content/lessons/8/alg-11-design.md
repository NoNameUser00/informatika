# Как самому построить алгоритм

Разработка алгоритма — не вдохновение, а последовательность шагов. Если их соблюдать, решение находится всегда.

## Шаг 1. Понять задачу

Отделить **что дано** от **что найти**. Записать ограничения: числа целые? положительные? Может ли ответ отсутствовать?

Пример: «найти количество чётных чисел от 1 до n» — дано n (целое положительное), найти количество чётных среди 1, 2, …, n.

## Шаг 2. Выбрать конструкции

| Задача выглядит так | Берём |
|---|---|
| «если…, иначе…» | ветвление |
| «пока не закончится» | цикл с условием |
| «повторить k раз» | цикл с заданным числом повторений |
| «для каждого элемента» | цикл `for` |

Часто нужны все вместе: перебрать элементы (for) и решить, учитывать ли каждый (if).

## Шаг 3. Выбрать переменные

Для каждой переменной записать: имя, тип, начальное значение, как меняется.

Пример: `n` — вход; `k` — счётчик, начальное 0, увеличивается на 1; `i` — текущий проверяемый элемент.

Начальное значение критично: без него сравнение в цикле может сработать не сразу.

## Шаг 4. Записать и проверить

Записать в выбранной форме. Затем прогнать **вручную** на маленьком примере и на краевых значениях (0, 1, максимум). Только потом — на компьютере.

## Пример целиком

**Задача:** найти количество чётных чисел от 1 до n.

```
n = int(input())
k = 0
for i in range(1, n + 1):
    if i % 2 == 0:
        k = k + 1
print(k)
```

Конструкции: цикл `for` (перебрать числа) и ветвление (учитывать ли чётное).

Проверка вручную: n = 5 → i = 1 (нечётное, пропускаем), 2 (чётное, k = 1), 3 (пропуск), 4 (k = 2), 5 (пропуск) → ответ 2. Верно.

Крайние случаи: n = 1 → ответ 0; n = 100 → 50.

## Ключевое (записать)

- Порядок: понять задачу → выбрать конструкции → выбрать переменные → записать → проверить вручную.
- У каждой переменной: имя, тип, начальное значение, как меняется.
- Проверять надо и на компьютере, и вручную — сначала вручную.

## Частые ошибки

- Начинать писать код, не разобравшись, что дано и что найти.
- Забыть начальное значение счётчика.
- Не проверить n = 0 или n = 1.
- Использовать цикл, когда достаточно ветвления (или наоборот).
