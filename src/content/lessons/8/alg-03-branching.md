# Ветвление выбирает

**Ветвление** — алгоритмическая конструкция, в которой действия зависят от условия. Условие — это вопрос с двумя ответами: «Да» и «Нет».

В блок-схеме условие всегда рисуют **ромбом** с двумя выходами. Ромб — только условие; параллелограммом обозначают ввод и вывод, прямоугольником — действие.

## Полная форма: если — то — иначе

```
если <условие>
  то <действие 1>
иначе <действие 2>
```

Выполняется **ровно одна** ветка из двух. Программа проверяет условие: истинно — идёт по «то», ложно — по «иначе», и сразу выходит из ветвления.

## Пример: игра с кучей

Задача: оставить сопернику число предметов, кратное 3. Если число уже кратно 3 — уступить ход, иначе — взять столько, чтобы остаток стал кратным 3.

```
если x mod 3 = 0
  то уступить ход
иначе
  взять (x mod 3) предметов
```

Проверим оба случая:

- x = 12. Остаток 0 → условие истинно → уступаем ход. Ветка «иначе» не выполнена.
- x = 14. Остаток 2 → условие ложно → берём 2, остаётся 12.

## Условие — логическое выражение

В условии работает логика прошлых уроков: сравнения (`>`, `<`, `=`) и связки И, ИЛИ, НЕ.

Пример «x внутри отрезка [0; 1]»: `(x >= 0) И (x <= 1)`. Одно сравнение мало — нужна конъюнкция двух.

Проверка: x = 0,5 → оба истинны → истинно. x = 2 → первое истинно, второе ложно → ложно. x = −1 → первое ложно → ложно.

## Проверка трассировкой

Возьми конкретные значения и пройди алгоритм вручную, записывая значение после каждого шага. **Обязательно проверь обе ветки** — иначе неисправная ветка не обнаружится.

## Ключевое (записать)

- Ромб — условие, два выхода: Да / Нет.
- Полная форма: выполняется ровно одна из двух веток.
- Условие — логическое выражение (сравнения + И/ИЛИ/НЕ).
- Проверка — трассировкой на конкретных данных, обе ветки.

## Частые ошибки

- Забыть ветку «иначе», где она нужна: тогда при ложном условии не будет никаких действий.
- Написать условие, которое всегда истинно (или всегда ложно) — одна ветка мёртвая.
- Проверить только одну ветку трассировкой.
- Считать условие «x > 0 ИЛИ x < 0» верным для всех x: забыть про x = 0.

## Проверь себя

1. Составь ветвление: если число чётное — раздели пополам, иначе — прибавь 1.
2. Протрассируй его для x = 6 и x = 7.
3. Запиши условие «x внутри отрезка [0; 1]».
