# Конструкция «ветвление»

Ветвление выбирает действия по условию (вопросу с ответом Да/Нет). В блок-схеме условие — всегда **ромб** с двумя выходами.

## Полная форма: если — то — иначе

```
если <условие>
  то <действие 1>
  иначе <действие 2>
```

Выполняется ровно одна ветка. Пример (игра с кучей из учебника): если число предметов кратно 3 — уступи ход, иначе возьми 1–2 предмета так, чтобы осталось кратное 3.

## Неполная форма: если — то (без иначе)

```
если <условие>
  то <действие>
```

Если условие ложно — просто идём дальше, ничего не делая.

## Условия пишут логикой прошлого блока

Условие — логическое выражение: сравнения (`>`, `<`, `=`), связки И/ИЛИ/НЕ. Пример: `(x >= 0) И (x <= 1)` истинно, только если x внутри отрезка [0, 1].

## Как не ошибиться: трассировка

Возьми конкретные значения и пройди алгоритм вручную, записывая значения после каждого шага. Это называется **трассировкой** (ручным исполнением) — так проверяют и отлаживают.

## Ключевое (записать)

- Ромб — условие, два выхода: Да / Нет.
- Полная форма: выполняется ровно одна из двух веток. Неполная: при «нет» — ничего.
- Условия — логика: сравнения + И/ИЛИ/НЕ.
- Проверка — трассировкой на конкретных данных.

## Частые ошибки

- Забывать ветку «иначе» там, где она нужна (и наоборот — городить иначе из ничего).
- Писать условие, которое никогда не истинно (или всегда истинно) — одна ветка мёртвая.
- Не проверять обе ветки трассировкой.

2. Протрассируй его для x = 6 и x = 7.
3. Чем полная форма отличается от неполной?
