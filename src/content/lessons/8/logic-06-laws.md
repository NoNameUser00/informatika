# Что такое закон

Закон — равенство, которое верно при любых значениях букв. В логике законы нужны, чтобы **упрощать** выражения до формы, в которой легко подставить значения.

Проверяются подстановкой: подставь все четыре комбинации `A = 0/1`, `B = 0/1` — равенство держится.

## Основные законы

**Одна переменная:**

- Закон исключённого среднего: `A ∨ ¬A = 1`
- Закон противоречия: `A ∧ ¬A = 0`
- Закон двойного отрицания: `¬¬A = A`
- Закон идемпотенции: `A ∨ A = A`, `A ∧ A = A`

**Две переменные (перестановка, поглощение, распределение):**

- Коммутативность: `A ∨ B = B ∨ A`, `A ∧ B = B ∧ A`
- Ассоциативность: `(A ∨ B) ∨ C = A ∨ (B ∨ C)`, то же для `∧`
- Дистрибутивность: `A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C)`
- Поглощение: `A ∧ (A ∨ B) = A`, `A ∨ (A ∧ B) = A`

**Особые:**

- Закон де Моргана: `¬(A ∧ B) = ¬A ∨ ¬B`, `¬(A ∨ B) = ¬A ∧ ¬B`

## Как упрощать

1. Убери скобки по распределительности: `A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C)`.
2. Примени поглощение и идемпотенцию: повторы исчезают.
3. Сверни константы: `A ∨ 1 = 1`, `A ∧ 0 = 0`.
4. Примени закон исключённого среднего и противоречия: получаешь 1 или 0.

Пример: `A ∧ (A ∨ B) = A` — по поглощению, без раскрытия скобок.

## Зачем это

Одна и та же задача может выглядеть по-разному. Эквивалентные записи — те, что дают одинаковую таблицу истинности. Умение приводить к простой форме избавляет от громоздкой таблицы.

## Ключевое (записать)

- `A ∨ ¬A = 1`, `A ∧ ¬A = 0`, `¬¬A = A`.
- `A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C)`.
- Поглощение: `A ∧ (A ∨ B) = A`.
- Де Морган: `¬(A ∧ B) = ¬A ∨ ¬B`.

## Частые ошибки

- Считать `A ∨ ¬A` выражением, которое «бывает и 1, и 0». Оно **всегда** 1.
- Раскрывать скобки, не проверив, что выражение уже упрощается по поглощению.
- Путать `A ∧ (B ∨ C)` с `(A ∧ B) ∨ C` — потеряется часть скобок.

## Проверь себя

1. Упрости `A ∨ (A ∧ B)`.
2. Упрости `¬(A ∧ B)`.
3. Упрости `(A ∧ B) ∨ (A ∧ C) ∨ (B ∧ C)`, если известно, что A = 0.
