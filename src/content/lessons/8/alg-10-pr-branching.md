# Практическая работа

Задание по КТП: создать и выполнить на компьютере несложные алгоритмы с использованием ветвлений и циклов для управления исполнителями.

## Порядок работы

1. **Условие.** Выписать, что дано и что получить.
2. **Исполнитель.** Выбрать, какие команды доступны.
3. **Алгоритм.** Записать с ветвлением и циклом.
4. **Проверка.** Прогнать на конкретных данных — обязательно обе ветки.
5. **Преобразование.** Перевести из одной формы записи в другую.

## Задание 1. Исполнитель с ветвлением

Исполнитель умеет: `вперёд n`, `направо 90`, `закрасить`. Дан прямоугольник 4 × 4, нужно обойти по периметру и закрасить углы.

```
алг Периметр
нач
  | вправо 3; закрасить
  | вперёд 3; направо 90
  | вправо 3; закрасить
  | вперёд 3; направо 90
кон
```

Проверка: четыре команды «вправо» и две «направо 90» дают полный обход с замыканием.

## Задание 2. Цикл с условием продолжения

Найти количество цифр в числе n. Идея: делим число на 10, пока оно не станет нулём.

```
алг Цифры
нач
  | ввод n
  | k := 0
  | нц пока n > 0
  |   n := n // 10
  |   k := k + 1
  | кц
  | вывести(k)
кон
```

Проверка на данных: n = 12345 → 5; n = 7 → 1; n = 100 → 3.

## Задание 3. Цикл с заданным числом повторений

Вывести первые четыре чётных числа, начиная с нуля: 0, 2, 4, 6.

```
нц 4 раз
  вывести(2 * i)
  i := i + 1
кц
```

## Типичные ошибки практической

- Написали алгоритм и сразу сдали, не проверив вторую ветку.
- В цикле не меняется переменная из условия.
- В блок-схеме действие нарисовали ромбом, а условие — прямоугольником.
- Забыли проработать оба случая: «положительное» и «неположительное».

## Ключевое (записать)

- Порядок: условие → исполнитель → алгоритм → проверка → преобразование формы записи.
- Ветвление и цикл можно сочетать в одном алгоритме.
- Проверять нужно обе ветки и крайние значения (0, 1, максимум).

## Частые ошибки

- Проверять только «средний» случай и пропускать 0 или отрицательные числа.
- Считать, что блок-схема и программа пишутся одинаково: в схеме — фигуры, в программе — команды.
