# Вложенные циклы и работа со строками

Продолжение темы циклов: объединение цикла с ветвлением и вложенные циклы.

## Цикл и ветвление вместе

Классическая задача: из чисел от 1 до n вывести только чётные.

```
n = int(input())
for i in range(1, n + 1):
    if i % 2 == 0:
        print(i)
```

Проверка при n = 7: i = 1 (нечётно, пропуск), 2 (чётно, вывод), 3 (пропуск), 4 (вывод), 5 (пропуск), 6 (вывод), 7 (пропуск). Итого 2, 4, 6.

## Счётчик внутри цикла

```
n = int(input())
k = 0
for i in range(1, n + 1):
    if i % 3 == 0:
        k = k + 1
print(k)
```

При n = 10: кратны 3 числа 3, 6, 9 → k = 3.

## Вложенные циклы

Цикл внутри цикла: внешний гоняет строки, внутренний — столбцы.

```
for i in range(3):
    for j in range(2):
        print(i, j)
```

Всего 3 × 2 = 6 выводов:

```
0 0
0 1
1 0
1 1
2 0
2 1
```

## Перебор символов строки

```
s = 'абракадабра'
k = 0
for ch in s:
    if ch == 'а':
        k = k + 1
print(k)   # 5
```

Считаем вручную: а, б, р, а, к, а, д, а, б, р, а — буква «а» на позициях 1, 4, 6, 8, 11. Итого 5.

## Задача: делители числа

```
n = int(input())
for i in range(1, n + 1):
    if n % i == 0:
        print(i)
```

При n = 12: 1, 2, 3, 4, 6, 12. Проверка: 12 делится на все эти числа без остатка.

## Ключевое (записать)

- Цикл + ветвление: сначала перебор, потом условие внутри.
- Вложенные циклы: произведение размеров даёт число выполнений (3 × 2 = 6).
- Счётчик накапливается в отдельной переменной, обнулённой до цикла.
- Перебор символов: `for ch in s`.

## Частые ошибки

- Забыть обнулить счётчик перед циклом (`k = 0`).
- Поставить `if` на уровне цикла, а не внутри тела — потеряем весь перебор.
- Считать, что вложенные циклы выполняются 3 + 2 раз, а не 3 × 2.
- Перепутать `%` и `//` при проверке делимости.
