# Переменная и её тип

**Переменная** — именованная ячейка памяти для значения. Имя придумываем сам (лучше латиницей), значение кладём командой присваивания.

**Тип данных** определяет, что можно делать со значением:

- `int` — целое число: 5, −12.
- `float` — вещественное (дробное): 3.14, −0.5.
- `str` — строка (текст): `'Привет'`. Кавычки обязательны.
- `bool` — истина или ложь: True, False.

## Присваивание: как работает память

`a = 10` — в ячейку с именем a положи 10. `s = a + b` — сложи значения ячеек a и b, результат положи в s.

```
a = 10
b = 5
s = a + b    # теперь s = 15
```

Правила:

- В правой части — только уже созданные переменные.
- Множественное присваивание: `a, b = 19, 25` (слева направо).
- Цепочкой: `a = b = 5` (сначала b = 5, потом a = 5).

`=` — это команда «положи», а не равенство. Поэтому в Python для проверки равенства два знака равно: `a == 5`.

## Ввод и вывод

`print(...)` — вывод. `input()` — ввод строки с клавиатуры (программа ждёт Enter). По умолчанию `input()` даёт **строку**, поэтому для числа сразу преобразуем:

```
a = int(input())      # целое
x = float(input())    # вещественное
```

Что понимает `int()`: цифры, знак и окружающие пробелы — `int(' 12 ')`, `int('-5')` работают. Не понимает буквы (`int('12ab')` — ошибка) и запятую как десятичный разделитель: для дробей нужен `float()` с точкой.

## Меняем тип

```
a = 5
b = str(a)      # b теперь '5' — строка
c = int('5') + 1  # 6 — число
```

## Ключевое (записать)

- Типы: `int`, `float`, `str`, `bool`.
- `=` — команда «положи». Проверка равенства — `==`.
- `print` — вывод, `input` — ввод строки.
- `int(input())` — целое, `float(input())` — вещественное.

## Частые ошибки

- Читать `=` как равенство (это команда!).
- Использовать переменную раньше создания.
- Забывать скобки у `input` и `print`.
- Складывать строку с числом: `'5' + 1` — ошибка, нужно `int('5') + 1`.
