# Циклы в Python

## while с break: считаем цифры числа

План: «укорачиваем» число справа (`n // 10`), считаем шаги, пока не дойдём до нуля:

```
n = 12345
k = 0
while True:
    n = n // 10
    k = k + 1
    if n == 0:
        break
print(k)   # 5
```

Тот же приём даёт и сумму цифр — добавь `s = s + n % 10` перед укорачиванием (остаток `%` — как раз отброшенная цифра!).

## for: когда число повторов известно

```
for i in range(1, 4):
    print(i, bin(i))
# 1 0b1
# 2 0b10
# 3 0b11
```

`range(1, 4)` даёт 1, 2, 3 (правая граница не входит!).

## Евклид на Python (связка с алгоритмами)

```
a, b = 48, 18
while b:
    a, b = b, a % b
print(a)   # 6
```

Цикл крутится, пока b не ноль; каждая итерация приближает конец (остаток меньше делителя) — бесконечности нет.

## Ключевое (записать)

- `while True: … if …: break` — выход по условию внутри.
- `n // 10` — отбросить последнюю цифру; `n % 10` — взять её.
- `for i in range(a, b)` — от a до b−1.
- Тело цикла обязано приближать выход.

## Частые ошибки

- Думать, что `range(1, 4)` включает 4 (нет!).
- Путать `//` (целая часть) и `/` (обычное деление).
- Забывать `break` — вечный цикл (в тренажёре его остановит таймаут 10 с).
- Менять переменную условия так, что выход не приближается.
