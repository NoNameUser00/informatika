# while: цикл с условием продолжения

Цикл `while` в Python работает, пока условие истинно:

```
while <условие>:
    тело цикла
```

Тело выполняется **до** первого раза, поэтому условие должно быть ложно изначально, если цикл не нужен.

## Подсчёт цифр числа

План: «укорачиваем» число справа операцией `n // 10` и считаем шаги, пока не дойдём до нуля.

```
n = 12345
k = 0
while n > 0:
    n = n // 10
    k = k + 1
print(k)   # 5
```

Проверка по шагам: 12345 → 1234 → 123 → 12 → 1 → 0. Пять делений, пять шагов.

## Сумма цифр

Тот же цикл, но перед укорачиванием добавляем отброшенную цифру — это `n % 10`:

```
n = 9876
s = 0
while n > 0:
    s = s + n % 10
    n = n // 10
print(s)   # 9 + 8 + 7 + 6 = 30
```

## while True и break

Выход можно сделать прямо внутри тела:

```
while True:
    x = int(input())
    if x > 0:
        break
print(x)
```

Программа спрашивает число, пока не введёт положительное. Без `break` цикл был бы вечным.

## Алгоритм Евклида

**НОД** — наибольший общий делитель. Евклид находит его без разложения на множители: пока второе число не ноль, заменяем пару на «остаток, делитель».

```
a, b = 48, 18
while b != 0:
    a, b = b, a % b
print(a)   # 6
```

Проследим:

| a | b | a % b | новая пара |
|---|---|---|---|
| 48 | 18 | 12 | (18, 12) |
| 18 | 12 | 6 | (12, 6) |
| 12 | 6 | 0 | (6, 0) → выход |

Ответ 6.

Почему бесконечности нет: остаток всегда **меньше** делителя, поэтому второе число на каждом шаге строго уменьшается и рано или поздно станет нулём.

Проверка ещё одного примера: НОД(20, 6): (20, 6) → (6, 2) → (2, 0) → ответ 2.

## Ключевое (записать)

- `while условие:` — тело выполняется, пока условие истинно.
- `n // 10` — отбросить последнюю цифру; `n % 10` — взять её.
- `while True:` + `break` — выход по условию внутри тела.
- Евклид: `while b != 0: a, b = b, a % b`. Остаток меньше делителя, поэтому цикл конечен.

## Частые ошибки

- Путать `//` (целая часть) и `/` (обычное деление): для цифр нужен именно `//`.
- Забыть `break` — вечный цикл (в тренажёре его остановит таймаут 10 секунд).
- Взять остаток не в том порядке: `a % b` даёт остаток от деления a на b.
- Считать, что Евклид разлагает на множители — не разлагает, только вычитает остатки.
