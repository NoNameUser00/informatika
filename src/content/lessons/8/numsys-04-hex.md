# Шестнадцатеричная система (основание 16)

Алфавит: 0-9 и A=10, B=11, C=12, D=13, E=14, F=15. Десять цифр обычные, шесть — первые буквы латиницы.

## Перевод 16 -> 10: по весам

Подпиши номера разрядов и считай (буквы замени числами):

```
разряды: 2 1 0
цифры:   3 A F
3AF₁₆ = 3·16² + 10·16¹ + 15·16⁰ = 768 + 160 + 15 = 943
```

## Перевод 10 -> 16: делением на 16

Остатки 10–15 записываем буквами. Пример 175: 175 : 16 = 10 (ост. 15=F); 10 : 16 = 0 (ост. 10=A). Читаем вверх: `AF₁₆` (inf-8-numsys-002). Пример 154: 154 : 16 = 9 (ост. 10=A); 9 : 16 = 0 (ост. 9). Ответ `9A₁₆`.

## Связь с двоичной: тетрады

16 = 2⁴, каждая цифра = ровно 4 бита (**тетрада**):

```
0=0000 1=0001 2=0010 3=0011 4=0100 5=0101 6=0110 7=0111
8=1000 9=1001 A=1010 B=1011 C=1100 D=1101 E=1110 F=1111
```

## Перевод 16 -> 2: каждую цифру в тетраду

Пример `3A₁₆`: 3=0011, A=1010 → `00111010` → убери ведущие нули → `111010₂` (=58, inf-8-numsys-006). Нули ВНУТРИ тетрады терять нельзя: B = 1011, а не 11!

## Перевод 2 -> 16: группируем по 4 справа

Пример: `101010₂` → дописать ноль слева → `0010 1010` = 2 A = `2A₁₆`. Большой пример: `11101101100110₂` (14 знаков) → дописать два нуля → `0011 1011 0110 0110` → `3B66₁₆`.

## Связка 16 <-> 8: через двоичную

Напрямую таблиц нет — идём через двоичную: 16→2 (тетрады) → 2→8 (триады). Пример: `F5₁₆` = 1111 0101 → группируем справа по 3: 11|110|101 → дописать ноль слева: 011 110 101 → 3 6 5 → `365₈` (проверка: 365₈ = 3·64+6·8+5 = 245 = F5₁₆).

## Правила ввода

- Регистр не важен: `af` = `AF`.
- Кириллица А/В/С/Е/Ф засчитывается как латиница.
- `0xAF`, `AF₁₆`, `AF(16)` — одно и то же.

## Ключевое (записать)

- A=10 … F=15 (A — десять, не одиннадцать!).
- 16→10: развёрнутая форма; 10→16: делить на 16, остатки-буквы читать снизу вверх.
- 16↔2: цифра ↔ тетрада (таблица выше); группируем всегда СПРАВА.
- 16↔8: только через двоичную.

## Частые ошибки

- A=10, а не 11 (сдвиг на единицу).
- Терять нули внутри тетрады: B = 1011, а не 11.
- Группировать по 3 вместо 4 (это триады для восьмеричной).
- Забывать дописать нули слева до полной группы.

## Проверь себя

1. 175 и 92 в шестнадцатеричную.
2. `3A₁₆` в двоичную через тетрады; `2F₁₆` в десятичную.
