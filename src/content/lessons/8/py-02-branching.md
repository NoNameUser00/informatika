# Условный оператор

Ветвление в Python — оператор `if` (сравнимашины: `and` = И, `or` = ИЛИ, `not` = НЕ):

```
if <условие>:
    <действие>
else:
    <действие>
```

Отступы (4 пробела) — часть языка: именно они показывают, что внутри ветки!

## Пример 1: точка на отрезке

```
x = 5
if x >= 0 and x <= 10:
    print('внутри')
else:
    print('снаружи')
```

Условие `(x >= 0) and (x <= 10)` истинно, только если оба сравнения верны (вспомни И из логики!).

## Пример 2: максимум из трёх (без функции max)

```
a, b, c = 3, 7, 5
y = a
if b > y:
    y = b
if c > y:
    y = c
print(y)   # 7
```

Два неполных ветвления подряд: каждое сравнивает кандидата с текущим чемпионом.

## Ключевое (записать)

- `if условие:` → отступ 4 пробела → `else:` → отступ.
- Условия: сравнения + and/or/not.
- Отступы обязательны — без них Python не поймёт границы веток.

## Частые ошибки

- Забывать двоеточие после условия.
- Путать `=` и `==` в условии (`=` — положить, `==` — сравнить!).
- Ломать отступы (смешивать табы и пробелы).
- Писать `else` без `if` выше.

1. Что выведет пример 2 при a, b, c = 3, 7, 5?
2. Запиши условие «x вне отрезка [0, 1]».
3. Найди максимум из 4, 9, 2 этим способом.
