# Условный оператор в Python

Ветвление в Python — оператор `if`. Неполная форма — только `if`, без `else`:

```
if <условие>:
    <действие>
```

Если условие ложно, ничего не выполняется и программа идёт дальше.

**Отступы обязательны.** Четыре пробела после `if:` — часть языка, а не оформление: ими обозначается тело ветки. Смешивать табы и пробелы нельзя.

Логические связки пишутся словами: `and` — И, `or` — ИЛИ, `not` — НЕ.

## Пример: пополнение баланса

```
balance = int(input())
if balance < 30:
    balance = balance + 50
print(balance)
```

- balance = 12 → пополнили, вывели 62.
- balance = 100 → ничего не изменилось, вывели 100.

## Пример: «максимум без функции max»

```
a, b, c = 3, 7, 5
y = a
if b > y:
    y = b
if c > y:
    y = c
print(y)
```

Два неполных ветвления подряд: каждое сравнивает кандидата с текущим чемпионом и при нужде обновляет его. Выведет 7.

## Не забыть else

Если нужно что-то делать и в случае ложного условия, добавляется `else` с тем же отступом, что и `if`:

```
if <условие>:
    <действие 1>
else:
    <действие 2>
```

Отступы внутри `if` и внутри `else` должны быть одинаковыми.

## Ключевое (записать)

- Неполная форма: `if условие:` + отступ + действие.
- Отступ 4 пробела — часть языка.
- Связки словами: `and`, `or`, `not`.
- Полная форма добавляет `else:` на уровне `if`.

## Частые ошибки

- Забыть двоеточие после условия — синтаксическая ошибка.
- Путать `=` и `==`: в условии нужен `==` (два знака равно).
- Смешать табы и пробелы в отступах.
- Написать `else` без парного `if`.
- Поставить `else` с неправильным отступом — ветка «уедет» не туда.
