# Когда число повторений известно заранее

**Цикл с заданным числом повторений** выполняет тело ровно столько раз, сколько раз указано в условии. Никакой проверки «продолжать или нет» нет — счётчик и так дойдёт до конца.

В ШАЯ:

```
нц 4 раз
  <тело цикла>
кц
```

В Python то же самое:

```
for i in range(4):
    тело цикла
```

`range(4)` даёт числа 0, 1, 2, 3 — ровно четыре значения.

## Пример: квадрат числа четыре раза

```
нц 4 раз
  ввод n
  вывести(n * n)
кц
```

Четыре раза спросит число и четыре раза покажет квадрат.

## range: границы

`range(a, b)` даёт числа от a до b − 1 — правая граница не включается.

```
range(1, 5)   → 1, 2, 3, 4
range(5)      → 0, 1, 2, 3, 4
range(2, 10, 2) → 2, 4, 6, 8
```

Это частая ловушка: «вывести числа от 1 до 5» — это `range(1, 6)`, а не `range(1, 5)`.

## for против while

Один и тот же результат можно получить двумя способами:

```
# for: повторим 5 раз
for i in range(5):
    print(i)

# while: то же счётчиком
i = 0
while i < 5:
    print(i)
    i += 1
```

Выбирай `for`, когда известно число повторений: короче и невозможно забыть увеличить счётчик.

## Вложенные циклы

Цикл внутри цикла: внешний гоняет строки, внутренний — столбцы. Тело внешнего выполнится столько раз, сколько повторов во внешнем, плюс все внутренние прогоны.

```
for i in range(3):
    for j in range(2):
        print(i, j)
```

Всего 3 × 2 = 6 выводов.

## Ключевое (записать)

- Цикл с заданным числом повторений: ровно указанное число раз.
- ШАЯ: `нц 4 раз ... кц`. Python: `for i in range(4):`.
- `range(a, b)` не включает b: для 1..5 нужно `range(1, 6)`.
- `for` — когда число повторений известно, `while` — когда нет.

## Частые ошибки

- `range(1, 5)` вместо `range(1, 6)` — теряется последнее число.
- Считать, что `range(5)` даёт 1..5: даёт 0..4.
- Путать вложенный цикл с повторением: 3 × 2 = 6, а не 5.
- Использовать `for` там, где число повторений неизвестно заранее.

## Проверь себя

1. Что выведет `range(1, 5)` и почему?
2. Сколько раз выполнится тело `нц 4 раз`?
3. Сколько выводов даст цикл `for i in range(3)` с вложенным `for j in range(2)`?
