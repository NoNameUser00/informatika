# Сложение и умножение в двоичной

## Сложение столбиком

Правила поразрядно: 0+0=0, 0+1=1, 1+1=10 (0 и перенос 1), 1+1+1=11 (1 и перенос 1).

Пример: `1011₂ + 110₂` (inf-8-numsys-007):

```
  1011  (11)
+ 0110  (6)
------
 10001  (17)
```

Проверка через десятичную: 11+6=17, 17 = `10001₂`. Совпало.

Важно: в проверочной ответ просят десятичным — `17`, без основания (как в Яндекс.Форме учителя).

## Умножение

Как в десятичной, но проще: умножаем на 0/1 и складываем со сдвигом.

```
  101 * 11 = 101 + 1010 = 1111 (5*3=15)
```

## Прием самопроверки

Переведи оба слагаемых в десятичную, сложи там, переведи обратно. Если не совпало — ищи перенос.

## Частые ошибки

- Забывать перенос при 1+1.
- Складывать как десятичные (11+6=17, а не 1121).
- Терять выравнивание разрядов справа.

2. Проверь результат через десятичную.
