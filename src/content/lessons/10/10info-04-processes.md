# Как передаётся и управляется информация

## Информационные процессы

Базовые действия: **получение**, **хранение**, **обработка**, **передача**.

Каждое из них может иметь помехи, потери и требовать контроля.

## Передача информации

Передача идёт по **каналу связи** от источника к получателю. Канал вносит искажения.

## Помехи

**Помехи** — посторонние воздействия, искажающие сигнал: шум, наводки, потери в линии.

Как с этим борются:

1. **Избыточность** — передаём больше бит, чем нужно: контрольные суммы, повторы, коды с проверкой на чётность.
2. **Помехоустойчивое кодирование** — сигнал настроен так, чтобы искажение выдливалось.

Принцип: чем выше помехи, тем больше избыточности нужно. Избыточность — плата за надёжность: канал должен быть быстрее, чтобы передать полезную информацию.

## Скорость передачи данных

**Скорость передачи** — объём данных, проходящий по каналу за единицу времени. Измеряется в битах в секунду (бит/с), часто с приставками.

Пропускная способность — сколько данных канал пропустит без искажений за секунду. Это разные вещи: канал может иметь высокую скорость, но плохую помехоустойчивость.

```
время = объём : скорость
```

Пример: файл 1 Кбайт по каналу 1024 бит/с.

```
объём = 1024 · 8 = 8192 бит
t = 8192 : 1024 = 8 секунд
```

## Система

**Система** — объект, состоящий из частей, связанных друг с другом, и взаимодействующий с окружающей средой.

Компьютер — система: процессор, память, устройства работают вместе. Компьютер в сети — тоже система.

## Управление как информационный процесс

**Управление** — воздействие на объект ради нужного результата. Управление всегда информационный процесс: есть цель, есть текущее состояние, есть команда.

По схеме управления:

- **программное** — по заранее заданной программе, без учёта текущего состояния;
- **обратная связь** — решение принимается с учётом того, что происходит на самом деле.

**Обратная связь** — возвращение сведений о состоянии объекта в управляющую систему.

Схема:

```
команда → объект → состояние → (сигнал обратно) → решение
```

Без обратной связи система слепа: она командует, не зная результата. Пример: термостат без датчика температуры — не работает, только жжёт.

## Ключевое (записать)

- Помехи искажают сигнал; борются избыточностью и помехоустойчивым кодированием.
- Скорость — бит/с; время = объём : скорость.
- Пропускная способность — сколько пройдёт без искажений.
- Управление — информационный процесс; обратная связь возвращает состояние объекта.

## Частые ошибки

- Путать скорость передачи с пропускной способностью.
- Забыть перевести объём в биты перед делением.
- Считать, что управление возможно без обратной связи: система слепа.
- Путать, куда идёт сигнал обратной связи: от объекта к управляющей системе.

## Проверь себя

1. Что такое помехи и как с ними борются?
2. Файл 1 Кбайт, канал 1024 бит/с. Сколько секунд?
3. Чем отличаются скорость передачи и пропускная способность?
