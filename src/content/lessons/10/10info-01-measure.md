# Объёмный подход

**Объёмный (алфавитный) подход** отвечает на вопрос: сколько места займёт сообщение, если его записать в виде кодов?

Ключевое отличие от вероятностного подхода: **смысл сообщения не учитывается**. Важны только длина и алфавит.

## Две формулы

```
N = 2^i        мощность алфавита ↔ вес символа
I = K · i      объём = число символов × вес символа
```

Из двух формул находится всё остальное.

## Порядок решения

**Дано → Формулы → Вычисление → Ответ.**

Пример: сообщение 140 символов, алфавит 32 символа.

```
N = 32 = 2^i   →   i = 5 (бит)
K = 140
I = 140 · 5 = 700 (бит) = 700 : 8 = 87,5 (байта)
Ответ: 700 бит.
```

## Обратная задача

Дано I = 720 бит, K = 180 символов.

```
i = I : K = 720 : 180 = 4 (бит)
N = 2^4 = 16 (символов в алфавите)
```

## Единицы

```
1 байт = 8 бит
1 Кбайт = 1024 байта
1 Мбайт = 1024 Кбайта
1 Гбайт = 1024 Мбайта
```

## Разница между подходами

| | Вероятностный (КТП 8) | Объёмный (этот урок) |
|---|---|---|
| Вопрос | сколько вариантов отсекает сообщение | сколько места занимает сообщение |
| Учитывает смысл | да | нет |
| Единица | бит на исход | бит на символ |
| Когда применять | научный расчёт, теория связи | практика: тексты, файлы, время передачи |

Одно и то же сообщение может иметь разный «вес» по двум подходам. Например, редкое слово из длинного алфавита несёт много информации, но занимает много места.

## Ключевое (записать)

- `N = 2^i` — мощность алфавита, `I = K · i` — объём.
- Объёмный подход не учитывает смысл сообщения.
- 1 Б = 8 бит, 1 КБ = 1024 Б, 1 МБ = 1024 КБ, 1 ГБ = 1024 МБ.
- Оформление: Дано | Формулы | Решение | Ответ.

## Частые ошибки

- Считать, что длинное слово «весит» больше из-за смысла: подход учитывает только длину.
- Путать K и I: K — штуки символов, I — биты.
- Делить на 1000 вместо 1024.
- Не привести ответ к единицам из вопроса.
