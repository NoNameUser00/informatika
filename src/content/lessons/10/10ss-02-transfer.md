# Перевод чисел

## Целое: из P-ичной в десятичную

Разложи по степеням основания и сложи:

```
243₁₀ = 2·8² + 4·8¹ + 3·8⁰ = 128 + 32 + 3 = 163₁₀
```

Проверка на двоичной: `1011₂` = 1·2³ + 0·2² + 1·2¹ + 1·2⁰ = 8 + 0 + 2 + 1 = 11₁₀ ✓

## Целое: из десятичной в P-ичную

**Деление с остатками снизу вверх**: делим число на P, записываем остаток, делим целую часть, и так пока не станет 0. Остатки читаются **снизу вверх**.

Пример: перевести `11₁₀` в двоичную.

```
11 : 2 = 5, остаток 1
 5 : 2 = 2, остаток 1
 2 : 2 = 1, остаток 0
 1 : 2 = 0, остаток 1

остатки снизу вверх: 1 0 1 1
Ответ: 11₁₀ = 1011₂
```

Проверка: 1011₂ = 8 + 2 + 1 = 11 ✓

Пример в шестнадцатеричной: `254₁₀` → делим на 16.

```
254 : 16 = 15, остаток 14 → E
 15 : 16 = 0,  остаток 15 → F
остатки снизу вверх: F E
Ответ: 254₁₀ = FE₁₆
```

## Конечная дробь: умножение на основание

Целую часть переводим как целое число, дробную — **умножением на основание**. Целые части произведений выписываем по порядку.

Пример: `0,625₁₀` в двоичную.

```
0,625 · 2 = 1,25   → пишем 1
0,25  · 2 = 0,5    → пишем 0
0,5   · 2 = 1,0    → пишем 1
Ответ: 0,101₂
```

Проверка: 1·2⁻¹ + 0·2⁻² + 1·2⁻³ = 0,5 + 0 + 0,125 = 0,625 ✓

## Бесконечная дробь

Процесс может не закончиться: `0,1₁₀` в двоичной даёт бесконечную дробь `0,000101010…₂`.

Признак: если в процессе умножения на основание снова получится исходная дробь — процесс циклический.

```
0,1 · 2 = 0,2  → 0
0,2 · 2 = 0,4  → 0
0,4 · 2 = 0,8  → 0
0,8 · 2 = 1,6  → 1
0,6 · 2 = 1,2  → 1
0,2  — снова!
Ответ: 0,00011 0,00011…₂ — периодическая дробь
```

Такую дробь округляют до нужного числа разрядов: `0,00011₂` ≈ `0,00011000₂`.

Точные дроби удобнее хранить в виде отношения числителя и знаменателя.

## Ключевое (записать)

- В P-ичную из десятичной: делить на P с остатками, читать снизу вверх.
- Дробь: умножать на P, выписывать целые части произведений.
- Процесс может стать периодическим — тогда округляют.
- Точные дроби хранят как числитель и знаменатель.

## Частые ошибки

- Читать остатки сверху вниз вместо снизу вверх.
- Забыть перевести целую часть при переводе дроби.
- Не заметить периодичность и «остановиться» на произвольном месте.
- Путать, что умножается: дробь — умножением, целое — делением.

## Проверь себя

1. Переведи 11₁₀ в двоичную делением с остатками.
2. Переведи 254₁₀ в шестнадцатеричную.
3. Переведи 0,625₁₀ в двоичную умножением на 2.
