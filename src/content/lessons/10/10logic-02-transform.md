# Эквивалентные преобразования

**Законы алгебры логики** — равенства, верные при любых значениях букв. С их помощью выражение упрощают до удобной формы.

Проверяются подстановкой: подставь все наборы значений — равенство должно держаться каждый раз.

## Законы одной переменной

| Закон | Равенство |
|---|---|
| Исключённого среднего | `A ∨ ¬A = 1` |
| Противоречия | `A ∧ ¬A = 0` |
| Двойного отрицания | `¬¬A = A` |
| Идемпотенции | `A ∨ A = A`, `A ∧ A = A` |

Главная ловушка: «A или не A» бывает и единицей, и нулём. **Нет — всегда 1.** Если A истинно, истинно первое; если A ложно, истинно второе. Ноль невозможен ни при каком A.

## Законы двух переменных

**Коммутативность** (перестановка):
```
A ∨ B = B ∨ A        A ∧ B = B ∧ A
```

**Ассоциативность** (склейка):
```
(A ∨ B) ∨ C = A ∨ (B ∨ C)        (A ∧ B) ∧ C = A ∧ (B ∧ C)
```

**Дистрибутивность** (главный рабочий закон):
```
A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C)
```

**Поглощение:**
```
A ∧ (A ∨ B) = A        A ∨ (A ∧ B) = A
```

## Закон де Моргана

```
¬(A ∧ B) = ¬A ∨ ¬B
¬(A ∨ B) = ¬A ∧ ¬B
```

Смысл: отрицание конъюнкции превращает «и» в «или» и наоборот.

## Порядок упрощения

1. Убери скобки по распределительности: `A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C)`.
2. Примени поглощение и идемпотенцию — повторы исчезают.
3. Сверни константы: `A ∨ 1 = 1`, `A ∧ 0 = 0`.
4. Примени исключённое среднее и противоречие — получишь 1 или 0.

## Работа с импликацией

Импликация выражается через базовые операции:

```
A → B = ¬A ∨ B
```

Проверка: `1→0 = 0`, а `¬1 ∨ 0 = 0 ∨ 0 = 0` ✓; `0→1 = 1`, а `¬0 ∨ 1 = 1 ∨ 1 = 1` ✓

## Пример упрощения

```
A ∨ (A ∧ B) = A                    по поглощению
```

Применять распределительность здесь не нужно — выражение уже в форме, которая сразу поглощается.

## Эквивалентность и исключающее ИЛИ

```
A ↔ B = (A ∧ B) ∨ (¬A ∧ ¬B)        истинно при равных
A ⊕ B = (A ∧ ¬B) ∨ (¬A ∧ B)        истинно при разных
```

Заметим: `A ⊕ B = ¬(A ↔ B)`.

## Ключевое (записать)

- `A ∨ ¬A = 1`, `A ∧ ¬A = 0`, `¬¬A = A`.
- Дистрибутивность: `A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C)`.
- Поглощение: `A ∧ (A ∨ B) = A`.
- Де Морган: `¬(A ∧ B) = ¬A ∨ ¬B`.
- `A → B = ¬A ∨ B`; `A ⊕ B = ¬(A ↔ B)`.

## Частые ошибки

- Считать `A ∨ ¬A` выражением, которое «бывает и 1, и 0».
- Раскрывать скобки, когда выражение уже упрощается по поглощению.
- Путать `A ∧ (B ∨ C)` с `(A ∧ B) ∨ C`: теряется скобка.
- Считать `A → B = ¬A ∧ B`: правильно `¬A ∨ B`.

## Проверь себя

1. Упрости `A ∨ (A ∧ B)`.
2. Упрости `¬(A ∧ B)`.
3. Представь импликацию `A → B` через базовые операции.
4. Упрости `(A ∧ B) ∨ (A ∧ C) ∨ (B ∧ C)` при A = 0.
