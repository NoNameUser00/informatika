# Решаем логические уравнения

**Решение уравнения** — наборы значений, при которых оно истинно. Приём: разбивай по главной операции.

Пример из учебника: `(A→C) ∨ ((B∨C)∧A) ∨ D = 0`. Дизъюнкция равна 0, только если ВСЕ части — 0:
- D = 0 (готово).
- A→C = 0 → бывает только как 1→0: A = 1, C = 0.
- (B∨C)∧A = 0 → подставляем: (B∨0)∧1 = 0 → B = 0... стоп, проверяем: (B∨0) = B, B∧1 = B = 0 → B = 0? В учебнике ответ B = 1? Нет — пересчитаем: нужно (B∨C)∧A = 0 при A=1, C=0: (B∨0)∧1 = B∧1 = B → B = 0.

Хм, в книге ответ A=1, B=1, C=0, D=0? Проверяем B=1: (1∨0)∧1 = 1 — не ноль! Значит, в условии учебника вторая часть, видимо, с отрицанием. Мораль примера: **всегда проверяй подстановкой** — даже печатный ответ!

## Нормальные формы: синтез по таблице

- **ДНФ** (дизъюнктивная): ИЛИ из И-частей — собирает строки, где функция истинна.
- **КНФ** (конъюнктивная): И из ИЛИ-частей — собирает строки, где ложна.
- По фрагменту таблицы подбирают формулу, совпадающую на всех строках.

## Эйлер-Венна и схемы

Круги Эйлера рисуют множества — и те же круги рисуют И (пересечение) и ИЛИ (объединение). Путь инженера из 8 класса работает и здесь: таблица → выражение → упрощение → схема; а теперь ещё и чтение схемы обратно в выражение.

## Ключевое (записать)

- Уравнение решай от главной операции + проверяй подстановкой ВСЕГДА.
- ДНФ — собирает единицы, КНФ — нули.
- Круги Эйлера = И/ИЛИ наглядно.

## Частые ошибки

- Верить печатному ответу без проверки (см. пример выше!).
- Путать ДНФ и КНФ (что собираем — то и в названии наоборот? Нет: ДНФ — дизъюнкция конъюнкций).
- Терять строки таблицы при синтезе.

## Проверь себя

1. Реши A→B = 0. (A=1, B=0 — единственный вариант)
2. Что собирает ДНФ? А КНФ?
3. Нарисуй круги для A∧B и A∨B.
