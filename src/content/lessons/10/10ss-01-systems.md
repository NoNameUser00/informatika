# Системы счисления

**Система счисления** — совокупность правил записи чисел и наименования их разрядов.

## Классификация

**По позиционности:**

- **Непозиционная** — значение символа не зависит от его места. Пример: римская система (IX всегда девять, независимо от позиции).
- **Позиционная** — значение зависит от позиции символа. Пример: `101` — в разряде единиц 1, в разрядах десятков и сотен 0.

Дальше работаем только с позиционными: без них не обойтись в вычислительной технике.

## Алфавит и основание

**Алфавит** — набор символов, используемых для записи чисел.

**Основание (P)** — число различных цифр в алфавите. Двоичная система: цифры 0 и 1, основание 2. Десятичная: 0–9, основание 10. Шестнадцатеричная: 0–9 и A–F, основание 16.

Цифры алфавита позиционной системы всегда нумеруются от 0 до P − 1. В системе с основанием 16 есть цифра 15, обозначаемая F.

## Развёрнутая форма записи

Вес каждого разряда равен степени основания:

```
     P⁴  P³  P²  P¹  P⁰
       d₄ d₃ d₂ d₁ d₀
```

Значение числа:

```
( d₄·P⁴ + d₃·P³ + d₂·P² + d₁·P¹ + d₀·P⁰ )P
```

Пример для `243₁₀` в двоичной системе:

```
243₁₀ = 11110011₂
2⁷ + 2⁶ + 2⁵ + 2⁴ + 2¹ + 2⁰ = 128 + 64 + 32 + 16 + 2 + 1 = 243 ✓
```

## Единицы записи

Число записывают с указанием основания: `1011₂`, `12₈`, `AF₁₆`, `11₁₀`. Подстрочные цифры в учебнике; на практике используют двойную точку `11.10₂` или префикс `0b1011`, `0xAF`.

Путать основания нельзя: `1011₂` = 11, а `1011₁₀` = 1011.

## Почему в технике двоичная система

Двоичная система основана на сигналах с двумя устойчивыми состояниями: «есть сигнал» и «нет сигнала». Такие схемы надёжны, просты и дешевы.

Другие системы применяются в людских интерфейсах: восьмеричная (3 бита, кратно 8) и шестнадцатеричная (4 бита, кратно 16) удобны при работе с машинными кодами, байтами и адресами памяти.

## Ключевое (записать)

- Система счисления — правила записи чисел.
- Непозиционная (римская) и позиционная (двоичная, десятичная).
- Основание P = число цифр в алфавите; цифры от 0 до P − 1.
- Развёрнутая форма: веса разрядов равны степеням P (P⁰, P¹, …).
- Техника использует двоичную систему: два устойчивых состояния.

## Частые ошибки

- Путать основание с числом цифр: они равны, но называются по-разному.
- Забыть основание у числа: `1011` без основания неоднозначно.
- Считать, что в системе с основанием 16 нет букв: есть, A–F.
- Путать позиционную и непозиционную системы в римской записи.

2. Чему равно основание системы счисления с алфавитом 0–9?
3. Запиши 243₁₀ в двоичной системе разложением по степеням двойки.
