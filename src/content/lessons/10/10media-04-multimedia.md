# Презентация как мультимедийный объект

## Что такое мультимедиа

**Мультимедиа** — совместное использование нескольких видов информации: текста, графики, звука, видео, анимации.

Мультимедийный продукт воспринимается целостнее, чем текст отдельно: картинка показывает то, что слова описывают долго.

## Виды мультимедийной информации

| Вид | Чем создаётся | Особенности |
|---|---|---|
| Текст | клавиатура, распознавание речи | легко править |
| Графика | редакторы, сканер, камера | растровая и векторная |
| Звук | микрофон, синтезатор | запись, монтаж |
| Видео | видеокамера | монтаж, сжатие |
| Анимация | графический редактор, код | покадрово или по ключевым кадрам |

## Онлайн-сервисы для презентаций

Презентацию можно делать не только в настольной программе. **Онлайн-сервисы** дают:

- работу в браузере без установки;
- совместное редактирование;
- готовые шаблоны и галереи;
- экспорт в разные форматы.

Плюсы: не нужно ничего ставить, доступ с любого устройства, работа в команде.
Минусы: нужен интернет, часть функций недоступна, зависимость от сервиса.

## Структура презентации проектной работы

1. **Титульный слайд**: тема, авторы, руководитель, класс, год.
2. **План**: о чём пойдёт речь.
3. **Проблема**: зачем эта работа.
4. **Данные**: 2–3 содержательных слайда с фактами.
5. **Методы**: как делали.
6. **Результаты**: графики, таблицы, выводы.
7. **Заключение**: итоги, спасибо за внимание.

Правило: не больше шести строк на слайде. Слайд — опора для рассказа, а не документ.

## Мультимедийное наполнение

- **Изображения** усиливают текст: график лучше таблицы цифр.
- **Звук** уместен для коротких пояснений, не для фона под весь доклад.
- **Видео** — короткие вставки, иллюстрирующие процесс, а не десятиминутный ролик.
- **Анимация** показывает порядок появления объектов, а не украшает.

## Практическая работа

1. Выбери тему проекта.
2. Собери структуру из 7 слайдов по схеме выше.
3. Создай презентацию в онлайн-сервисе.
4. Добавь на содержательные слайды графики или изображения.
5. Задай единый дизайн: один шрифт, одна цветовая гамма.
6. Проверь показ: читаемость с расстояния, отсутствие лишнего текста.

## Ключевое (записать)

- Мультимедиа — текст, графика, звук, видео, анимация вместе.
- Онлайн-сервисы: работа в браузере, совместно, шаблоны, нужен интернет.
- Структура проекта: титул, план, проблема, данные, методы, результаты, заключение.
- Не больше шести строк на слайде.
- Анимация показывает порядок, а не украшает.

## Частые ошибки

- Перегружать слайды текстом: их никто не прочитает.
- Использовать фоновую музыку на весь показ: мешает докладчику.
- Ставить анимацию на каждый объект: зритель перестаёт следить за смыслом.
- Работать с сервисом, который не сохраняет результат: работа пропадёт.

## Проверь себя

1. Что входит в понятие мультимедиа?
2. Назови семь слайдов структуры проектной презентации.
3. Сколько строк текста допустимо на слайде?
