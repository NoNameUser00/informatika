# Обобщение: оба подхода вместе

Блок изучен целиком. Главное — научиться выбирать подход и переводить единицы.

## Два подхода — краткая памятка

**Вероятностный (содержательный)**: `2^i = N`, где `N` — число равновероятных исходов.

**Объёмный (алфавитный)**: `N = 2^i` и `I = K · i`, где `K` — число символов.

| Вопрос | Подход |
|---|---|
| Сколько бит несёт сообщение об исходе? | вероятностный |
| Сколько места займёт текст? | объёмный |
| Сколько бит на один символ? | объёмный |
| Сколько вариантов различить? | вероятностный |

## Разбор задачи 1 (вероятностный)

Сообщение различает 256 равновероятных исходов.

```
N = 256 = 2^i  →  i = 8 бит
```

Проверка: 2⁸ = 256 ✓

## Разбор задачи 2 (вероятностный)

Поле n × n, первый ход несёт 6 бит.

```
N = 2^6 = 64 клетки
n = √64 = 8
Ответ: 8 × 8.
```

## Разбор задачи 3 (объёмный)

Сообщение 140 символов, алфавит 32 символа.

```
N = 32 = 2^i  →  i = 5 бит
K = 140
I = 140 · 5 = 700 бит = 87,5 байта
```

## Разбор задачи 4 (передача)

Файл 2 Мбайта, канал 2 Мбит/с.

```
объём = 2 · 1024 · 1024 · 8 = 16 777 216 бит
скорость = 2 Мбит/с = 2 000 000 бит/с
t = 16 777 216 : 2 000 000 ≈ 8,4 секунды
```

Обрати внимание: в битах и килобитах — 1024, в мегабитах для скорости — 1 000 000. Смешивать нельзя.

## Разбор задачи 5 (кодирование)

Алфавит из 4 символов. Каков вес символа?

```
N = 4 = 2^i  →  i = 2 бит
```

## Типичные ошибки

1. **Путать подходы.** «Сколько бит в сообщении о погоде?» — вероятностный; «сколько места занимает текст?» — объёмный.
2. **Не проверять результат.** Получил `i = 5` — подставь в 2⁵ и убедись, что совпало с N.
3. **Делить на 1000** при переводе в Кбайты.
4. **Путать Мбит/с и Мбайт/с** (разница × 8).
5. **Забыть про равновероятность** в вероятностном подходе.

## Ключевое (записать)

- Вероятностный: `2^i = N`. Объёмный: `I = K·i`, `N = 2^i`.
- Всегда проверяй: 2ⁿ должно совпасть с исходным числом.
- Единицы: Кбайт = 1024 байта, но 1 Мбит/с = 1 000 000 бит/с.

## Частые ошибки

- Считать 2⁵ = 25 или 2⁵ = 32 «на глаз» — всегда считай и проверяй обратно.
- Считать время, не переведя объём в биты.
- Применять вероятностный подход к неравновероятным исходам.

## Проверь себя

2. Алфавит из 64 символов. Чему равен вес символа?
3. Файл 4 Кбайта, канал 2048 бит/с. Сколько секунд?
