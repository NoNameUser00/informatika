# Обобщение: системы счисления и кодирование

Собираем блок: системы счисления, представление в памяти, кодирование текста, изображений и звука.

## Формулы блока

```
N = 2^i              мощность алфавита ↔ вес символа
I = K · i            объём сообщения (символы)
V = K · i            объём изображения (пиксели · глубина)
V = f · i · t        объём звука (частота · разрядность · время)
t = V : v            время передачи (объём : скорость)
```

## Разбор задачи 1: перевод числа

Переведи 254₁₀ в шестнадцатеричную.

```
254 : 16 = 15, остаток 14 → E
 15 : 16 = 0,  остаток 15 → F
Ответ: FE₁₆
Проверка: F = 15, 15·16 + 14 = 254 ✓
```

## Разбор задачи 2: арифметика в СС

Вычисли FE₁₆ − A₁₆.

```
254 − 10 = 244 = F4₁₆
```

Проверка переводом: 254 − 10 = 244 ✓

## Разбор задачи 3: объём изображения

Изображение 1024 × 768 пикселей, глубина 24 бита.

```
K = 1024 · 768 = 786 432 пикселя
V = 786 432 · 24 = 18 874 368 бит
V = 18 874 368 : 8 = 2 359 296 байт ≈ 2,25 Мбайт
```

## Разбор задачи 4: объём звука

Звук длится 30 секунд, частота 8 000 Гц, разрядность 8 бит.

```
V = 8000 · 8 · 30 = 1 920 000 бит
V = 1 920 000 : 8 = 240 000 байт ≈ 234 Кбайт
```

## Разбор задачи 5: время передачи

Файл 234 Кбайт, канал 32 768 бит/с.

```
V = 234 · 1024 · 8 = 1 916 928 бит
t = 1 916 928 : 32 768 = 58,5 секунды
```

## Разбор задачи 6: глубина цвета

Сколько цветов даёт глубина 8 бит на канал RGB?

```
N = 256³ = 16 777 216
```

## Типичные ошибки

1. **Основание vs система счисления.** В системе с основанием 16 цифры 0–9 и A–F, а не 0–15.
2. **24 бита и три канала.** Не умножать на 3: 24 бита уже это три канала по 8.
3. **Разрядность звука и частота.** Частота — Гц, разрядность — бит. Перепутать нельзя.
4. **Единицы.** Кбайт = 1024 байта; в битах и килобитах — тоже 1024.
5. **Разрешение и размер.** Больше разрешение — больше объём, но не всегда лучше качество на экране.
6. **Округление.** Если 24 бита делятся на 8 нацело — все три канала «полные». Иначе часть бит «недостающая» (padding).

## Ключевое (записать)

- `N = 2^i`, `I = K·i`, `V = K·i` (изображение), `V = f·i·t` (звук), `t = V : v`.
- Перевод: делить с остатками (целое) и умножать (дробь).
- Проверяй результат переводом в десятичную.

## Частые ошибки

- Умножать объём на 3 для RGB, считая, что 24 бита — это 8 бит на канал.
- Забыть перевести биты в байты в задачах на звук.
- Считать время, не переведя объём в биты.
