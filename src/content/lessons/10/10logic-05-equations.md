# Ищем значения букв

**Логическое уравнение** — равенство с логическим выражением, где искомое — значения букв.

## Главный приём: идём от главной операции

Дизъюнкция равна 0, только если **все** её части равны 0.
Конъюнкция равна 1, только если **все** её части равны 1.

Это и есть ключ к решению.

## Разбор примера

Уравнение: `(A→C) ∨ ((B∨C) ∧ A) ∨ D = 0`

Шаг 1. Вся дизъюнкция равна 0 → **каждая** часть равна 0:
- `A→C = 0`
- `(B∨C) ∧ A = 0`
- `D = 0` → готово, D = 0

Шаг 2. `A→C = 0`. Импликация ложна ровно в одном случае: из истины ложь. Значит **A = 1, C = 0**.

Шаг 3. `(B∨C) ∧ A = 0`. Подставляем известное: `(B∨0) ∧ 1 = 0`. Упрощаем: `B ∧ 1 = B = 0`. Значит **B = 0**.

Шаг 4. Ответ: A = 1, B = 0, C = 0, D = 0.

Шаг 5. **Проверка подстановкой** — обязательный шаг:

```
A=1, B=0, C=0, D=0
(1→0) ∨ ((0∨0)∧1) ∨ 0
= 0 ∨ (0∧1) ∨ 0
= 0 ∨ 0 ∨ 0
= 0  ✓
```

Решение верно.

## Правило проверки

**Всегда проверяй подстановкой — даже печатный ответ из учебника.**

Пример из практики: в учебнике к похожему примеру приведён ответ с B = 1. Проверка подстановкой показывает, что при B = 1 выражение равно 1, а не 0. Значит, в условии или в ответе опечатка. Правильный ход — проверить и исправить, а не принять на веру.

## Типичные случаи

**Уравнение с дизъюнкцией равно 0:**
```
A ∨ B = 0   →   A = 0 и B = 0   (оба сразу!)
```

**Уравнение с конъюнкцией равно 1:**
```
A ∧ B = 1   →   A = 1 и B = 1
```

**Уравнение с конъюнкцией равно 0:**
```
A ∧ B = 0   →   хотя бы одно равно 0
```

**Уравнение с дизъюнкцией равно 1:**
```
A ∨ B = 1   →   хотя бы одно равно 1
```

## Когда решений несколько

Если уравнение не задаёт все значения, решений несколько. Например `A ∨ B = 1` даёт три пары: (0,1), (1,0), (1,1).

Такое уравнение решают таблицей истинности: отмечают строки, где выражение равно заданному значению.

## Ключевое (записать)

- `X ∨ Y = 0` → и X = 0, и Y = 0.
- `X ∧ Y = 1` → и X = 1, и Y = 1.
- Импликация `A→B = 0` → A = 1 и B = 0.
- Ответ всегда проверяй подстановкой.

## Частые ошибки

- Верить печатному ответу без проверки.
- Для `A ∨ B = 0` записать только A = 0, забыв про B.
- Считать, что `A ∧ B = 0` означает оба нуля: достаточно хотя бы одного.
- Останавливаться на середине решения, не проверив все условия.

## Проверь себя

1. Реши `A → B = 0`.
2. Реши `A ∨ B = 0`.
3. Сколько решений у `A ∨ B = 1`? Перечисли их.

Ответы: 1) A = 1, B = 0. 2) A = 0, B = 0. 3) Три: (0,1), (1,0), (1,1).
