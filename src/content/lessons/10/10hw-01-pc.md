# Принцип работы компьютера

Урок открывается **техникой безопасности** (слайд на главной странице класса). Главная тема — как устроен компьютер по схеме, а не по списку деталей.

## Принцип программного управления

Вся работа компьютера подчиняется одному правилу: **программа управляет работой устройств**. Процессор не «понимает» задачу — он выполняет команды из памяти по указаниям программы.

Отсюда следствие: заменив программу, получаешь другую задачу на том же железе. Именно поэтому компьютер называют универсальным.

## Магистрально-модульная организация

**Магистраль** (шина данных) — общая линия, по которой процессор обменивается данными с памятью и устройствами.

Схема:

```
             ┌──────────┐
             │ ПРОЦЕССОР│
             └────┬─────┘
                  │  магистраль (шина)
        ┌─────────┼─────────┐
   ┌────┴────┐ ┌──┴───┐ ┌───┴────┐
   │ ПАМЯТЬ  │ │ ВВОД │ │  ВЫВОД │
   └─────────┘ └──────┘ └────────┘
```

Что важно:

1. **Всё идёт через магистраль.** Нет отдельного пути от процессора к каждому устройству — одна общая линия.
2. **Магистраль ограничена.** За такт по ней проходит ограниченный объём данных — отсюда понятие пропускной способности.
3. **Адреса и данные идут по одной линии.** Процессор сначала передаёт адрес ячейки памяти или устройства, потом — данные.

## Что даёт такая схема

- **Универсальность**: сменил программу — сменил задачу.
- **Простоту сборки**: устройства подключаются к общей магистрали, а не попарно.
- **Ограничение скорости**: магистраль — узкое место, её пропускная способность ограничивает всю систему.

## Ключевое (записать)

- Компьютер работает по программе: процессор выполняет команды из памяти.
- Магистраль — общая линия обмена данными между процессором, памятью и устройствами.
- Через магистраль идёт всё: адреса и данные.
- Пропускная способность магистрали ограничивает всю систему.

## Частые ошибки

- Считать, что процессор «понимает» задачу: он выполняет команды.
- Путать магистраль с кабелем питания: это линия данных.
- Считать, что у каждого устройства свой путь к процессору: всё идёт через общую шину.

## Проверь себя

1. В чём состоит принцип программного управления?
2. Что такое магистраль?
3. Почему магистраль ограничивает быстродействие системы?
