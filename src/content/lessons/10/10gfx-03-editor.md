# Работа с изображениями

## Два вида графики

**Растровая** — изображение как сетка пикселей. Точная цветопередача (фото), но при увеличении появляются «ступеньки».

**Векторная** — изображение как формулы фигур и кривых. Масштабируется без потерь, но фотографию в векторе не рисуют.

| Свойство | Растр | Вектор |
|---|---|---|
| Хранение | пиксели | формулы фигур |
| Увеличение | «ступеньки» | качество не меняется |
| Фотография | да | нет |
| Схемы, логотипы | плохо | отлично |
| Объём | большой | маленький |

## Обработка графических объектов

Основные операции в растровом редакторе (GIMP, LibreOffice Draw):

1. **Выделение** — обязательный шаг перед действиями: иначе оно применится ко всему слою.
2. **Слои** — прозрачные листы; верхний закрывает нижний.
3. **Резкость и размытие** — фильтры для коррекции.
4. **Кадрирование** — обрезка лишнего.
5. **Коррекция** — яркость, контраст, цветовой баланс.
6. **Ретушь** — «лечащая кисть» убирает дефекты.

## Форматы графических файлов

| Формат | Сжатие | Прозрачность | Для чего |
|---|---|---|---|
| **BMP** | нет | нет | качество без потерь, большой |
| **PNG** | без потерь | да | качество + прозрачность |
| **JPEG** | с потерями | нет | фотографии, малый размер |
| **GIF** | с потерями | да | 256 цветов, анимация |
| **SVG** | нет | да | вектор, масштабируется |

Компромисс JPEG: файл в десятки раз меньше, но часть данных теряется навсегда — увеличенный JPEG покажет блочные артефакты.

## Практическая работа

Задание КТП: преобразование растровых изображений.

1. Открой фотографию в растровом редакторе.
2. Обрежь кадр, оставь главный объект.
3. Исправь экспозицию: сделай темнее или светлее.
4. Повысь резкость.
5. Сохрани в BMP, PNG и JPEG — сравни размеры трёх файлов.
6. Открой JPEG, увеличь в 5 раз — найди артефакты.
7. Открой PNG в том же масштабе — сравни качество.

Вывод: PNG и BMP хранят изображение без потерь, JPEG сжимает сильнее, но качество падает.

## Ключевое (записать)

- Растр — пиксели (фото); вектор — формулы (схемы, логотипы).
- Перед действием выделяй область, иначе оно применится ко всему слою.
- Слои — прозрачные листы; верхний закрывает нижний.
- PNG и BMP — без потерь; JPEG — с потерями; SVG — вектор.
- JPEG экономит место ценой качества.

## Частые ошибки

- Заливать весь слой, забыв про выделение.
- Рисовать всё на одном слое: исправить потом нельзя.
- Считать, что JPEG сохраняет качество полностью.
- Растягивать изображение, портя пропорции.
- Сохранять PNG, когда нужен фотосайт: размер получится огромным.

2. Какой формат сохраняет качество без потерь?
3. Почему JPEG при увеличении даёт артефакты?
