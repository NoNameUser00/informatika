# Работа с чужим документом

## Инструменты рецензирования

Текстовый процессор умеет не только редактировать, но и **рецензировать** — оставлять замечания, не трогая исходный текст.

- **Комментарий** (замечание) — примечание на полях, привязанное к месту в тексте. Исходный текст не меняется.
- **Исправление в режиме рецензирования** — правка видна и выделена, автор и время сохраняются.
- **Вставка закладок и перекрёстных ссылок** — для навигации по документу.

Принцип: автор не должен гадать, что имел в виду рецензент. Комментарий должен быть конкретным и доброжелательным.

Плохо: «неправильно». Хорошо: «здесь лучше поставить запятую после слова "который", так читается легче».

## Деловая переписка

**Деловое письмо** — официальное сообщение. Требования к оформлению:

- точный заголовок по теме письма;
- обращение на «Вы» с заглавной буквы;
- краткое вводное предложение: о чём письмо;
- суть по существу, без воды;
- конкретная просьба или предложение, если она есть;
- подпись и контактные данные.

Отличия от личного письма: нейтральный тон, без эмоций, чёткая структура, отсутствие сокращений в деловой части.

## Цитирование и список литературы

**Цитирование** — указание авторства чужой мысли.

Правила:

1. Пересказывай **своими словами** в основном тексте.
2. Точную цитату бери **в кавычки** и снабжай ссылкой.
3. Составляй **список литературы** — источники, которые действительно использованы.

Требования к каждому источнику:

- **Книга**: Фамилия И. О. Название. — Город: Издательство, год. — Страницы.
- **Статья**: Фамилия И. О. Название статьи // Название журнала. — Год. — № журнала. — Страницы.
- **Сайт**: Название сайта. — URL (дата обращения).

Пример:

```
— Иванов И. Информатика: учебник для 10 класса. — М.: Просвещение, 2023. — 128 с.
— Системы счисления // Информатика и образование. — 2022. — № 4. — С. 12–18.
— Открытая коллекция цифровых образовательных ресурсов. — URL: https://school-collection.edu.ru (дата обращения: 15.03.2025).
```

## Облачные сервисы

**Облачные сервисы** для документов дают:

- доступ с любого устройства,
- совместную работу в реальном времени,
- историю версий и комментарии,
- общий доступ по ссылке с ограничением прав.

Правила: выдавай **минимальные права**; для контрольной работы ставь «только просмотр». Скачивай файл перед сдачей — ссылка не заменяет файл.

## Практическая работа

Задание КТП: коллективная работа с документом.

1. Создай документ в облачном сервисе.
2. Дай доступ однокласснику на редактирование.
3. Пусть он оставит 2–3 комментария — исправь по ним.
4. Добавь свой комментарий к его правке.
5. Составь список литературы из трёх источников: книга, статья, сайт.
6. Вставь сноску со ссылкой на один из них.
7. Скачай итоговый файл локально.

## Ключевое (записать)

- Комментарий не меняет текст; правка в режиме рецензирования — меняет и видна.
- Деловое письмо: заголовок, обращение, суть, просьба, подпись.
- Цитата — в кавычки, со ссылкой; пересказ — своими словами.
- Список литературы: книга, статья, сайт — у каждого свои данные.
- Облако: минимальные права, файл перед сдачей.

## Частые ошибки

- Править чужой текст молча, без комментария: автор не поймёт, что изменилось.
- Писать комментарий в стиле «неправильно»: бесполезно.
- Указывать в списке литературы источники, которые не использовались.
- Забыть дату обращения для сайта.
- Отправить ссылку вместо файла.

## Проверь себя

1. Чем комментарий отличается от правки в режиме рецензирования?
2. Что указывать для книги в списке литературы?
3. Почему для контрольной работы ставят «только просмотр»?
