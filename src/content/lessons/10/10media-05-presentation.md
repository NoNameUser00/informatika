# Собираем мультимедийную презентацию

Задание КТП: презентация с изображениями, звуками и видео.

## Что должно получиться

Презентация из 8–10 слайдов, где:

- **титульный слайд** с темой и авторами;
- **содержательные слайды** с изображениями и графиками;
- **минимум одна вставка видео**, поясняющая процесс;
- **озвучка или короткий звуковой комментарий**;
- **выводы** на последнем слайде.

## Порядок работы

### 1. Содержание

1. Определи тему и цель.
2. Составь план из 8–10 пунктов.
3. Найди данные: графики, таблицы, факты. Данные важнее украшений.

### 2. Изображения

1. Подготовь изображения по теме: схемы, фотографии, графики.
2. Оптимизируй их: уменьши размер, если файл большой.
3. Подпиши каждое: «Рисунок 1 — …».
4. Задай обтекание текстом, не накладывай на текст.

### 3. Видео

1. Выбери короткий ролик, поясняющий процесс, — 30–60 секунд.
2. Проверь формат: если сервис не поддерживает кодек, видео не запустится.
3. **Встрой файл в презентацию**, а не ссылайся внешне: ссылка может не сработать на чужом компьютере.
4. Настрой запуск по щелчку.

### 4. Звук

1. Озвучка нужна на 1–2 слайдах, не на всю презентацию.
2. Громкость — на минимуме, чтобы не перебивать докладчика.
3. Можно добавить короткий звуковой комментарий к ключевому слайду.
4. Звук должен быть со смыслом, а не фоном.

### 5. Оформление

1. Единый шрифт и размер — размер читаем с расстояния.
2. Одна цветовая гамма, максимум три цвета.
3. Контрастный текст: тёмный на светлом или светлый на тёмном.
4. Выравнивание: заголовки по одному краю, текст — по ширине.

## Что проверить перед сдачей

1. Все изображения загрузились, «битых» значков нет.
2. Видео запускается и воспроизводится.
3. Звук слышен, но не перекрикивает.
4. Текст читается с расстояния 2–3 метра.
5. Нет опечаток, единообразие оформления.
6. Файл сохранён локально, показ работает без интернета.

## Решение типовых проблем

| Проблема | Причина | Решение |
|---|---|---|
| Видео не запускается | неподдерживаемый кодек | встроить как видео, не ссылкой |
| Звук перебивает | громкость по умолчанию | снизить громкость |
| Текст мелкий | размер шрифта уменьшен при копировании | задать единый размер вручную |
| Слайд перегружен | вставлено слишком много | оставить главное, остальное — в речь |

## Ключевое (записать)

- Презентация = 8–10 слайдов: титул, содержание, выводы.
- Видео встраивают в файл, а не ссылкой.
- Звук тихий, только на 1–2 слайдах.
- Шрифт читаем с расстояния, единый во всей презентации.
- Проверь показ на том компьютере, с которого будешь выступать.

## Частые ошибки

- Ссылаться на видео во внешнем файле: на чужом компьютере не найдёт.
- Ставить фоновую музыку на весь показ.
- Делать слайды мелким текстом «чтобы влезло побольше».
- Не проверить показ заранее.
- Забыть сохранить файл локально.

## Проверь себя

1. Что должно быть в готовой мультимедийной презентации?
2. Почему видео встраивают в файл, а не ссылкой?
3. Как настроить звук, чтобы он не мешал докладчику?
