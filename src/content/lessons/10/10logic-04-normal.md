# Синтез выражения по таблице

**Нормальная форма** — стандартный вид выражения, из которого удобно читать и сравнивать.

**ДНФ** (дизъюнктивная нормальная форма) — ИЛИ из И-частей:

```
ДНФ = (И из ИЛИ) ИЛИ (И из ИЛИ) ИЛИ …
```

**КНФ** (конъюнктивная нормальная форма) — И из ИЛИ-частей:

```
КНФ = (ИЛИ из И) И (ИЛИ из И) И …
```

Запомнить легко: **ДНФ — дизъюнкция конъюнкций**, значит, «снаружи ИЛИ, внутри И». КНФ — наоборот.

## Что собирает какая форма

- **ДНФ собирает строки, где выражение истинно** (единицы).
- **КНФ собирает строки, где выражение ложно** (нули).

## Построение ДНФ

1. Построй таблицу истинности.
2. Выпиши строки, где значение — **1**.
3. Для каждой такой строки составь произведение из букв:
   - если буква равна 1 — берём её **как есть**;
   - если буква равна 0 — берём **отрицание**.
4. Соедини полученные произведения **дизъюнкцией**.

### Пример

Выражение `F(A, B)` истинно в строках: A=0, B=0 и A=1, B=1.

Строка A=0, B=0 → произведение `¬A ∧ ¬B`.
Строка A=1, B=1 → произведение `A ∧ B`.

```
ДНФ: (¬A ∧ ¬B) ∨ (A ∧ B)
```

Проверка: при A=0, B=0 → `1 ∧ 1 = 1` → истина ✓. При A=1, B=0 → `0 ∧ 1 = 0`, `1 ∧ 0 = 0` → ложь ✓.

## Построение КНФ

1. Выпиши строки, где значение — **0**.
2. Для каждой составь сумму из букв:
   - если буква равна 0 — берём **как есть**;
   - если буква равна 1 — берём **отрицание**.
3. Соедини суммы **конъюнкцией**.

### Тот же пример

Ложные строки: A=0, B=1 и A=1, B=0.

Строка A=0, B=1 → `A ∨ ¬B`.
Строка A=1, B=0 → `¬A ∨ B`.

```
КНФ: (A ∨ ¬B) ∧ (¬A ∨ B)
```

Проверка: при A=0, B=1 → `0 ∨ 0 = 0`, `1 ∨ 1 = 1`, `0 ∧ 1 = 0` → ложь ✓.

## Замечание

Если ДНФ построена по строкам единиц, то КНФ того же выражения строится по **остальным** строкам.

## Ключевое (записать)

- ДНФ — ИЛИ из И-частей; КНФ — И из ИЛИ-частей.
- ДНФ собирает строки со значением 1, КНФ — со значением 0.
- В ДНФ: буква 1 → как есть, буква 0 → с отрицанием.
- В КНФ: наоборот — буква 0 → как есть, буква 1 → с отрицанием.

## Частые ошибки

- Путать, какие буквы брать с отрицанием в ДНФ и в КНФ (правило обратное!).
- Соединять произведения конъюнкцией в ДНФ.
- Потерять строки таблицы при выписывании.
- Считать, что ДНФ и КНФ одного выражения совпадают: это разные формы.

## Проверь себя

1. В чём разница между ДНФ и КНФ по построению?
2. Построй ДНФ для выражения, истинного только при A=1, B=0.
3. Построй КНФ для того же выражения.

Ответ к пункту 2: единственная строка A=1, B=0 → `A ∧ ¬B`, значит ДНФ = `A ∧ ¬B`.
Ответ к пункту 3: ложные строки 00, 01, 11. Для 00: `A ∨ B`. Для 01: `A ∨ ¬B`. Для 11: `¬A ∨ ¬B`. КНФ = `(A ∨ B) ∧ (A ∨ ¬B) ∧ (¬A ∨ ¬B)`.
