# Текстовый документ (LibreOffice Writer)

Наш главный инструмент — **LibreOffice Writer** (свободный, по-русски, открывает чужие форматы).

**Текстовый процессор** — программа для документов (набор, правка, оформление). Правила набора: один пробел между словами, абзац — Enter, красная строка — не пробелами!

## Три уровня форматирования

1. **Символы** (прямое): шрифт, размер, жирность/курсив.
2. **Абзацы**: выравнивание, отступы, интервалы, списки.
3. **Документ**: поля, колонтитулы, номера страниц, оглавление, стили.

**Стили** — именованные наборы (Заголовок 1, Обычный): поменял стиль — поменялось всё разом. Умные средства: голосовой ввод, распознавание, перевод, проверка орфографии.

## Списки и таблицы — структура

Перечисления — **списками** (маркированные/нумерованные). Сетки данных — **таблицами** (строки × столбцы). В документ вставляют формулы, картинки, цитаты со ссылками на источники.

## Ключевое (записать)

- Три уровня: символы → абзацы → документ.
- Стили меняют всё разом. Списки — перечисления, таблицы — сетки.
- Цитаты — только со ссылкой на источник.

## Частые ошибки

- Лепить пробелы вместо отступов и Enter вместо абзацев.
- Форматировать каждый заголовок вручную вместо стиля.
- Цитаты без источников.

## Проверь себя

1. Что относится к форматированию абзаца, а что — символов?
2. Когда нужна таблица, а когда список?
