# Чем рисовать и править

## Растровый редактор: пиксели

Инструменты: кисть, заливка, ластик, выделение, пипетка (взять цвет). Операции над фото: кадрирование, яркость/контраст, поворот. Форматы: JPEG (фото), PNG (схемы + прозрачность), GIF (анимация, 256 цветов).

Правило: правишь копию, оригинал не трогаешь!

## Векторный редактор: фигуры

Инструменты: линия, прямоугольник, эллипс, кривые, текст. Объекты можно двигать, тянуть, группировать. Форматы: SVG (веб), встроенные фигуры процессора.

## Сравнение размеров (практика)

Один и тот же рисунок сохрани в BMP, JPEG, PNG, GIF и сравни размеры: BMP — огромный без сжатия, JPEG — маленький для фото, PNG — оптимум для схем, GIF — только 256 цветов.

## Ключевое (записать)

- Растр: кисть/заливка/ластик/пипетка. Вектор: фигуры и кривые.
- JPEG — фото, PNG — схемы, GIF — 256 цветов, SVG — веб-вектор.
- Оригинал не трогаем — правим копию!

## Частые ошибки

- Сохранять схему в JPEG (мыло вокруг букв!).
- Тянуть растр (лесенка) вместо перерисовки вектором.
- Забывать, где лежит исходник.

## Проверь себя

1. Чем взять цвет с картинки? Чем залить область?
2. Какой формат для фото? Для схемы с текстом?
