# Информация вокруг нас

**Информация** — сведения об окружающем мире, которые мы получаем органами чувств, приборами и из сообщений.

## Свойства информации (выучи!)

- **Объективность** — не зависит от мнения (температура −5°).
- **Достоверность** — соответствует правде.
- **Полнота** — её достаточно для решения.
- **Актуальность** — вовремя (расписание позавчера — уже нет).
- **Ценность/полезность** — помогает достичь цели.
- **Понятность** — на знакомом языке.

## Информационные процессы

Сбор → обработка → хранение → передача. Пример с фото задачи в мессенджере: источник (ты), кодирующее устройство (камера), канал связи (интернет), декодер (телефон друга), приёмник (друг).

## Носители и формы

Носитель — то, на чём хранится (бумага, флешка, глина). Информация бывает непрерывной (звук, температура) и дискретной (цифры, текст) — компьютер работает только с дискретной.

## Ключевое (записать)

- Свойства: объективность, достоверность, полнота, актуальность, ценность, понятность.
- Процессы: сбор, обработка, хранение, передача.
- Цепочка передачи: источник → кодер → канал → декодер → приёмник.

## Частые ошибки

- Путать носитель и информацию (книга — носитель, рассказ — информация).
- Считать любую новость достоверной (проверяй источник!).
