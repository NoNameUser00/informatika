# Текст как частный случай

Текст — сообщение из символов одного алфавита. Всё решается той же парой формул: сначала вес символа через мощность, потом объём через число символов.

```
N = 2^i
I = K · i
```

Число символов текста: страницы × строки × символы в строке.

## Разбор 1: текстip 64-символьного алфавита

Условие: 3 страницы, 40 строк по 60 символов. Сколько байт?

```
N = 64            64 = 2^i, i = 6 (бит)
K = 3·40·60 = 7200
I = 7200·6 = 43200 (бит) = 5400 (байт)
Ответ: 5400 байт.
```

## Разбор 2: обратный ход

Условие: 6 страниц по 40 строк по 60 символов, всего 9000 байт. Найти вес символа и мощность алфавита.

```
K = 6·40·60 = 14400
I = 9000 байт = 72000 бит
i = 72000 / 14400 = 5 (бит)
N = 2^5 = 32 (символа)
Ответ: 5 бит, алфавит 32 символа.
```

## Разбор 3: племя Пульти

Алфавит 32 символа (i = 5 бит), 512 табличек по 256 символов.

```
На табличке: I = 256·5 = 1280 (бит) = 160 (байт)
Во всём своде: 160·512 = 81920 (байт) = 80 (Кбайт)
```

## Ключевое (записать)

- K текста = страницы × строки × символы.
- Байты ↔ биты (×8), байты ↔ Кбайты (÷1024).
- Ход решения: N → i → K → I (или в обратную сторону от I).

## Частые ошибки

- Считать K только одной страницы, забыв умножить на число страниц.
- Делить не на то: i = I/K, а не K/I.
- Терять «байт» в ответе, когда просят байты.
