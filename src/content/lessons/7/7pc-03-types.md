# Компьютер — универсальное устройство

**Компьютер** — универсальное электронное программно управляемое устройство для работы с информацией. «Универсальное» значит: одна машина выполняет любые задачи, если для них есть программа.

## Типы компьютеров

- **Встроенные** — часть прибора: стиральная машина, бортовой компьютер, домофон.
- **Персональные** — для одного человека дома или в офисе.
- **Серверы** — обслуживают запросы многих: сайты, почта, файлы для всей школы.
- **Суперкомпьютеры** — тысячи процессоров для науки: прогноз погоды, моделирование.

## Поколения компьютеров

Компьютеры менялись по元件ам, из которых собрана вычислительная машина:

1. **Лампы** — большие, горячие, медленные.
2. **Транзисторы** — меньше, надёжнее.
3. **Интегральные микросхемы** — на одной плате тысячи элементов.
4. **Сверхбольшие интегральные схемы** — миллиарды транзисторов на кристалле.

Каждое поколение быстрее, меньше и дешевле предыдущего.

## Тенденции развития

Сегодня видны три направления:

- **Многоядерность** — ядер в процессоре всё больше, задачи делятся между ними.
- **Мобильность** — системный блок → ноутбук → планшет → смартфон в кармане.
- **Облака** — тяжёлые вычисления уезжают с домашнего устройства в дата-центр.

Суперкомпьютеры — вершина гонки: тысячи процессоров для научных расчётов. Общая тенденция одна: **та же задача выполняется меньшим устройством и быстрее**.

## Ключевое (записать)

- Типы: встроенные, персональные, серверы, суперкомпьютеры.
- Поколения: лампы → транзисторы → микросхемы → сверхбольшие схемы.
- Тенденции: многоядерность, мобильность, облака.

## Частые ошибки

- Считать, что компьютер умеет только «считать»: универсальность обеспечивают программы.
- Путать сервер и суперкомпьютер: сервер обслуживает запросы, суперкомпьютер считает.
- Считать, что поколения отличаются размером: они отличаются элементной базой.

2. Чем поколения компьютеров отличаются друг от друга?
3. Назови три тенденции развития компьютеров.
