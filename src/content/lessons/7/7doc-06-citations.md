# Ссылка на источник

Если в тексте использованы чужие мысли, нужно **сослаться на источник**. Это не только вежливость: без ссылки работа выглядит плагиатом.

## Два вида ссылок

**Подстрочная (сноска)** — ссылка внизу страницы, под текстом, к которому она относится. Сноску вставляют прямо во время набора.

**Затекстовая (концевая)** — список источников в конце работы. Каждый источник пронумерован, и в тексте стоит его номер.

## Как оформить список источников

Для школьной работы достаточно единого формата. Обычно указывают:

1. **Фамилия, имя** автора (или название, если нет автора).
2. Название работы.
3. Место и год издания (для сайта — адрес и дата обращения).
4. Для книги — издательство.

Примеры:

```
— Иванов И. Информатика: учебник для 7 класса. — М.: Просвещение, 2020.
— Электронный ресурс: Единая коллекция цифровых образовательных ресурсов. —
  URL: https://school-collection.edu.ru (дата обращения: 10.03.2025).
```

## Что нельзя делать

1. **Сдавать чужой текст как свой.** Это плагиат, а не реферат.
2. **Цитировать без кавычек**, выдавая чужую мысль за свою.
3. **Указывать источник, который не использовался**, или не указывать использованный.
4. **Ссылаться на непроверенный источник** — скачанный «реферат» из интернета не является источником.

## Как правильно использовать чужой материал

Схема простая:

1. Найди информацию в надёжном источнике.
2. Перескажи её своими словами в основном тексте.
3. Если приводишь точную формулировку — возьми в кавычки и укажи ссылку.
4. Составь список источников.

Так работа остаётся твоей, а авторство исходного материала признано.

## Практическая работа

Задание КТП: создание небольших текстовых документов с цитатами и ссылками на цитируемые источники.

1. Выбери тему, найди два источника (учебник и сайт).
2. Напиши абзац, пересказывающий содержание источника.
3. Одну точную формулировку возьми в кавычки и снабди сноской.
4. Составь список источников в конце документа.
5. Проверь оформление: автор, название, выходные данные, дата обращения для сайта.

## Ключевое (записать)

- Сноска — внизу страницы; затекстовая ссылка — номер в списке в конце.
- Пересказывай своими словами; точную цитату — в кавычки со ссылкой.
- Источник указывается реальный и только один раз.
- Список источников — обязательная часть работы.

## Частые ошибки

- Сдавать скачанный текст без ссылок.
- Пересказ чужими словами, но с чужими ошибками: проверь факты.
- Забыть дату обращения для сайта, который меняется.
- Указывать источник, но не сослаться на него в тексте.

## Проверь себя

1. Чем подстрочная ссылка отличается от затекстовой?
2. Что обязательно указывать для интернет-источника?
3. Почему сдавать чужой текст — плагиат?
