# Что такое файл

**Файл** — именованная область хранения данных. У файла есть имя и расширение: `реферат.docx`, где `.docx` — расширение, по ному система понимает, какой программой открыть.

## Типы файлов по содержимому

| Тип | Расширения | Примеры |
|---|---|---|
| Текстовые | .txt, .doc, .docx, .odt | записка, реферат |
| Графические | .jpg, .png, .bmp, .gif | фотография, рисунок |
| Звуковые | .mp3, .wav, .ogg | запись голоса |
| Видео | .mp4, .avi, .mkv | ролик |
| Табличные | .xls, .xlsx, .ods | расчёт |
| Архивы | .zip, .rar, .7z | упакованная папка |
| Исполняемые | .exe, .bat | программа |

Расширение — подсказка для программы, но не гарантия: файл `.jpg` внутри может оказаться переименованным `.txt`.

## Папки и файловая система

**Файловая система** — правила, по которым данные записаны на носителе. Она определяет, что у каждого файла есть путь, а на верхнем уровне есть корневая папка.

В Windows путь записывают обратными слэшами: `C:\Users\Иван\Документы\реферат.docx` — диск, папки, имя файла.

**Папка (каталог)** — контейнер для файлов и других папок. Краткий путь — просто имя, полный — от корня.

## Файловый менеджер

Проводник (или «Файлы») умеет:

- создавать папки и файлы,
- открывать и просматривать содержимое,
- копировать, перемещать, переименовывать,
- удалять (в корзину),
- искать по имени и маске.

## Практическая работа

**Задание**: изучить элементы интерфейса операционной системы.

1. Открой Проводник, найди панель: адрес, поиск, дерево папок, список файлов.
2. Создай папку `7 класс` и внутри — вложенную `Работы`.
3. Создай в ней файл `проба.txt`.
4. Посмотри свойства файла: размер, тип, дата изменения.
5. Переименуй, скопируй в другую папку и удали — проверь, что попало в корзину.

## Ключевое (записать)

- Файл = имя + расширение; расширение подсказывает программу.
- Папка — контейнер; полный путь: диск, папки, имя файла.
- Файловая система задаёт правила хранения и пути.
- Проводник: создать, открыть, копировать, переместить, переименовать, удалить, искать.

## Частые ошибки

- Считать, что расширение гарантирует содержимое файла.
- Путать перемещение и копирование: при перемещении оригинал исчезает.
- Удалять файлы мимо корзины: восстановить будет нельзя.
- Хранить всё в одной папке: потом не найти.
