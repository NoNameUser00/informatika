# Вставляем объекты в документ

Задание КТП: вставка в документ формул, таблиц, изображений и оформление списков.

## Работа с формулами

В Writer есть **редактор формул**, в котором математические выражения пишутся структурой, а не набором символов.

Порядок:

1. Вставь объект формулы (Вставка → Объект → Формула).
2. Набери выражение в специальном окне.
3. Сохрани объект и вернись в текст.

Сравни два способа записи одного и того же:

| Способ | Как выглядит | Когда применять |
|---|---|---|
| Текстом с клавиатуры | a² + b² = c² | простая формула в строке текста |
| Редактором формул | профессиональная вёрстка | длинные выражения, дроби, индексы |

В специализированном редакторе дроби и индексы выравниваются по правилам, текстом — «как набралось». Для реферата по математике нужен редактор формул.

## Работа с изображениями

1. Вставь изображение (Вставка → Изображение).
2. Задай размер, сохрани пропорции — иначе рисунок растянется.
3. Задай обтекание текстом: «по квадрату», «в тексте», «перед текстом».
4. Дай подпись: «Рисунок 1 — Схема алгоритма».

Правило: подпись обязательна, размер разумный (картинка во всю страницу съедает текст).

## Оформление списков

1. Выдели пункты абзацев.
2. Примени маркированный или нумерованный список.
3. Проверь отступы и интервалы — они должны совпадать с остальным текстом.

## Диаграмма по таблице

Числа из таблицы нагляднее показать **диаграммой** (Вставка → Диаграмма): столбцы — для сравнения, круг — для долей.

Диаграмма связана с таблицей: поменял число — столбик перестроился сам. Подпись и заголовок обязательны.

## Практическая работа

1. Создай документ с заголовком и абзацем.
2. Вставь и оформи нумерованный список из 4 пунктов.
3. Вставь таблицу 3 × 4, заполни шапку и данными, подпиши.
4. Вставь диаграмму по данным таблицы.
5. Вставь изображение, задай размер с сохранением пропорций, добавь подпись.
6. Вставь формулу через редактор формул.
7. Сохрани документ в формате `.odt` и в `.docx` — сравни размеры.

## Ключевое (записать)

- Формулы: простые — текстом, сложные — редактором формул.
- Изображение: сохранять пропорции, задавать обтекание, подписывать.
- Диаграмма строится по таблице и связана с ней.
- Документ сохраняем в `.odt` (свой формат LibreOffice) и `.docx` (обменный).

## Частые ошибки

- Растягивать изображение, ломая пропорции.
- Забывать подпись к рисунку или таблице.
- Строить диаграмму вручную, когда она строится из таблицы.
- Сохранять только в `.docx`: при открытии в LibreOffice возможны мелкие расхождения, для надёжности есть `.odt`.

## Проверь себя

1. Когда применяют редактор формул, а когда достаточно текста?
2. Что обязательно сделать с вставленным изображением?
3. Как связаны таблица и диаграмма?
