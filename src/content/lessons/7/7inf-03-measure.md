# Сколько весит сообщение

**Информационный вес символа (i)** — сколько бит приходится на один символ. **Информационный объём (I)** — вес всего сообщения.

## Две формулы (выучи!)

```
N = 2^i        (мощность алфавита ↔ вес символа)
I = K · i      (объём = число символов × вес символа)
```

## Как решать (оформление как в учебнике)

Дано → формулы → вычисление → ответ. Пример: сообщение 140 символов, алфавит 32 символа.

```
N = 32       I = K·i, N = 2^i    32 = 2^i, i = 5 (бит)
K = 140      ─────────────────   I = 140·5 = 700 (бит)
I — ?
Ответ: 700 бит.
```

Обратная задача: I = 720 бит, K = 180 → i = 720/180 = 4 → N = 2⁴ = 16 символов.

## Единицы измерения

```
1 байт = 8 бит
1 Кбайт = 1024 байта
1 Мбайт = 1024 Кбайта
1 Гбайт = 1024 Мбайта
```

Переводы цепочкой: 24576 бит = 3072 байта = 3 Кбайта (делим на 8, потом на 1024).

## Ключевое (записать)

- N = 2^i, I = K·i. Из двух формул находится всё третье.
- 1 Б = 8 бит; 1 КБ = 1024 Б; 1 МБ = 1024 КБ; 1 ГБ = 1024 МБ.
- Оформление: Дано | Формулы | Решение | Ответ.

## Частые ошибки

- Путать K и I (K — штуки символов, I — биты!).
- Делить на 1000 вместо 1024.
- Забывать перевести биты в байты, когда спрашивают байты.
- Считать i = N (нет! i — это степень: N = 2^i).

## Проверь себя

1. Сообщение 650 бит из 130 символов. Вес символа?
2. Вырази в разных единицах: 24576 бит; 2048 байт; 1,5 Кбайта.
