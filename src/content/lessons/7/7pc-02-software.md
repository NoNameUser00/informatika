# Программы на компьютере

Железо само по себе бесполезно. Компьютер работает только потому, что для него написаны **программы** — инструкции на понятном машине языке.

**Программное обеспечение (ПО)** — все программы, которые есть на компьютере.

## Три группы ПО

| Группа | Для чего | Примеры |
|---|---|---|
| Системное | Управление компьютером и устройствами | операционная система, драйверы, утилиты |
| Системы программирования | Создание новых программ | среды разработки, компиляторы |
| Прикладное | Решение задач пользователя | текстовый процессор, графический редактор, браузер |

**Операционная система** — главная системная программа. Она загружается первой и управляет всем остальным: запускает программы, распределяет память, работает с устройствами.

Чтобы запустить программу, ОС должна найти для неё место в памяти, дать процессору команды и показать окно на экране. Утилиты (архиватор, антивирус, дефрагментатор) тоже системные — они обслуживают систему.

## Свободное программное обеспечение

Не всё ПО платное. **Свободное ПО** — то, что можно:

1. использовать,
2. изучать,
3. копировать,
4. распространять в изменённом виде.

Такие права даёт лицензия **GNU GPL**. Примеры: Linux, LibreOffice, GIMP, Firefox, Inkscape.

Обратная сторона: **бесплатное ≠ свободное**. Программа может быть бесплатной, но запрещать изменение кода или ограничивать использование — лицензия это запрещает.

## Запуск программ

Установка и запуск идут так:

1. Инсталлятор копирует файлы программы в папку и записывает её в список.
2. Появляются ярлыки на рабочем столе и в меню «Пуск».
3. Двойной щелчок по ярлыку — запускается системная программа **загрузчик**, которая ищет программу и передаёт ей управление.

## Ключевое (записать)

- ПО = системное + прикладное + системы программирования.
- ОС — главная системная программа, загружается первой.
- Свободное ПО: 4 свободы по лицензии GNU GPL.
- Бесплатное не значит свободное.

## Частые ошибки

- Считать браузер системной программой — он прикладной.
- Путать ОС и программу: ОС управляет, программа решает задачу.
- Думать, что бесплатная программа свободна: смотри лицензию.
- Считать драйвер прикладной программой — это системное ПО.

## Проверь себя

1. Назови три группы программного обеспечения и по два примера в каждой.
2. Что делает операционная система?
3. Какие четыре свободы даёт GNU GPL? Чем свободное отличается от бесплатного?
