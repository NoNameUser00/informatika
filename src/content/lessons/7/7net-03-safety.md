# Адреса и правила поведения в сети

## Компьютерные сети

**Компьютерная сеть** — несколько компьютеров, соединённых так, чтобы они могли обмениваться данными.

Виды сетей:

- **Локальная** — в одном здании или классе (школьная сеть, домашний роутер).
- **Глобальная** — через всю планету. Интернет — самая большая глобальная сеть.

## Веб-страница и веб-сайт

**Веб-страница** — отдельный документ в сети, обычно с текстом и картинками.

**Веб-сайт (сайт)** — набор веб-страниц, связанных ссылками и объединённых общим адресом.

## Структура адреса

Адрес веб-ресурса состоит из частей:

```
протокол://домен/путь/страница
```

Пример: `https://www.example.com/docs/index.html`

- `https` — протокол (защищённое соединение).
- `www.example.com` — доменное имя.
- `/docs/index.html` — путь внутри сайта.

**Задание КТП**: восстановить адрес из фрагментов.

Дан фрагменты: `https`, `www`, `ru`, `/info/`, `page1.html`. Собрать: `https://www.ru/info/page1.html`.

Домен верхнего уровня (`.ru`, `.com`, `.edu`) показывает страну или тип организации. При сборке адреса порядок такой: протокол, затем домен, затем косая черта, затем путь.

## Сетевой этикет

Правила поведения в сети — те же, что в обычном общении:

1. Представляйся, если пишешь незнакомому.
2. Отвечай на сообщения, не оставляя без внимания.
3. Не груби и не спамь.
4. Не выкладывай личные данные: адрес, телефон, номер карты, фото документов.
5. Уважай чужие авторские права: картинку нашёл в сети — это ещё не значит, что можно использовать.

## Стратегия безопасного поведения

- Установи антивирус и обновляй его.
- Не переходи по ссылкам из подозрительных писем.
- Проверяй адрес сайта перед вводом данных: буквы-подделки (`а` кириллицей вместо `a` латинской).
- Не скачивай файлы без необходимости.
- Придумай разные пароли для разных сайтов и не сообщай их.

## Правовая охрана программ и данных

Авторские права на программы, изображения, музыку и тексты принадлежат их авторам. Копирование и распространение без разрешения — нарушение закона. Домашнее задание с чужим рефератом, скачанным из сети, — тоже использование чужой работы.

## Практическая работа

Задание КТП: использовать сервисы интернет-коммуникаций.

1. Напиши короткое сообщение другу: поздоровайся, задай вопрос, ответь на его ответ.
2. Соблюдай этикет: без грубости, без спама, личных данных не сообщай.

## Ключевое (записать)

- Локальная сеть — в одном здании, глобальная — через планету. Интернет — глобальная.
- Адрес: `протокол://домен/путь`.
- Этикет в сети = этикет в жизни; личные данные не выкладывать.
- Авторские права: нашёл в сети — не значит можно использовать.

## Частые ошибки

- Путать веб-страницу и веб-сайт: страница — одна, сайт — их набор.
- Не проверять домен перед вводом пароля: подделка выглядит похоже.
- Считать, что интернет-страница не проверяется: любой может написать что угодно.
- Сдавать реферат, скачанный целиком.

## Проверь себя

1. Из каких частей состоит адрес веб-ресурса?
2. Собери адрес из фрагментов: `http`, `site`, `ru`, `/blog/`.
3. Назови три правила сетевого этикета.
4. Почему нельзя вводить пароль на сайте, похожем на известный?
