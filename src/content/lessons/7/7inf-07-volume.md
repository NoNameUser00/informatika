# Сколько весит сообщение

**Информационный объём (I)** — вес всего сообщения в битах.

```
I = K · i        (объём = число символов × вес символа)
```

## Две формулы

```
N = 2^i        (мощность алфавита ↔ вес символа)
I = K · i      (объём = число символов × вес символа)
```

Из двух формул находится всё остальное.

## Оформление решения

Как в учебнике: **Дано → Формулы → Вычисление → Ответ**.

Пример: сообщение из 140 символов, алфавит 32 символа.

```
Дано:  N = 32       Формулы:  I = K·i,  N = 2^i
       K = 140
       I — ?

Решение: 32 = 2^i  →  i = 5 (бит)
         I = 140 · 5 = 700 (бит)

Ответ: 700 бит.
```

## Единицы измерения

```
1 байт = 8 бит
1 Кбайт = 1024 байта
1 Мбайт = 1024 Кбайта
1 Гбайт = 1024 Мбайта
```

Внимание: Кбайт, Мбайт, Гбайт — это 1024. А километр — 1000 метров. Не путай.

## Переводы

Переводим цепочкой, деля на 8 и на 1024:

```
24576 бит = 24576 : 8 = 3072 байта = 3072 : 1024 = 3 Кбайта
```

Обратно, в байты: `3 Кбайта = 3 · 1024 = 3072 байта = 3072 · 8 = 24576 бит`.

## Обратная задача

Дано I = 720 бит, K = 180 символов.

```
i = I : K = 720 : 180 = 4 (бит на символ)
N = 2^i = 2⁴ = 16 (символов в алфавите)
```

Ответ: 16 символов.

## Ключевое (записать)

- `N = 2^i`, `I = K · i`. Из двух формул находится всё третье.
- 1 Б = 8 бит; 1 КБ = 1024 Б; 1 МБ = 1024 КБ; 1 ГБ = 1024 МБ.
- Оформление: Дано | Формулы | Решение | Ответ.

## Частые ошибки

- Путать K и I: K — штуки символов, I — биты.
- Делить на 1000 вместо 1024 при переводе в Кбайты.
- Забыть перевести биты в байты, когда вопрос про байты.
- Считать i = N: i — степень, а не само число.
- Перемножать K на 8: 8 нужно при переводе в байты, а не внутри формулы I = K·i.

## Проверь себя

2. Вырази в разных единицах: 24576 бит; 2048 байта; 1,5 Кбайта.
3. Алфавит из 256 символов. Чему равен I для сообщения в 300 символов?
