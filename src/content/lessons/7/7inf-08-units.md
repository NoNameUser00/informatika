# Единицы и переводы

В прошлом уроке вывели формулы. Теперь — уверенный счёт переводов, потому что это самая частая ошибка в задачах.

## Таблица единиц

```
1 бит   = 1
1 байт  = 8 бит
1 Кбайт = 1024 байта = 8192 бит
1 Мбайт = 1024 Кбайта = 1 048 576 байт
1 Гбайт = 1024 Мбайта
```

Ключевое число, которое встречается везде: **1024**.

## Перевод вниз (из большего в меньшее) — делим

- биты → байты: `: 8`
- байты → Кбайты: `: 1024`
- Кбайты → Мбайты: `: 1024`
- Мбайты → Гбайты: `: 1024`

## Перевод вверх (из меньшего в больший) — умножаем

- байты → биты: `· 8`
- Кбайты → байты: `· 1024`
- Мбайты → Кбайты: `· 1024`

## Примеры цепочкой

```
24576 бит  = 24576 : 8 = 3072 байта = 3072 : 1024 = 3 Кбайта
2048 байт  = 2048 : 1024 = 2 Кбайта
1,5 Кбайта = 1,5 · 1024 = 1536 байт = 1536 · 8 = 12 288 бит
```

## Типовые задачи

**Задача 1.** Текст из 100 символов, каждый занимает 2 байта.

```
I = 100 · 2 = 200 (байт)
```

**Задача 2.** Файл весит 4 Кбайта. Сколько символов в нём, если один символ — 1 байт?

```
4 Кбайта = 4 · 1024 = 4096 байт
4096 : 1 = 4096 символов
```

**Задача 3.** Сообщение 2 Кбайта, алфавит 256 символов.

```
i = 8 (бит) = 1 байт
2 Кбайта = 2048 байт
символов = 2048 : 1 = 2048
```

## Ключевое (записать)

- 1 Б = 8 бит; 1 КБ = 1024 Б; 1 МБ = 1024 КБ; 1 ГБ = 1024 МБ.
- Вниз — делим, вверх — умножаем.
- Кбайт/Мбайт/Гбайт считаются по 1024, а метры и килограммы — по 1000.

## Частые ошибки

- Делить на 1000 вместо 1024.
- Путать направление: из байтов в биты — умножаем на 8, не делим.
- Забыть, что при вопросе «во сколько байт» из битов нужно сначала разделить на 8.
- Считать «1,5 Кбайта» как «1 байт + 5 бит».

## Проверь себя

1. Вырази 24576 бит в байтах и Кбайтах.
2. Вырази 1,5 Кбайта в битах.
3. Файл 4 Кбайта, символ занимает 2 байта. Сколько символов?
