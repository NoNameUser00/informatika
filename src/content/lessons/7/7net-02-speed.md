# Скорость канала

**Скорость передачи данных** — сколько бит проходит по каналу за секунду. Измеряется в битах в секунду (бит/с), часто с приставками килобиты, мегабиты.

Провайдеры пишут «100 Мбит/с», а скачивание программы измеряют в мегабайтах в секунду (Мбайт/с). Разница в 8 раз:

```
1 Мбайт/с = 8 Мбит/с
```

## Связь объёма, скорости и времени

```
время = объём : скорость
```

Пример: файл 1 Кбайт по каналу 1024 бит/с.

```
Объём: 1 Кбайт = 1024 байта = 8192 бит
t = 8192 : 1024 = 8 секунд
```

Второй пример: файл 2 Мбайта по каналу 2 Мбит/с.

```
Объём: 2 Мбайта = 2 · 1024 · 1024 · 8 = 16 777 216 бит
Скорость: 2 Мбит/с = 2 · 1 000 000 ≈ 2 000 000 бит/с
t ≈ 16 777 216 : 2 000 000 ≈ 8,4 секунды
```

## Что влияет на реальную скорость

Заявленная провайдером скорость — это максимум канала. Реальная ниже, потому что:

- канал делят другие пользователи,
- часть трафика идёт на служебные нужды,
- есть задержка — отклик не мгновенный,
- дальние серверы отдают данные медленнее.

Поэтому файл в 700 Мбайт при заявленных 100 Мбит/с качается не 56 секунд, а заметно дольше.

## Считаем время на практике

```
t = объём : скорость
```

Обязательно сначала выровнять единицы: объём в биты, скорость в биты в секунду.

## Ключевое (записать)

- Скорость — бит в секунду; 1 Мбайт/с = 8 Мбит/с.
- `время = объём : скорость`.
- Выравнивать единицы перед делением.
- Реальная скорость ниже заявленной.

## Частые ошибки

- Считать время в байтах, а скорость в битах.
- Путать Мбит/с и Мбайт/с (разница × 8).
- Забыть перевести Кбайты в биты: 1 Кбайт = 8192 бит, а не 1000.
- Считать, что заявленная скорость = реальная.

## Проверь себя

1. Файл 1 Кбайт, канал 1024 бит/с. Сколько секунд?
2. Сколько бит в 1 мегабайте?
3. Почему реальная скорость меньше заявленной?
