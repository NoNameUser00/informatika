# От знаков — к двоичному коду

**Знак** — заменитель объекта по соглашению (слово, цифра, жест). Набор знаков — **знаковая система**. Языки бывают естественные (русский) и формальные (математика, ноты, код).

## Алфавит и мощность

**Алфавит** — все символы для записи. **Мощность (N)** — количество символов в нём. У русского алфавита мощность 33, у двоичного — всего 2 (0 и 1).

## Главная формула кодирования

Двоичных слов длины i существует ровно **N = 2^i**:

```
i: 1  2  3   4   5   6   7   8
N: 2  4  8  16  32  64 128 256
```

Каждая позиция удваивает количество: слов из 3 символов вдвое больше, чем из 2 (000, 001, …, 111 — всего 8).

## Универсальность двоичного кода

Любой алфавит переводится в двоичный код — значит, двоичным кодом выражается ЛЮБАЯ информация: тексты, формулы, картинки, звуки. Компьютеру достаточно двух состояний схемы — «включено» (1) и «выключено» (0). Простота реализации — главное достоинство; недостаток — большая длина кода.

## Ключевое (записать)

- Знак — заменитель по соглашению. Мощность — число символов алфавита.
- N = 2^i: длина кода ↔ сколько разного можно закодировать.
- Двоичным кодом выразимо всё; компьютеру хватает 0 и 1.

## Частые ошибки

- Путать i (длина кода) и N (сколько закодируем): N — это 2 В СТЕПЕНИ i.
- Думать, что 8 символов кодируются 8 битами (надо 3: 2³ = 8).

## Проверь себя

1. Сколько разных символов закодируем кодом длины 5? А длины 7?
2. Какой длины нужен код для 64 символов? Для 100?
