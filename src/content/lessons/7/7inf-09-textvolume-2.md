# Задачи повышенной сложности

Продолжение темы: задачи, где нужно сначала найти промежуточную величину или где данные заданы неявно.

## Приём 1. Объём текста, а не алфавита

Если дан алфавит, но не вес символа, вес находится по `N = 2^i`.

```
Условие: 3 страницы, 40 строк по 60 символов, алфавит 64 символа.
N = 64 = 2^i  →  i = 6 (бит)
K = 3 · 40 · 60 = 7200 (символов)
I = 7200 · 6 = 43 200 (бит) = 43 200 : 8 = 5400 (байт)
Ответ: 5400 байт.
```

## Приём 2. Идём назад: от объёма к алфавиту

```
Условие: 6 страниц по 40 строк по 60 символов, всего 9000 байт.
K = 6 · 40 · 60 = 14 400 (символов)
I = 9000 · 8 = 72 000 (бит)
i = I : K = 72 000 : 14 400 = 5 (бит)
N = 2^5 = 32 (символа)
Ответ: вес символа 5 бит, алфавит 32 символа.
```

## Приём 3. Сообщение из нескольких частей

Если сообщение состоит из текста и, скажем, рисунка, объёмы складываются.

```
Условие: текст 20 символов по 8 бит + рисунок 2 560 бит.
I = 20 · 8 + 2 560 = 160 + 2 560 = 2 720 (бит) = 340 (байт)
```

## Приём 4. Считаем от ответа

Часто в условии не дано K, а дан объём в байтах и вес символа. Тогда:

```
Условие: сообщение занимает 3 Кбайта, вес символа 4 бита.
I = 3 · 1024 = 3072 (байт) = 3072 · 8 = 24 576 (бит)
K = I : i = 24 576 : 4 = 6144 (символа)
```

## Алгоритм решения

1. Выписать Дано, выписать Формулы.
2. Если нет i — найти через N. Если нет N — найти через i.
3. Найти I (или K).
4. Привести к нужным единицам.
5. Ответ.

## Ключевое (записать)

- Число символов текста = страницы × строки × символы в строке.
- Нет веса символа → найти через мощность алфавита.
- Объёмы частей сообщения складываются.

## Частые ошибки

- Перемножить страницы на строки, забыв про символы в строке.
- Считать объём в байтах, но забыть перевести биты.
- Перепутать, что искать: в условии спрашивают K, а не I.
- Не привести ответ к единицам из вопроса.

## Проверь себя

1. Текст: 2 страницы, 50 строк по 70 символов, алфавит 128 символов. Найди объём в байтах.
2. Сообщение 2 Кбайта, вес символа 8 бит. Сколько символов?
3. Текст 15 символов по 4 бита и рисунок 800 бит. Общий объём?
