# Непрерывное и дискретное

Мир вокруг нас непрерывен: температура меняется плавно, звук — волна, движение — без остановок. Компьютер же работает только с **дискретными** величинами: у него есть конечный набор состояний.

**Аналоговая (непрерывная) информация** — значение может принимать любое число из промежутка. Пример: температура 21,7 °C, громкость звука.

**Дискретная информация** — значение из конечного набора. Пример: «дождь идёт / не идёт», цифра от 0 до 9, положение на шахматной доске.

## Преобразование данных из непрерывной формы в дискретную

Это называется **дискретизация** — процесс превращения непрерывной величины в набор конечных значений.

Как это работает:

1. Из непрерывного множества выбираем **конечное** количество значений (например, 256 оттенков серого).
2. Каждому промежутку между ними присваиваем код.
3. Исходное значение округляем к ближайшему из выбранных.

Пример: яркость от 0 до 100 кодируем числами 0…255. Значение 63,5 округлится к 64 — оно станет одним из 256 возможных.

## Зачем это нужно

Дискретные данные — и есть материал для компьютера. Изображение, звук, видео — всё это непрерывные величины, которые программа превращает в числа, а потом хранит как последовательность битов.

Поэтому: **больше дискретных значений — точнее представление, но больше данных**. 256 оттенков точнее, чем 4, но требуют больше бит.

## Где мы это уже видели

- 8-битный цвет: 256 оттенков на канал.
- Код символа в ASCII: 128 значений.
- Оцифровка звука: частота дискретизации задаёт, сколько значений в секунду берётся.

## Ключевое (записать)

- Аналоговая информация — непрерывная, принимает любое значение из промежутка.
- Дискретная — конечный набор значений.
- Дискретизация: выбрать конечное число значений и округлить к ним.
- Компьютер работает только с дискретными данными.

## Частые ошибки

- Считать, что компьютер хранит «настоящее» непрерывное значение: он хранит ближайшее из конечного набора.
- Путать увеличение числа значений с увеличением размера файла: больше значений — больше бит.
- Считать дискретизацию копированием: это приближение, а не точная копия.

## Проверь себя

1. Приведи пример аналоговой и дискретной информации.
2. Что такое дискретизация?
3. Почему чем больше значений, тем больше данных?
