- Что: локальный роутер, один OpenAI-совместимый endpoint к 40–60+ провайдерам, 3-уровневый фолбэк, экономия токенов (RTK). Поддерживает OpenCode как клиента.
- Родственник: OmniRoute (`diegosouzapw/OmniRoute`) — та же ниша, разбор 2026-10-06.
- Когда пригодится: личные dev-сессии вне пилота (срезать расходы coding-агентов, фолбэк при лимитах).
- Жёсткое правило (не снимать): никакого `teacher_only` и ПДн через шлюзы — данные размазываются по сторонним free-провайдерам. Только синтетика и публичный код.
- В контур проекта (бэкенд/фронт) не добавлять: для синтетики уже есть OpenRouter (`backend/src/rag_informatics/openrouter.py`).
