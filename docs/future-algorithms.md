# Будущая тема «Алгоритмы» — отложенные решения

## Ebitengine (ex-Ebiten) — кандидат для темы алгоритмов

- Источник: `github.com/hajimehoshi/ebiten` (Apache-2.0), 2D-движок для Go, есть WebAssembly-сборка.
- Зачем отложено сюда (`запомни`, 2026-10-06): визуализация алгоритмов (сортировки, поиск, обходы графов) и игровые проектные работы с ручной оценкой по рубрике.
- Почему не сейчас: пилот — системы счисления; Go-тулчейн чужероден стеку Astro+TS; автопроверка игр слабая; сборка WASM требует песочницы.
- Условия возврата: тема алгоритмов входит в план + решение по языку (Python vs Go/JS) + песочница для кода учеников + витрина WASM-сборок на Pages.

## Не применять

- Как основу автопроверяемых заданий с влиянием попыток на оценку (см. разбор 2026-10-06: скриншот-тесты хрупкие, попытки — слой БД/Edge, не движка).
