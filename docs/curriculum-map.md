## Порядок запуска (предложение)

1. Добить пилот 8-СС (банк → варианты → контрольная на сервере).
2. 8-Матлогика: смежная тема, тот же класс, типы заданий те же (single_choice/numeric_base/matching + таблицы истинности).
3. 7-Информация: входной класс, простые типы.
4. Дальше по готовности методиста; 10–11 — после отработки схемы (там текстовый слой, конспекты дешевле).

## Правила для новых банков (из пилота)

- Формат заданий и teacher_only — как в `data/tasks/8/number-systems/bank.yaml`; теги ФГОС — контролируемый словарь.
- Программирование (только Python и КуМир, Паскаль запрещён — AGENTS.md) — только через песочницу (AGENTS.md), автопроверка — тестами, не LLM.
- Каждый банк: свои `docs/curriculum-<класс>-<тема>.md` по образцу `curriculum-8-ss.md` + сценарии/симы по мере сил.
