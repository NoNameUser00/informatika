# 7 класс — Двоичное кодирование и ещё 5

В этом банке 21 задание single_choice, из них **14** в ведомости.
Ещё 7 имеют объективное свидетельство (пояснение прямо называет верный
вариант или вариант отвергнут в `common_errors`) — их ключ машина проверяет сама,
поэтому в список они не попали.

**Как отвечать.** Меняйте только строку `Вердикт:`:

* `Вердикт: верно` — ключ правильный, ничего менять не нужно;
* `Вердикт: поправить на C` — верный вариант другой.

Пустую строку скрипт применения пропустит и посчитает как «ещё не проверено».
Любой другой текст он считает опечаткой и останавливается — чтобы ошибка не
прошла молча.

Применить ответы: `node scripts/apply-key-review.mjs`.

## 10. inf-7-inf-040

**Вопрос.** Для алфавита из 64 символов ученик записал i = 64. В чём ошибка?

* **D.** i = 64 верно, но вес символа измеряют в байтах
* **C.** i находят делением: 64 : 8 = 8
* **A.** Вес символа — степень двойки: 64 = 2^6, значит i = 6 бит ← сейчас ключ

**Ключ сейчас: A** — Вес символа — степень двойки: 64 = 2^6, значит i = 6 бит

**Почему так.** Из N = 2^i берут показатель степени: при 64 символах i = 6, а не 64.
