# 8 класс — Системы счисления

В этом банке 2 задания single_choice, из них **2** в ведомости.
Ещё 0 имеют объективное свидетельство (пояснение прямо называет верный
вариант или вариант отвергнут в `common_errors`) — их ключ машина проверяет сама,
поэтому в список они не попали.

**Как отвечать.** Меняйте только строку `Вердикт:`:

* `Вердикт: верно` — ключ правильный, ничего менять не нужно;
* `Вердикт: поправить на C` — верный вариант другой.

Пустую строку скрипт применения пропустит и посчитает как «ещё не проверено».
Любой другой текст он считает опечаткой и останавливается — чтобы ошибка не
прошла молча.

Применить ответы: `node scripts/apply-key-review.mjs`.

## 1. inf-8-numsys-005

**Вопрос.** Сколько единиц в двоичной записи числа 15₁₀?

* **A.** 2
* **B.** 3
* **C.** 4 ← сейчас ключ
* **D.** 1

**Ключ сейчас: C** — 4

**Почему так.** 15 = 1111_2, четыре единицы
**Ошибки учеников.** Путают с числом нулей; Считают 15_10 как 111_2

Урок: `numsys-02-binary` · basic · 1 балл.

Вердикт: верно

## 2. inf-8-numsys-012

**Вопрос.** Какая система счисления является непозиционной?

* **A.** Двоичная
* **B.** Римская ← сейчас ключ
* **C.** Восьмеричная
* **D.** Шестнадцатеричная

**Ключ сейчас: B** — Римская

**Почему так.** В римской значение знака не зависит от позиции (I, V, X...), в остальных — зависит от разряда
**Ошибки учеников.** Путают основание с позиционностью

Урок: `numsys-01-intro` · basic · 1 балл.

Вердикт: верно
