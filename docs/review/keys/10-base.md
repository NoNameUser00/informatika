**Вопрос.** При проверке программы один тест не совпал с ожидаемым результатом. Что это означает и что делают дальше?

* **B.** Лишний тест: его надо удалить из набора, он не соответствует задаче
* **D.** Ошибка в самом тесте: правильный ответ нужно заменить на результат программы
* **A.** Тест выявил ошибку: по нему ищут причину в коде, исправляют её и прогоняют всю проверку заново
* **C.** Программа готова: остальные тесты прошли, а этот можно не учитывать ← сейчас ключ

**Ключ сейчас: C** — Программа готова: остальные тесты прошли, а этот можно не учитывать

**Почему так.** Тест, на котором программа не проходит, — это описание найденной ошибки, а не повод отмахнуться. Сначала по нему локализуют причину, потом правят код, и только после этого прогоняют весь набор заново, чтобы убедиться, что исправление ничего не сломало. Подменять ожидаемый ответ выводом программы нельзя: иначе ошибка станет новым правилом.
