поэтому в список они не попали.

**Как отвечать.** Меняйте только строку `Вердикт:`:

* `Вердикт: верно` — ключ правильный, ничего менять не нужно;
* `Вердикт: поправить на C` — верный вариант другой.

Пустую строку скрипт применения пропустит и посчитает как «ещё не проверено».
Любой другой текст он считает опечаткой и останавливается — чтобы ошибка не
прошла молча.

## 5. inf-9-arr-024

**Вопрос.** Что делает условие в алгоритме с ветвлением?

* **D.** Останавливает программу
* **B.** Повторяет действия заданное число раз
* **C.** Записывает результат в таблицу
* **A.** Выбирает, какую из двух ветвей выполнять дальше ← сейчас ключ

**Ключ сейчас: A** — Выбирает, какую из двух ветвей выполнять дальше

**Почему так.** Ветвление — это выбор: условие проверяется, и дальше выполняется только одна из ветвей. Цикл, в отличие от ветвления, повторяет действия, а не выбирает их.

## 6. inf-9-arr-038

**Вопрос.** Массив: 3, 5, 9, 1. Верно ли, что среднее арифметическое равно сумме, делённой на количество элементов?

* **B.** Нет, среднее считается по максимуму
* **D.** Да, но только для чётных массивов
* **A.** Да, это определение среднего арифметического ← сейчас ключ
* **C.** Нет, среднее равно половине суммы

**Ключ сейчас: A** — Да, это определение среднего арифметического
