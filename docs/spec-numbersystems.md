# Пилот: 8 класс — Системы счисления

## Состав контрольной (шаблон v1)
- время: 45 мин, попыток: 1, вариантов: 30
- слоты:
  - S1-S2: перевод 10->2/8/16 (basic, 1б)
  - S3-S4: перевод 2/8/16->10 (basic, 1б) + 1 single_choice
  - S5-S7: перевод 2<->8<->16, цепочки, арифметика (intermediate, 2б)
  - S8-S9: анализ / соответствие / цепочка переводов (advanced, 3б)
- макс: 5*1 + 3*2 + 2*3 = 17б

## Теги ФГОС 3.0 (контролируемый словарь)
- subject: `inf-8-numsys-represent`, `inf-8-numsys-convert`, `inf-8-numsys-arith`

- cognitive: remember | apply | analyze

## Правила нормализации numeric_base
- trim, убрать пробелы/подчеркивания: `1 010` -> `1010`
- регистр не важен: `aF` == `AF`
- кириллица А-Е -> латиница A-E, ё->е (для текстовых полей)
- префиксы допустимы и отрезаются: `0b1010`, `0xAF`, `0o17`
- суффиксы основания: `1010_2`, `AF(16)` — отрезаются при `strip_affixes:true`
- ведущие нули игнорируются: `00101` == `101`
- числовое сравнение — по значению в base 10, не по строке

## Частичный балл
- single_choice: all_or_nothing
- multiple_choice (если будет): `score = max(0,(ok - extra)/total_correct)*points`
- matching: `score = round(matched_pairs/total_pairs * points)`
- numeric_base: all_or_nothing (опечатка = 0, без «почти верно» на экзамене)

## Шкала (дефолт, правится методистом)
- percent = earned / max * 100 (тренажер: max=20; контрольная v1: max=17)
- 5: >=90, 4: >=75, 3: >=50, 2: <50
- proposed_mark предлагает сервер, final_mark ставит учитель с причиной (audit).

## Формат по Яндекс.Форме учителя (проверочная 8 кл., 1 триместр)
- Структура: стр.1 — ФИО ученика (Фамилия Имя), Класс, Буква класса (+ ссылка на материалы);
  дальше страницы по ~5 вопросов, на каждой повтор инструкции.
- Инструкция на каждой странице: «В ответе запишите только само число.
  Основание системы счисления (₂, ₈, ₁₀, ₁₆) указывать не нужно.»
- Основание пишется подстрочным: ₂ ₈ ₁₀ ₁₆ (не `_2`, не `(2)`).
- Арифметика — ответ в десятичной системе.

  Класс/Буква отдельно, баннер-инструкция), классы — реальные:
  7-Ю/Я, 8-Ч/Ш/Э, 9-У/Ф/Ш, 10-Я, 11-Я.
