# 8 класс — карта блока «Системы счисления» (ФРП база + КТП + сайт)

Источники: `material/FRP/FRP_Informatika_7-9_base_2025.pdf` (8 класс: СС 6ч, с.8-9,32; коды 1.1/1.2, элементы 1.1-1.4),
`material/ktp/26_27. Информатика-8.xlsx` (блок СС — 6 уроков), `material/Bosova_demo/bosova-8-ogl.pdf` (§1.1.1-1.1.7).
Теория на сайте — только свои конспекты, не копия Босовой.

## Ритм (по учителю)
- задачи — каждый урок СС
- практика — через 2-3 урока
- проверочная в триместре: практическая или тест (тесты всегда на компьютере)
- КР раз в триместр + следующий урок — работа над ошибками

## Триместровый контур
- Проверочная (тест, компьютер): слоты S1-S7, автопроверка, proposed_mark
- КР раз в триместр (охватывает СС + логика/алгоритмы по КТП): 30 вариантов, сервер, teacher_only скрыт
- След. урок: работа над ошибками — подборка из неверных слотов (индивидуальные ссылки на тренажеры)
