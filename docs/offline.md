# Офлайн-версии для школы без интернета

Две сборки из одного кода (`npm run build:offline-student|teacher`).
Дистрибутивы (`dist-offline-*/`) в репо не коммитятся — раздаются файлами
(флешка, локальная сеть). Одна ОС — один и тот же дистрибутив, различаются
только запускалки: `start-windows.bat` (Windows 10/11) и `start-rosa.sh`
(Rosa OS Mostex 12, МосТех.ОС). Запуск — локальный сервер
`http://localhost:8000/` (нужен Python: на Rosa есть в образе, на Windows —
обычно тоже; нет — попросить учителя).

## Ученическая сборка

- Все ключи вырезаны (`scripts/offline-strip.mjs`): полные банки проверок
  удалены, из тренажёрных вычищены `key/correct/expected/answerMap`.
- Проверок/тренажёров с оценкой нет: вместо «Отправить» ученик скачивает
  файл ответов `класс_фамилия_имя_работа_vN.json` (формат `informatika-answer-v1`:
  работа, вариант, хэш версии, ответы — без ключей).
- Файл передаётся учителю: почта, флешка, локальная сеть.
- Каждая сборка кончается строгим аудитом (`scripts/offline-audit.mjs`):
  утечка ключей = брак сборки.
- Осознанные исключения (не контрольные, а разбор с самопроверкой):
  задания внутри уроков (`*/play/*`) и ТБ-викторина (`*/tb/*`).

## Учительская сборка

- Полные банки с ключами + страница «Проверка файлов» (`/teacher/check-files/`).
- Проверка файла: формат → известная работа → **хэш версии** (`offline-hashes.json`,
  считает `npm run offline:hash`). Хэш разошёлся — файл отклоняется:
  это другая версия работы, проверять нельзя.
- Итоги: таблица (верно из N, баллы, отметка), разбор по ученику (учителю
  можно), аналитика по темам, экспорт CSV. Шкала та же: 5/4/3 от 90/75/50.
- Задания с кодом (`code_run`): Python в браузере тянется с CDN, офлайн его
  не выполнить — такие задания учитель засчитывает вручную кнопками
  «Засчитать / Не засчитать» прямо в разборе (итоги пересчитываются).
- **Не раздавать ученикам**: в этой сборке лежат ключи всех работ.

## Обычные приложения (двойной клик, без Python и терминала)

`npm run app:student|teacher` (после `build:offline-*`) упаковывает дистрибутив
в нативное окно на Neutralino (~3 МБ, свой сервер внутри):
`app-<role>-windows/` (`Informatika-*.exe`) и `app-<role>-rosa/` (бинарь Linux).
Раздаются папками целиком (exe + `neutralino.config.json` + `resources/`).
Требования: Windows 10/11 с WebView2 (обычно уже стоит), Rosa OS с WebKitGTK.
В приложении сохранение файла идёт через системный диалог (в браузере —
обычное скачивание). Запускалки `.bat`/`.sh` остаются запасным путём.

## Обновление версий

Работы зашиты в сборку. Изменились банки — пересобери обе версии и перегенерируй
хэши (`npm run offline:hash` коммитится в репо). Файлы ответов от старой версии
новая учительская сборка отклоняет по хэшу — это защита, а не баг.
